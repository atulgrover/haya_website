Data Privacy & Sovereignty

Privacy Policy

Effective Date: August 14, 2026  |  Domain: https://hayagriva.app  |  Platform: HAYAGRIVA IPE & Skillpedia
🔒 Core Privacy Guarantee: HAYAGRIVA is architected around a Local-First & Zero Cloud Data Transmission principle. All confidential case files, company domain records, financial ledgers, and local AI agent inferences execute strictly on your local device.

1. Introduction & Scope

HAYAGRIVA (“we”, “our”, or “us”) operates the HAYAGRIVA Universal Integrated Professional Environment (IPE) Platform, the NSQF Skillpedia learning hub, and the web portal hosted at https://hayagriva.app.

This Privacy Policy explains what data is processed when you access our web portal, download desktop binaries, use our NSQF micro-learning video reels, or purchase software licenses and marketplace intelligence reports.

2. Information We Collect

We only collect information necessary to provide authentication, licensing, and access to educational materials:

  • Account & Profile Information: When you register on the portal, we store your full name, email address, password hash (encrypted using salt-hashed bcrypt), role persona (Student, Employee, or Professional), and optional firm/organization name.
  • Authentication & Session Data: We issue secure JSON Web Tokens (JWT) stored locally in your browser’s localStorage to maintain authenticated sessions.
  • Licensing & Transaction Details: For licensed professionals, we store cryptographic license keys, purchase tiers, transaction identifiers, and expiration dates.
  • Marketplace Report Orders: When ordering valuation or intelligence reports, we collect order specifications (company name, report parameters, notes) to fulfill the requested analysis.

3. Local-First & Zero-Cloud Data Sovereignty

For users of the HAYAGRIVA Desktop IPE (Insolvency Professionals, Legal Counsel, and Enterprise Teams):

  • No Cloud Document Uploads: Case papers, valuation sheets, Section 29A verification files, and corporate debtor records processed in the Desktop IPE are stored exclusively in your local encrypted vaults (.vlt) and local SQLite instances.
  • Local AI Inferences: Multi-agent audits and LLM workflows run via local quantized models (GGUF / local inference runtimes) without transmitting sensitive prompts or documents over the public internet.

4. Third-Party Integrations & YouTube API Services

HAYAGRIVA integrates with YouTube API Services to provide relevant, verified vocational training demonstration videos mapped to the National Skills Qualification Framework (NSQF) 2,176 job roles and performance criteria.

📺 YouTube API Terms & Google Privacy Disclosures:
  • HAYAGRIVA uses YouTube API Services to retrieve public vocational video metadata and embed instructional video tutorials.
  • By using these video features on HAYAGRIVA, users agree to be bound by the YouTube Terms of Service.
  • Please refer to the Google Privacy Policy for information on how Google collects and processes data.
  • Users can view and revoke HAYAGRIVA’s access to their data via the Google Security Settings Page.

4.1 Non-Commercial Public Education & Zero Paywalls

HAYAGRIVA NSQF Skillpedia is a 100% free, open public education initiative designed to empower Indian vocational learners, students, and ITI candidates across 41 economic sectors:

  • Zero Paywalls on YouTube Content: Video search, curriculum discovery, and instructional video playback are completely free. We do not charge fees, require paid subscriptions, or gate YouTube video playback behind any payment mechanism.
  • Non-Monetized API Access: We do not sell access to YouTube API Data or monetize video embeds.

4.2 User Information & API Data Collected, Accessed, and Stored (Policy III.A.2d)

We believe in complete transparency regarding the data accessed and stored in connection with YouTube API Services:

  • Public Video Metadata Accessed: When users search or browse vocational curriculum modules, our API Client queries the YouTube Data API v3 to retrieve public, non-authenticated video metadata including: video IDs, video titles, descriptions, channel titles, published dates, durations, and video thumbnail image URLs.
  • No Personal Google Account Data Collected: HAYAGRIVA does NOT access, collect, store, or process any private user Google/YouTube account data, viewing histories, personal profiles, Google account passwords, or OAuth tokens. We do not require users to sign in with Google to view public vocational tutorials.
  • User Learning State: Any user progress (such as completing an NSQF skill checklist or module bookmark) is stored independently in the user’s local account database and is never associated with or transmitted to Google/YouTube accounts.

4.3 How We Use, Process, and Share Information (Policy III.A.2e)

We process API Data strictly for educational qualification delivery:

  • Processing & Educational Mapping: Retrieved YouTube metadata is processed solely to categorize and display practical demonstration videos corresponding to specific National Occupational Standards (NOS) and Performance Criteria (PC) for vocational learners.
  • Internal Parties: API Data is processed internally solely by our educational curriculum indexer and user-facing search engine to present structured learning pathways. No employee or internal party accesses private user search histories.
  • External Parties & Zero Data Sharing: We do NOT sell, rent, license, trade, or transfer any user data or YouTube API Data to external third parties, advertising networks, commercial brokers, or analytics syndicates.
  • Embedded Official Player: Video playback is executed directly within the user’s web browser via the official YouTube IFrame Embed Player connecting directly to YouTube servers. We do not download, modify, stream-rip, or alter original YouTube audio or video streams.

4.4 7-Day Rolling Ephemeral Operational Cache & Purge Policy (Policy III.E.4.a-g)

In strict adherence to YouTube Developer Policy III.E.4.a-g:

  • 7-Day Ephemeral Operational Cache: Any cached search query mappings or YouTube video metadata temporarily stored on our servers for rate-limit protection and performance optimization are retained for a maximum of 7 days.
  • Automated Daily Purging: An automated background maintenance job runs every 24 hours to delete and purge any cached YouTube search metadata older than 7 days. No API statistics, metrics, or metadata are retained or displayed beyond this 7-day operational window without being re-fetched fresh from the YouTube Data API v3.
  • User Deletion Requests: Users may request immediate deletion of their local portal account and associated learning bookmarks at any time by contacting hayagriva.app@gmail.com.

5. Financial Disclosures (Desktop IPE Only)

6. Cookies & Local Storage

We use standard browser local storage (localStorage) strictly for functional session management (JWT token persistence, active tab state, and theme preferences). We do not use third-party behavioral advertising trackers or cross-site tracking cookies.

7. Data Security & Compliance

We implement robust technical and organizational security measures:

  • All web traffic is encrypted in transit using industry-standard TLS / HTTPS (256-bit).
  • Database backups are encrypted at rest.
  • We adhere to data protection principles set out under the Digital Personal Data Protection Act, 2023 (DPDP Act, India) and global privacy standards.
