Introduction

PageIndex is a document harness for LLMs and agents: the layer that lets your AI model work with your documents. Use it to get cited answers from long documents, find the pages that answer a question, and extract data as JSON. Pick the product that fits your needs:

You want to Use API keys you need Coding agent
Get answers with line-level citations PageIndex Agent PageIndex and your LLM's
Find the pages that answer a question Page Search API PageIndex
Extract fields and tables as JSON Page Extract API PageIndex

All three products use the same PageIndex API key, the same SDK (Python or JavaScript) and the same document library: a document you upload for one works with the others. Get a key in the PageIndex Console. A new account starts with $10 of free credit and needs no subscription. See Pricing.

Working with a coding agent such as Claude Code, Codex, or Cursor? Copy prompt copies a prompt to paste into it, and the agent sets up that product in your project.

PageIndex Agent

PageIndex replaces fragile text-chunking and vector proximity with hierarchical document reasoning. Rather than breaking 100+ page CIRP resolution plans or High Court paper books into blind chunks, PageIndex extracts the document's true table of contents and structural tree so your model navigates pages just like a seasoned practitioner.

Install the PageIndex library with a single command: 

# Python SDK
pip install pageindex

# JavaScript & TypeScript SDK
npm install pageindex

Why Agentic Professionals?

The legal, restructuring, and valuation landscape is transitioning from passive manual research to autonomous agentic execution. Becoming an Agentic Professional means equipping your chambers with sovereign local agents that read filings, verify statutory timelines, cross-reference judicial precedents, and synthesize multi-page briefs with verifiable citations.
