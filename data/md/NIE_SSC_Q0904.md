#### NIE/SSC/Q0904: Cyber Security Assistant
Brief Job Description
The Cyber Security Assistant Qualification would provide the fundamental skillset to the enrolled trainee,
pertaining to the field of Cyber Security. After course completion, the trained learner will exhibit a refined
posture about the basic concepts of Cyber Security ranging from Primitive Networking, Fundamentals of
Cyber Security, Operating System Introduction, Wireless, Mobile Security, OS, Web, Social engineering, and
Cyber laws
Personal Attributes
A Cyber Security Assistant should possess strong attention to detail, integrity, and critical thinking skills to
identify and address security threats effectively. They must be trustworthy, adaptable, and capable of
handling confidential information responsibly. Strong communication, teamwork, and a commitment to
continuous learning are essential in this fast-evolving field.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. DGT/VSQ/N0101: Employability Skills (30 Hours)
2. NIE/ITS/N0901: Fundamentals of Network and Operating System
3. NIE/ITS/N0902: Fundamentals of Cyber Security
4. NIE/SSC/N0918: Implemenation of Cyber Security Project

#### NIE/ITS/N0901: Fundamentals  of Network and Operating System
Description
Fundamentals of Network and Operating Systems encompass competencies in understanding networking
fundamentals, operating system basics, network configuration and management, network services and
protocols, troubleshooting, virtualization, security, documentation, and compliance within the context of
network and operating system environments.
Scope
The scope covers the following :
Networking fundamentals, configuration and management, operating system basics, virtualization,
security
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Overview of OSI, TCP/IP Model and Function of layers, learn about various types of networks.
- PC2. Knowledge about the Benefits of Networks, and components of Computer Networks and also
have an insight into various topologies used in networking.
- PC3. Explain various Transmission modes, Ethernet, and the Classification Of Transmission Media.
- PC4. In-depth idea about various networking devices like Repeaters, Hubs, Bridges, Switches, and
routers
- PC5. Introduction to TCP/IP Protocol Model in Depth, Port Numbers, Common TCP& UDP Ports and
also Some important TCP/IP protocols.
- PC6. IP addressing, Classes, IP Addressing Scheme, Subnetting Basics alongwith How to Create
Subnets, Subnet Masks, Subnetting Class C Addresses, Subnetting Class B Addresses and VLSM
- PC7. Configure ip addresses in Windows and Linux and also have a proper introduction to RIR,
registries and IANA along with attaining knowledge about TCP/IP Troubleshooting utilities,
Troubleshooting IP Addressing
- PC8. The in-depth idea about the Windows and Linux operating system and its File System
- PC9. Working on Command Line Utilities
- PC10. Working with Links: Working with Symbolic Links, Working with Hard Links
- PC11. Configuring Permissions, Read, Write, and Execute:
- PC12. Preparing the File System for ACLs
- PC13. Configuring Administrator Tasks with sudo
- PC14. The in-depth idea about the Linux operating system and its File System
- PC15. Managing Users and Groups,

#### NIE/ITS/N0901: Operating System Basics
Description
The NOS cover the installation processes of Windows and Linux, including various Linux installation types.
It emphasizes using OS commands for file management, system operations, and configuring essential
services. Understanding how OS boots, interacts with hardware, and manages services helps in system
administration and troubleshooting tasks effectively.
Scope
The scope covers the following :
The scope of this learning includes gaining hands-on experience with both Windows and Linux OS installation, understanding different installation types, and mastering essential commands for file
management and system operations. It also covers configuring and managing services, understanding OS boot processes, hardware interaction, and troubleshooting for efficient system
administration.
#### Elements and Performance Criteria
Install Windows and Linux Operating Systems
#### To be competent, the user/individual on the job must be able to:
- PC1. Identify system requirements for Windows and various Linux distributions.
- PC2. Perform a clean installation of Windows and Linux OS.
- PC3. Configure initial setup options (language, time zone, users, partitions).
Understand Linux Installation Types
#### To be competent, the user/individual on the job must be able to:
- PC4. Compare full installation, minimal installation, and custom installation of Linux.
- PC5. Select appropriate installation type based on use case (e.g., server vs desktop).
- PC6. Demonstrate ability to create and configure partitions (manual and guided).
Use Linux Command Line Interface (CLI)
#### To be competent, the user/individual on the job must be able to:
- PC7. Execute common Linux commands (navigation, viewing files, managing directories).
- PC8. Use file manipulation commands (cp, mv, rm, touch, mkdir).
- PC9. Utilize text editors (nano, vi) for basic file editing.
Perform File and Directory Operations
#### To be competent, the user/individual on the job must be able to:
- PC10. Create, rename, and delete files and directories.
- PC11. Change file permissions and ownership using chmod and chown.
- PC12. Copy and move files between directories and devices.
#### Knowledge and Understanding (KU)

#### NIE/ITS/N0902: Fundamentals  of Cyber Security
Description
Fundamentals of Cyber Security encompass competencies in core cyber security principles, regulations
and policies, threat awareness, network and operating system security, access control, incident response,
data protection, ethical hacking, and risk management, providing a framework for individuals to
understand, implement, and adhere to essential security practices in the field of cyber security.
Scope
The scope covers the following :
Fundamentals of Cyber Security encompasses the foundational knowledge and skills required to comprehend, implement, and maintain essential security practices, including threat awareness,
network and system security, access control, and incident response, to safeguard digital assets and
data from cyber threats and vulnerabilities.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Gaining the basic idea of Information Security and Introduction to Ethical Hacking
- PC2. Overview of Cryptography
- PC3. OS security and security tools for Windows Operating System
- PC4. Gaining the idea of Wireless Networks and Wireless Security
- PC5. Gaining the idea of the Android and iPhone iOS Operating system
- PC6. Introduction to Web Application & its terminologies and exploring Web Application Protocols
- PC7. Configuring Browser Security
- PC8. Introduction to Social Media & its security
- PC9. Exploring Security in Digital Payment Systems
- PC10. Gaining the idea of Various kinds of fraud in banking and Cyber Crime
- PC11. Introduction to Cyber Law, Cyber Cell, and Cyber Fraud Helpline
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Comprehensive Understanding of Cybersecurity Concepts -Knowledge of information security fundamentals, ethical hacking, cryptography, and OS-level security measures.
- KU2. Familiarity with Security Tools and Practices -Awareness of tools and techniques for securing
Windows OS, wireless networks, mobile operating systems (Android/iOS), and web applications.
- KU3. Insight into Emerging Threats and Platforms -Understanding of social media security, digital
payment systems, and potential threats in modern digital platforms.

#### NIE/ITS/N0902: Computer Network
Description
Develop comprehensive skills in computer networking, including IP addressing, routing, switching, and
WAN technologies. Gain hands-on experience configuring network devices, securing networks using ACLs,
NAT, VPN, and Layer 2 protections, and implementing network monitoring and logging solutions. Learn to
troubleshoot network issues and ensure secure, reliable communication across various protocols and
platforms.
Scope
The scope covers the following :
This module equips learners with practical skills in designing, configuring, and managing both LAN
and WAN networks using IPv4 and IPv6. It covers essential topics such as routing, switching, VLANs,
NAT, ACLs, VPNs, and network security. Students also gain hands-on experience with device configuration, network monitoring, and troubleshooting to ensure secure and efficient network
operations.
#### Elements and Performance Criteria
Design and Configure a Functional Network
#### To be competent, the user/individual on the job must be able to:
- PC1. Identify and explain types of networks, topologies, and models (OSI, TCP/IP).
- PC2. Design small LAN/WAN topologies and assign IP addressing (IPv4/IPv6) including subnetting
using VLSM and FLSM.
- PC3. Configure network devices using CLI and verify connectivity using protocols such as Telnet,
SSH, CDP, and LLDP.
Implement and Troubleshoot Routing & Switching
#### To be competent, the user/individual on the job must be able to:
- PC4. Configure static, default, and dynamic routing protocols (RIP, EIGRP, OSPF, IPv6 variants).
- PC5. Implement Layer 2 switching, VLANs, trunking protocols, and mitigate threats using port-
security and ACLs.
- PC6. Analyze and troubleshoot routing tables, protocol operations, and switching behaviors.
Manage WAN and Network Security Features
#### To be competent, the user/individual on the job must be able to:
- PC7. Configure WAN protocols like PPP, HDLC, and Frame Relay.
- PC8. Implement NAT types, troubleshoot connectivity, and ensure secure Internet access.
- PC9. Deploy FHRP protocols (HSRP, VRRP, GLBP) and use tracking for redundancy.
Apply Network Monitoring and Synchronization Tools
#### To be competent, the user/individual on the job must be able to:
- PC10. Install and configure SNMP and logging servers; set up network devices as agents.
- PC11. Configure NTP on routers and synchronize time across the network.

Description
Cyber Security Assistant, contribution to projects such as network vulnerability assessments, phishing
awareness simulations, and log monitoring for threat detection. I also supported the development of
cybersecurity policies to strengthen organizational security. These projects enhanced my skills in threat
analysis, incident response, and security awareness.
Scope
The scope covers the following :
The Cyber Security Assistant supports the implementation and monitoring of security measures to
protect computer systems, networks, and data. Their scope includes assisting with threat detection,
vulnerability assessments, incident response, and user awareness activities. They help enforce security policies, manage access controls, and ensure compliance with organizational and regulatory
standards. The role is crucial in maintaining the confidentiality, integrity, and availability of
information systems.
#### Elements and Performance Criteria
Assist in Monitoring Security Systems

- PC1. Monitor system alerts and logs for unusual or unauthorized activity.
- PC2. Report identified threats or anomalies to the security team.
Support Threat Identification and Response
#### To be competent, the user/individual on the job must be able to:
- PC3. Assist in identifying common cyber threats such as phishing, malware, and unauthorized
access.
- PC4. Follow incident response procedures under supervision.
Assist in Conducting Security Assessments
#### To be competent, the user/individual on the job must be able to:
- PC5. Participate in vulnerability scans and basic risk assessments.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Understand basic cybersecurity concepts, common threats (e.g., phishing, malware), and the
importance of data confidentiality, integrity, and availability.
- KU2. Familiar with antivirus software, firewalls, SIEM tools, and basic networking components like
IPs, protocols, and ports.
- KU3. Knowledge of cybersecurity policies, data protection laws (e.g., GDPR), and ethical responsibilities in handling sensitive data.
