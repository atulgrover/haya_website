#### SSC/Q8205: IoT Software Analyst
Brief Job Description
The IoT Software Analyst role, based on the modules you've posted, involves designing, developing,
testing, and maintaining end-to-end IoT solutions. Key activities include working with connectivity
protocols, developing and integrating software at device, platform, and cloud levels, ensuring system
reliability, and testing for functionality and performance. The role also emphasizes automation (CI/CD
pipelines), configuration management, quality assurance through various testing methods (functional, non-
functional, end-to-end), and proper documentation. Skills required include programming , working with IoT
platforms, managing source code, employing DevOps tools, and ensuring system security and compliance.
Overall, the analyst is crucial in enabling seamless, reliable, and secure IoT systems from development to
deployment.
Personal Attributes
IoT Software Analysts must be able to communicate effectively, build relationships with others and
collaborate with various stakeholders. They must have strong analytical abilities and a zeal to learn new
things.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N8218: Design, develop and maintain software across appropriate layers of IoT solutions
2. SSC/N8219: Develop software applications and manage application lifecycle for IoT solutions
3. SSC/N8245: Develop tools, processes and mechanisms for continuous integration and delivery for
IoT solutions
4. SSC/N8224: Develop simulations and manage tests for end-to-end IoT solutions
5. SSC/N8244: Understand functional & non-functional testing of IoT solutions
6. SSC/N8238: Create technical documents and manuals
7. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### SSC/N8218: Design, develop and maintain software across appropriate
layers of IoT solutions
Description
This unit is about designing, developing and maintaining software across the device, connectivity,
platform, server, analytics, application, and presentation layers of the IoT solution.
Scope
The scope covers the following :
Develop device layer
Develop connectivity layer
Develop platform layer
Develop server & application layer
Deploy streaming analytics
Develop presentation layer
Drive continuous monitoring
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. design, develop and maintain real-time operating systems at the device layer
- PC2. design, develop and maintain device software which enables access to device hardware
- PC3. design, develop and maintain device software which enables features such as remote
controlling the device, upgrading its firmware, monitoring its battery level, etc.
- PC4. design, develop and maintain firmware that enables wired/wireless connectivity between the
end device and IoT gateway
- PC5. apply appropriate wired/wireless connectivity protocols for device-device or device-gateway
communications
- PC6. design, develop and maintain IoT device management with Over the Air functionality
- PC7. design, develop and maintain the deployment of analytics packet Over the Air updates on
the devices through the IoT device management platform
- PC8. evaluate IOT Device Management Commercial off-the-shelf platforms
- PC9. design, develop and maintain applications to run on standard IoT platforms
- PC10. design, develop and maintain software which enables IoT platforms to interact with large
numbers of devices and gateways
- PC11. design, develop and maintain a central registry to identify the devices/gateways running in
an IoT solution
- PC12. design, develop and maintain scalable processing solutions with the ability to store and
analyze data
- PC13. design, develop and maintain software applications, libraries, server software and APIs
- PC14. Design and develop analytics solutions for the edge / platform layers

#### SSC/N8219: Develop  software applications and manage application
lifecycle for IoT solutions
Description
This unit is about identifying the requirements for the software application and developing, deploying,
managing, and maintaining it.
Scope
The scope covers the following :
Specify requirements
Develop application
Deploy applications
Use Application Management Services
Drive application maintenance
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. gather requirements for the development of software applications from relevant
stakeholders
- PC2. ensure regulatory and compliance requirements are also identified
- PC3. categorize specifications and prioritize them based on when they must be developed
- PC4. design and develop software applications for the IoT solution
- PC5. continuously verify that the application is in line with the specified requirements
- PC6. identify appropriate methodologies (such as agile, scrum, etc.) to structure, plan, and control
the solution development process
- PC7. develop and run test cases on the application being built
- PC8. plan the deployment model of the application
- PC9. roll out the application when it is ready for release
- PC10. use Application Management Services to provide ongoing application support to external
providers
- PC11. use Application Monitoring Services to delegate the responsibilities of monitoring and
releasing patches, bug-fixes, and enhancements to external vendors
- PC12. monitor and manage deployed application
- PC13. continuously look for and resolve bugs in software application
- PC14. plan for application updates and patches
- PC15. plan for application upgrades
- PC16. plan for the retirement of application and migration to a new application

#### SSC/N8245: Develop  tools, processes and mechanisms for continuous
integration and delivery for IoT solutions
Description
This unit is about developing tools, processes and mechanisms to to assist continuous delivery and
integration of developed solutions.
Scope
The scope covers the following :
deploy production systems, monitor performance
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Map IoT device types communication protocols and deployment scenarios to identify
integration requirements
- PC2. Identify hardware and software dependencies for IoT development and deployment
- PC3. Define goals for CI/CD such as rapid updates secure deployments and scalability
- PC4. Evaluate and select CI CD tools compatible with IoT including version control and
containerization options
- PC5. Integrate IoT-specific testing tools like simulators and hardware-in-the-loop testing into CI
pipelines
- PC6. Develop scripts to automate code compilation firmware image generation and signing
- PC7. Incorporate static code analysis security checks and security scanning into build and
deployment processes
- PC8. Create automated test scripts for unit integration and system testing including hardware-in-
the-loop tests
- PC9. Automate firmware software deployment and use OTA mechanisms for deployment to real
devices
- PC10. Implement phased rollouts with rollback capabilities and integrate monitoring tools for device
health and logs
- PC11. Set up alerts for failures and anomalies and develop feedback loops to improve testing and
code quality
- PC12. Automate configuration management for different environments and maintain consistent
versioning of firmware and software
- PC13. Document CI CD workflows scripts and configurations along with SOPs for failures and
updates
- PC14. Run pilot pipelines on small IoT projects refine processes and plan gradual scaling
- PC15. Collect data analyze results and automate additional testing for broader IoT deployments

#### SSC/N8224: Develop  simulations and manage tests for end-to-end IoT
solutions
Description
This unit is about simulating the IoT solution prior to the development process and performing various
tests across the various layers of the solution.
Scope
The scope covers the following :
Manage simulations
Perform device testing
Perform gateway testing
Perform platform testing
Perform integration testing
Perform end-to-end testing
Carry out test-case automation
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Simulate the IoT solution during development to gain early feedback and support rapid
prototyping and scaling
- PC2. Use simulations to manage end to end testing and ensure interoperability of IoT components
and communications
- PC3. Test device discovery communication processes and performance metrics such as battery
life and signal strength
- PC4. Perform functional and interoperability testing of device firmware and hardware
- PC5. Test communication between devices and cloud services including multi-device and multi-
protocol compliance
- PC6. Conduct remote diagnostics performance and security testing of the entire IoT solution
- PC7. Test IoT platform functionalities including performance load testing and end to end solution
validation for standards compliance
- PC8. Verify interactions within modules and interfaces of the IoT solution to ensure proper
integration and behavior
- PC9. Develop automation suites and infrastructure to execute UI API and device level tests
efficiently
- PC10. Ensure comprehensive testing through automation and perform functional and user
experience assessments of the complete IoT solution
