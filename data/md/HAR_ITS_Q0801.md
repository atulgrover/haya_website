#### HAR/ITS/N0908: IT Foundation and Digital Tools (2)
Description
The NOS provides basic knowledge and skills to operate computer and prepares you to perform basic
office jobs.
Scope
The scope covers the following :
The NOS builds essential skills in Word, Excel, PowerPoint, and Internet usage, preparing students
for basic office tasks and serving as a foundation for advanced computer applications.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Understand the meaning, characteristics, history, generations, and classification of
computers.
- PC2. Identify and explain the main components, input/output devices, and the working of a
computer system.
- PC3. Differentiate between data and information, and perform basic number conversions.
- PC4. Demonstrate understanding of operating systems, including the settings and functions of
Windows..
- PC5. Diagnose and resolve common peripheral malfunctions and connectivity issues.
- PC6. Create and edit documents using word processing tools with proper formatting and layout.
- PC7. Apply formulas and functions in spreadsheets and use spreadsheet tools effectively.
- PC8. Design and present information visually using digital presentation software.
- PC9. Develop correct typing posture and accuracy with improved speed.
- PC10. Utilize networking and internet skills to communicate online, manage email accounts, ensure
cybersecurity, and understand cloud storage
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Demonstrates understanding of the evolution, characteristics, and classification of computers,
including their historical development and technological generations.
- KU2. Identifies and explains the main hardware components, input/output devices, and the overall
functional process of a computer system.
- KU3. Explains the purpose, functions, and configuration of operating systems, particularly Windows,
in managing computer resources and settings.
- KU4. Understands methods for diagnosing and resolving common hardware, peripheral, and connectivity issues within a computer system.

#### Generic Skills (GS)
User/individual on the job needs to know how to:
- GS1. Analyze client requirements and design solutions that meet functional needs.
- GS2. Clearly communicate ideas and requirements to team members and clients.
- GS3. Manage time and priorities to meet project deadlines.

#### HAR/ITS/N0801: Foundations  of Programming  and SQL Database
Management   (OOPs & SQL  Concepts)
Description
The NOS provides basic knowledge and skills about Programming languages and Database Management.
Scope
The scope covers the following :
The NOS provides learners with a strong foundation in programming concepts, database management, and object-oriented programming using SQL, C, C++, and VB.NET.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Explain the fundamentals of databases, DBMS architecture, relational models, and
normalization concepts.
- PC2. Create, manage, and manipulate databases using SQL commands such as DDL, DML, TCL,
DCL, and DQL.
- PC3. Apply SQL concepts including joins, keys, views, subqueries, triggers, and stored procedures
for database operations.
- PC4. Understand programming fundamentals, algorithms, flowcharts, and different programming
paradigms.
- PC5. Write, compile, debug, and execute programs in C language using control statements,
functions, arrays, strings, pointers, structures, and file handling.
- PC6. Develop applications in C++ using constructors, destructors, exception handling, dynamic
memory allocation, and file handling techniques.
- PC7. Understand the .NET Framework architecture and VB.NET programming environment.
- PC8. Create Windows-based applications using VB.NET with forms, controls, event handling, and
exception handling.
- PC9. Establish database connectivity using ADO.NET and perform data retrieval and manipulation
operations.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. The concepts of data, database, DBMS architecture, database models, ER models, and normalization techniques.
- KU2. SQL syntax, commands, joins, views, subqueries, triggers, and stored procedures used in database management.
- KU3. programming fundamentals including algorithms, flowcharts, programming paradigms, and translators.

| Occupation | Occupation is a set of job roles, which perform similar/ related set of functions in an industry. |
| Job role | Job role defines a unique set of functions that together form a unique employment opportunity in an organisation. |
| Occupational Standards (OS) | OS specify the standards of performance an individual must achieve when carrying out a function in the workplace, together with the Knowledge and Understanding (KU) they need to meet that standard consistently. Occupational Standards are applicable both in the Indian and global contexts. |
| Performance Criteria (PC) | Performance Criteria (PC) are statements that together specify the standard of performance required when carrying out a task. |
| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |
| Qualifications Pack (QP) | QP comprises the set of OS, together with the educational, training and other criteria required to perform a job role. A QP is assigned a unique qualifications pack code. |
| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
| Description | Description gives a short summary of the unit content. This would be helpful to anyone searching on a database to verify that this is the appropriate OS they are looking for. |
| Scope | Scope is a set of statements specifying the range of variables that an individual may have to deal with in carrying out the function which have a critical impact on quality of performance required. |
