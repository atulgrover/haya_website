SSC/Q8804: XR Developer
Brief Job Description
Individuals in this job role are responsible for developing software for AR/VR/MR experiences for varied
industrial use cases. They also customize the solution based on the feedback and are responsible for
evaluating and documenting product/software performance reports.They must manage and collaborate
with various stakeholders involved in developing AR/VR solution experiences. They must have a strong
analytical mindset and a zeal to learn new things.
Personal Attributes
XR Developers must be able to communicate effectively, build relationships with others and collaborate
with various stakeholders. They must have a zeal to learn new things.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
- 1. SSC/N8825: Translate design concepts into functional applications while focusing on user
experience, usability, and intuitive interaction methods.
- 2. SSC/N8812: Develop software for a wide range of AR/VR experiences for varied industrial use
cases
- 3. SSC/N8826: Collaborate with designers to integrate 3D models, animations, audio, and other
assets into applications, ensuring they function seamlessly within AR/VR environments.
- 4. DGT/VSQ/N0102: Employability Skills (60 Hours)

SSC/N8825: Translate design concepts into functional applications while
focusing on user experience, usability, and intuitive interaction methods.
Description
This NOS is about translating design concepts into functional applications
Scope
The scope covers the following :
Design Concepts,Focus on user experience,Ensure Usability,Implement Intuitive
Interaction,Technical Tralsation, Iterative Testing and Feedback,Documentation,Final Deployment
and Support
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Understand the design concepts developed during the prototyping phase and ensuring
alignment with user needs and business requirements
PC2. Collaborate closely with UX/UI designers to translate visual designs and interaction
specifications into functional requirements. This may involve discussions about user flows,
interface elements, and intended interactions
PC3. Keep the user's perspective at the forefront of the development process. Ensure that every
feature and interaction is designed to enhance the user experience, making it pleasant and
engaging
PC4. Develop interfaces that are easy to navigate and use. Focus on creating layouts and controls
that follow established usability principles, enabling users to accomplish tasks with minimal
effort
PC5. Implement visual and auditory feedback mechanisms within the application. Users should
receive immediate responses to their interactions, such as highlighting buttons when
hovered over or providing sound cues for actions.
PC6. Utilize interaction methods that feel natural and aligned with human behaviors. In AR/VR
applications, this may include gesture recognition, eye-tracking, voice commands, and
physical movements that mimic users’ real-world actions.
PC7. Select appropriate development frameworks and tools that support the translation of design
concepts into functional applications. For AR/VR, this may involve platforms such as Unity or
Unreal Engine, which provide specific capabilities for creating immersive experiences.
PC8. Translate visual and functional designs into code, focusing on both front-end and back-end
development. This includes creating user interfaces, programming interactions, and
integrating necessary features and functionalities into the application.
PC9. . Implement iterative testing throughout the development process. Usability testing sessions
and user feedback loops should be integrated into the workflow to validate interactions and
ensure that the application meets user expectations.
PC10. Use insights gained from testing to refine and enhance features, usability, and interactivity.
This iterative approach helps create a more effective end product that resonates with users.

SSC/N8812: Develop software for a wide range of AR/VR experiences for
varied industrial use cases
Description
This unit is about developing software solution which encompasses a variety of AR/VR experience that can
be used across industries
Scope
The scope covers the following :
Development, Testing, Bug Fixing, Best practices, Documentation
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Identify the platforms on which the AR/VR application would run
PC2. Identify internal development platforms and end-user devices.
PC3. Gather information on interactive elements and 3D objects to be included in the product
from relevant teams (Design, Architecture, etc.)
PC4. Interact with design and content teams and contribute to the development of 3D assets as
required
PC5. Develop virtualization applications based on AR/VR to visualize the product.
PC6. Develop product-specific features based on functional requirements such as face detection,
tracking, real-time networking for synchronous play, etc.
PC7. Develop apps to support monoscopic or stereoscopic videos as per requirement
PC8. Develop computer vision to implement Custom Object Detection for AR/VR applications
PC9. Develop high-performance graphics using appropriate modes of rendering, render pipelines,
textures
PC10. Optimize 3D models and environment using appropriate techniques and levels of detailing to
ensure smooth performance with good quality imagery
PC11. Ensure proper integration of 3D models, CMS systems, and other existing systems
PC12. Include features for adaptive streaming and transcoding in the product/solution
PC13. Develop audio/ speech interfaces using NLP when required.
PC14. Test the software code for robustness, including corner cases, usability, and general
reliability
PC15. Carry out unit testing of software to ensure desired performance
PC16. Debug the code and fix coding errors
PC17. Apply coding practices such as reusability, continuous integration, continuous delivery,
platform-specific best practices/guidelines, etc
PC18. Create documents, demonstrations, and relevant artefacts for the software code, product
usage, and troubleshooting

SSC/N8826: Collaborate with designers to integrate 3D models,
animations, audio, and other assets into applications, ensuring they
function seamlessly within AR/VR environments.
Description
Collabore with designers to integrate 3D models, animations, audio, and other assets into applications,
ensuring they function seamlessly within AR/VR environments.
Scope
The scope covers the following :
Integration of 3D Models,Animation Integration,Audio Implementation,Asset Management,Interaction
design,Testing for Seamless Functionality
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Collaborate with 3D artists to optimise models for performance in AR/VR environments. This
includes reducing polygon counts, simplifying textures, and ensuring that models are
efficient without sacrificing quality.
PC2. Ensure that the 3D models are in compatible file formats that can be seamlessly imported
into development environments, such as Unity or Unreal Engine. Common formats include
FBX, OBJ, and glTF.
PC3. . Carefully position and scale 3D models within the AR/VR environment. This involves
considering the user’s viewpoint and interactions to create a natural and immersive
experience.
PC4. Coordinate with designers and animators to implement animations effectively. This may
involve setting up animation timelines, ensuring smooth transitions, and defining triggers for
animations based on user interactions.
PC5. Optimize animations to run smoothly in real time within AR/VR applications. This can include
techniques like baking animations or using skeletal animations to ensure fluid motion.
PC6. Work with sound designers to integrate audio elements that enhance the immersive
environment, including background music, sound effects, and spatial audio that responds to
user movements and interactions
PC7. Utilize audio middleware (e.g., FMOD, Wwise) to manage complex audio systems, allowing
for dynamic audio playback that adapts to the user’s actions and the environment's context.
PC8. Conduct thorough testing of audio elements in conjunction with visual assets, ensuring that
soundscapes complement the visual experience and that audio cues provide effective
feedback during user interactions.
PC9. Implement an organized asset management system that keeps all 3D models, animations,
and audio files easily accessible. Use version control systems to manage asset updates and
collaborate effectively
PC10. If using third-party assets or purchasing from asset stores, evaluate their compatibility,
quality, and licensing terms before integration into the project
