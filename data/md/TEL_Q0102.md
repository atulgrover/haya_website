#### TEL/Q0102: Broadband  Technician
Brief Job Description
A Broadband Technician installs, configures, and tests CPE (modems, routers, switches) for broadband
access. The individual ensures seamless connectivity between CPE and end-user devices (CPU, laptop,
tablets, Smart/IP TV) at customer premises and troubleshoots connectivity, cable, and equipment issues in
coordination with the NOC.
Personal Attributes
The individual should have good communication, interpersonal, and teamwork skills, along with a technical
mindset and problem-solving ability. The individual should be customer-focused and able to work under
pressure with practical judgment.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. TEL/N0111: Lay cable/system wiring and install equipment at customer premises
2. TEL/N0112: Configure customer premises equipment and establish broadband connectivity
3. TEL/N0113: Troubleshoot and rectify faults
4. TEL/N9105: Follow sustainable practices in telecom infrastructure installation
5. DGT/VSQ/N0101: Employability Skills (30 Hours)

#### TEL/N0111: Lay cable/system wiring and install equipment at customer
premises
Description
This unit covers the installation of system wiring, and setting up equipment, including Power over Ethernet
(PoE)-supported devices such as IP cameras and VoIP phones, at customer premises.
Scope
The scope covers the following :
Prepare for wiring and equipment installation
Undertake wiring and install system hardware
Install/replace UPS and check domestic power supply
Clean up worksite and complete documentation
#### Elements and Performance Criteria
Prepare for wiring and equipment installation
#### To be competent, the user/individual on the job must be able to:
- PC1. collect work requirements, tools, equipment, and materials required for installation, ensuring
availability of PoE-compatible components
- PC2. visit site/customer premises for installation, assessing feasibility for PoE-supported devices
- PC3. analyze the installation environment and customer requirements to select the correct type of
cables, connectors, and PoE injectors/switches
- PC4. inspect indoor and outdoor cable routes to ensure they are free of electrical hazards and
interference sources
- PC5. verify that the cable running length is within permissible limits to maintain signal continuity
and throughput, considering power transmission for PoE devices
- PC6. ensure the equipment installation location is near a power point, has proper signal coverage,
and supports PoE power budgets
Undertake wiring and install system hardware
#### To be competent, the user/individual on the job must be able to:
- PC7. install structured wiring (interior and exterior) from PoP to customer premises, integrating
PoE network elements as required
- PC8. perform cable splicing and crimping, ensuring proper termination for both standard and PoE-
enabled cables
- PC9. perform neat wiring and clipping within customer premises, adhering to structured cabling
norms
- PC10. use appropriate connectors and terminate cables securely, ensuring PoE-supported devices
receive stable power and data signals
- PC11. perform immediate fault clearance if connectivity or power issues arise during installation
- PC12. test cables and joints for transmission loss and signal strength, re-terminating if loss exceeds
prescribed limits

#### TEL/N0112: Configure customer premises  equipment and establish
broadband  connectivity
Description
This unit covers CPE configuration, service provider gateway and end-user device connectivity, broadband
integration with smart home ecosystems, basic cybersecurity implementation, and customer documentation of configurations and testing.
Scope
The scope covers the following :
Configure CPE
Connect CPE to the service provider gateway and end-user devices
Record configuration settings and testing steps for the customer
#### Elements and Performance Criteria
Configure CPE
#### To be competent, the user/individual on the job must be able to:
- PC1. connect a laptop/PC, smart/IP TV, IoT devices, and other customer devices to the CPE and
establish connectivity
- PC2. access Customer Premises Equipment (CPE) settings using default login credentials and
update them for security
- PC3. configure CPE as per base settings (IP, gateway, mask, NAT, QoS, etc.) and enable IPv6
support
- PC4. set up VPN or Internet Lease Line (ILL) configurations as per customer requirements
- PC5. follow basic cybersecurity settings such as strong password policies, firewalls, and MAC
filtering
Connect CPE to the service provider gateway and end-user devices
#### To be competent, the user/individual on the job must be able to:
- PC6. verify that all cables and connectors are properly plugged in and functional
- PC7. ping the service provider gateway and analyze response time for troubleshooting
- PC8. analyze connectivity test results for latency, throughput, and packet loss parameters
- PC9. configure end-user devices to establish LAN/Wi-Fi connectivity with CPE, including SSID and
security settings
- PC10. ping CPE from the end-user device, analyze the response, and optimize network settings for
stability
- PC11. enable Quality of Service (QoS) settings to prioritize network traffic based on user needs
- PC12. integrate broadband with smart home systems like Amazon Alexa, Google Home, or Apple
HomeKit
Record configuration settings and testing steps for the customer
#### To be competent, the user/individual on the job must be able to:

#### TEL/N0113: Troubleshoot and rectify faults
Description
This unit covers troubleshooting and resolving cable, connector, CPE, and broadband service faults using
traditional and AI-based tools, including remote diagnostics, documentation, and site restoration.
Scope
The scope covers the following :
Troubleshoot and repair cable, connector, and CPE faults
Troubleshoot and restore broadband service
Document work and clean the site
#### Elements and Performance Criteria
Troubleshoot and repair cable, connector, and CPE faults
#### To be competent, the user/individual on the job must be able to:
- PC1. identify the root cause of faults, including No Service, service degradation, and intermittent
connectivity issues
- PC2. use signal level meters, OTDR, or AI-based diagnostic tools to test cabling and identify faults
- PC3. repair or replace faulty connectors and damaged cables using industry-standard tools and
techniques
- PC4. perform re-connectorization/crimping of cable pairs or replace cables to restore connectivity
- PC5. connect CPE to a laptop, CPU, or portable device for diagnostics and troubleshooting
- PC6. access the CPE through an appropriate browser/software application, run diagnostic tests,
and analyze logs
- PC7. install or update CPE access software if required for troubleshooting or configuration
- PC8. reset, reconfigure, or update firmware/software settings on CPE to resolve faults
- PC9. utilize remote configuration and diagnostic tools to identify and troubleshoot faults without
an on-site visit
Troubleshoot and restore broadband service
#### To be competent, the user/individual on the job must be able to:
- PC10. diagnose and repair faults between customer equipment and the optical node using AI-
assisted analysis
- PC11. identify and rectify signal loss, interference, or line attenuation using advanced
measurement tools
- PC12. take readings at splitter points and terminated ends to determine signal integrity and
continuity
- PC13. conduct network troubleshooting, including ping tests, trace routes, and speed tests, using
remote diagnostic tools
- PC14. detect and document system, drop, and in-house signal leakage for resolution
- PC15. assist customers in resolving issues using remote configuration tools and AI-driven
troubleshooting guidance

#### Assessment Guidelines
1. Criteria for assessment for each Qualification Pack will be created by the Sector Skill Council. Each
Element/ Performance Criteria (PC) will be assigned marks proportional to its importance in NOS. SSC will
also lay down proportion of marks for Theory and Skills Practical for each Element/ PC.

3. Assessment will be conducted for all compulsory NOS, and where applicable, on the selected elective/option NOS/set of NOS.
4. Individual assessment agencies will create unique question papers for theory part for each candidate at
each examination/training center (as per assessment criteria below).
5. Individual assessment agencies will create unique evaluations for skill practical for every student at
each examination/ training center based on these criteria.
6. To pass the Qualification Pack assessment, every trainee should score the Recommended Pass %
aggregate for the QP.
7. In case of unsuccessful completion, the trainee may seek reassessment on the Qualification Pack.
