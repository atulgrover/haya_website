NIE/ITS/Q1103: Data Analysis Assistant
Brief Job Description
The Data Analyst Assistant Qualification is meant to inculcate the basic skills of data handling, processing
and visualization. The trained learner will be able to view data in summary and aggregated form, he/she
would able to formulate equation for prediction.
Personal Attributes
hould possess a strong analytical mindset, attention to detail, and problem-solving skills to interpret and
process data effectively. Proficiency in statistical tools, data visualization software, and programming
languages like Python or SQL is essential. Excellent communication skills are necessary to present findings
clearly to stakeholders. Additionally, a keen eye for patterns, logical reasoning, and adaptability to new
technologies are crucial for success in this role. Time management and the ability to work both
independently and collaboratively enhance efficiency in handling complex datasets and delivering
meaningful insights.

NIE/ITS/N1116: Implementation of Data Analysis Assistant Project
Description
The Data Analysis Assistant syllabus covers essential skills required for handling and interpreting data. It
includes topics such as spreadsheet calculations, database management, data analysis with statistical
tools, and data visualization using Tableau. Students will learn fundamental database concepts, SQL, and
open-source tools like Linux. The course also emphasizes employability skills and hands-on project work,
ensuring practical experience in real-world data analytics applications. With a total duration of 300 hours,
this program prepares students for entry-level roles in data analysis by equipping them with technical and
analytical skills.
Scope
The scope covers the following :
The scope includes performing calculations using spreadsheets, managing structured data with
databases, analyzing data using statistical techniques, and utilizing open-source tools like Linux.
Additionally, it covers data visualization using Tableau and implementing real-world data analytics
use cases. Students will develop practical skills in data manipulation, SQL queries, pivot tables,
statistical analysis, and dashboard creation. The project will enhance analytical capabilities and job
readiness through structured technical learning and hands-on applications.
Elements and Performance Criteria
Data Processing and Calculation
To be competent, the user/individual on the job must be able to:
PC1. Apply basic and advanced spreadsheet functions for data manipulation.
PC2. Perform sorting, filtering, and conditional formatting for data structuring.
PC3. Utilize pivot tables and "What-If" analysis for insights.
Database Management
To be competent, the user/individual on the job must be able to:
PC4. Understand database concepts and implement SQL queries for data retrieval
PC5. Ensure data integrity using keys and constraints.
PC6. Perform data migration and aggregation operations.
Statistical Analysis and Data Interpretation
To be competent, the user/individual on the job must be able to:
PC7. Implement statistical techniques, including probability and regression analysis.
PC8. Conduct descriptive analytics for trend identification.
PC9. Utilize statistical models for decision-making.
Open-Source Data Management
To be competent, the user/individual on the job must be able to:
PC10. Work with Linux-based systems for file management and command-line operations.
PC11. Utilize scripting for data handling and automation.

NIE/ITS/N1105: Visualize data graphically
Description
Introduction to Tableau involves understanding its data visualization capabilities and functionalities.
Connecting Tableau to various data sources such as Excel, CSV, and databases allows for seamless data
integration. Analyzing data using Tableau's robust features, including formatting options, sorting
capabilities, and diverse charting tools, enables users to gain valuable insights and present data in a
visually appealing and comprehensive manner.
Scope
The scope covers the following :
The scope encompasses a comprehensive understanding of Tableau, focusing on its data
visualization capabilities and the process of connecting to diverse data sources such as Excel, CSV,
and databases. It includes extensive training in data analysis through Tableau's advanced features,
encompassing formatting techniques, sorting functionalities, and various charting tools, enabling
users to effectively transform complex datasets into insightful visual representations for informed
decision-making and data presentation
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Familiarization with Tableau's interface and its capabilities for data visualization and analysis.
Learning the process of linking Tableau to Excel and CSV files for seamless data integration
and analysis
PC2. Understanding how to establish connections between Tableau and various databases to
access and analyze data directly from these sources, Exploring Tableau's data analysis tools
and functionalities for dissecting and understanding complex datasets
PC3. Mastering formatting techniques within Tableau to enhance the visual appeal of data
visualizations and dashboards. Understanding the sorting capabilities in Tableau to arrange
data in a meaningful and logical order for effective analysis. Utilizing Tableau's diverse
charting tools to create various types of visual representations, including bar charts, line
graphs, and pie charts, for comprehensive data presentation.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Introduction to Tableau and Connecting to Excel, CSV Text Files
KU2. Connecting to Databases and its analysis
KU3. Formatting, Sorting and Charts
