SSC/Q8101: AI Data Quality Analyst
Brief Job Description
Data Quality analyst qualification is designed to equip individuals with the knowledge and practical
expertise to manage, ensure, and improve the quality, security, and integrity of organisational data. This
qualification covers the end-to-end data management lifecycle including sourcing, validation,
transformation, monitoring, security, and governance using industry best practices, tools, and frameworks.
It prepares learners to establish data standards, implement automated workflows, conduct audits, and
foster a culture of data ownership, compliance, and continuous improvement across the organisation.
Personal Attributes
A data quality analyst needs to have good analytical skills, attention to detail and problem solving ability.
S/he needs to have good communication skills to work with stakeholders across multiple teams such as
data science, product development, etc.
Applicable National Occupational Standards (NOS)

SSC/N8101: Extract or Import data as per requirement
Description
This unit is about using a variety of techniques to import data into datasets or data frames.
Scope
The scope covers the following :
Identify Data Requirements,Develop a Data Collection Strategy,Set Up Data Import Mechanisms
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Determine what data is needed based on business goals and analytical needs
PC2. Identify potential internal and external sources such as databases, APIs, web services,
spreadsheets, and third-party vendors.
PC3. Evaluate the accessibility, reliability, and quality of each source
PC4. Decide how often data needs to be collected (real-time, hourly, daily, etc.).
PC5. Choose appropriate methods for data retrieval, including API calls, data feeds, and file
transfers.
PC6. Opt for ETL (Extract, Transform, Load) tools or data integration platforms suited to the
business needs
PC7. Create workflows for automating data extraction, transformation, and loading into target
systems.
PC8. Establish secure and reliable connections to each data source.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Understanding data governance policies procedures and guidelines and knowing how to
access information from data sources
KU2. Familiarity with organizational policies for sharing and documenting data governance
processes and involving the right stakeholders
KU3. Knowledge of different database types data modeling SQL skills and database management
system platforms
KU4. Skills in ETL processes performance tuning access control backup and recovery and database
monitoring and maintenance
KU5. Insights into scalability practices data integrity documentation collaboration and continuous
learning for effective database management
Generic Skills (GS)

SSC/N8102: Process the data
Description
This unit is about using a variety of techniques to process data i.e. clean and transform the data
Scope
The scope covers the following :
Data Preparation & standardization,Data Loading and Integration,Monitoring and Maintenance
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Apply transformations to clean and harmonize data into a uniform format before import
PC2. Define data schemas and structures that align with organizational databases.
PC3. Set basic validation checks during import to ensure data quality (e.g., format checks, range
checks).
PC4. Transfer processed data into data warehouses, databases, or other storage solutions.
PC5. For real-time needs, implement streaming data solutions where applicable
PC6. Ensure new data is merged seamlessly with existing datasets to provide a consistent view.
PC7. Set up alerts and monitoring to catch issues in the data import process quickly.
PC8. Regularly assess import processes to identify bottlenecks or errors, and resolve them
promptly.
PC9. Maintain comprehensive documentation of data collection strategies, source configurations,
and process workflows for easy reference and modification.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Understanding of organizational guidelines for data accuracy, consistency, security, and
compliance when processing and importing data.
KU2. Knowledge of internal data warehouses, databases, and storage systems where processed
data must be integrated or loaded.
KU3. Familiarity with business-defined schemas, master data definitions, and data relationships to
ensure correct data harmonization and merging.
KU4. Awareness of how data engineers, analysts, IT teams, and data stewards collaborate in data
transformation, validation, monitoring, and documentation.
KU5. Understanding organizational procedures for updating import workflows, handling data
pipeline failures, version control, and documentation standards.
KU6. Knowledge of methods like normalization, standardization, deduplication, handling missing
values, and unifying data formats before import.

SSC/N8163: Ensure organizational quality standards are achieved
regarding data
Description
This unit is about ensuring organizational quality standards regarding data
Scope
The scope covers the following :
Define Data Quality Standards,Develop Quality Assurance Processes,Establish Monitoring
Mechanisms,Conduct Regular Audits and Reviews,Conduct Regular Audits and Reviews,Prioritize
Continuous Improvement,Foster Collaborative Culture,Documentation
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Establish clear criteria for data quality dimensions like accuracy, completeness, consistency,
timeliness, validity, and relevancy
PC2. Determine acceptable thresholds and benchmarks for each quality dimension, tailored to the
organization's specific needs and objectives.
PC3. Create processes and controls to regularly assess data against the defined standards. This
can include automated scripts, manual reviews, and cross-verification with trusted sources.
PC4. Encode business logic and rules to validate incoming data, ensuring it meets necessary
criteria before entering critical systems
PC5. Use data quality tools to automate monitoring and alerts for data anomalies, deviations, or
breaches in quality standards.
PC6. Implement dashboards that provide visual indicators of data quality metrics in real time,
enabling quick detection and response to issues.
PC7. Schedule regular audits to thoroughly review datasets and validate that they comply with
quality standards.
PC8. Perform gap analysis to identify discrepancies between current data quality and desired
standards, providing a foundation for improvements.
PC9. Establish feedback loops with end-users and stakeholders to gather insights on data quality
issues and suggestions for enhancement.
PC10. Use findings from audits and monitoring to refine quality assurance processes continuously,
adapting to the evolving needs of the business.
PC11. Work closely with IT, data science, and business teams to ensure a unified approach to data
quality.
PC12. Provide training for staff on data quality principles and their importance, fostering a culture
of quality throughout the organization.
PC13. Maintain detailed records of data quality standards, processes, checks, and incidents to
enhance transparency and guide future initiatives.

Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Understanding of organizational rules, regulatory requirements, and governance policies
related to data accuracy, privacy, integrity, and audit readiness.
KU2. Awareness of the organizations strategic goals, KPIs, and how data quality impacts decision-
making, operations, and customer outcomes.
KU3. Knowledge of designated data owners, stewards, cross-functional teams, and escalation
paths responsible for maintaining and enforcing data quality standards.
KU4. Familiarity with the databases, data pipelines, applications, data warehouses, and analytics
platforms where data quality checks must be applied.
KU5. Understanding of internal procedures for documenting standards, updating business rules,
implementing corrective measures, and conducting periodic reviews.
KU6. Knowledge of accuracy, completeness, consistency, timeliness, validity, and relevancy, and
how to define thresholds and quantify these metrics.
KU7. Understanding how to design, encode, and apply validation rules, business logic, cross-
verification checks, and data profiling methods.
KU8. Familiarity with tools such as Talend DQ, Informatica DQ, Ataccama, Great Expectations, and
monitoring systems for anomaly detection, scoring, and alerts.
KU9. Knowledge of BI tools (Power BI, Tableau, Looker) used to build visual indicators for real-time
quality monitoring and issue detection.
KU10. Understanding of how to perform data audits, conduct gap analyses, monitor pipelines,
review logs, track incidents, and refine quality processes.
Generic Skills (GS)
User/individual on the job needs to know how to:
GS1. Ability to assess data discrepancies, identify root causes, evaluate quality gaps, and apply
logical problem-solving for continuous improvement.
GS2. Capability to work with IT, business users, data science teams, and stakeholders, while clearly
communicating quality issues, standards, and required corrective actions.
GS3. Skill in creating detailed records of standards, checks, processes, and incidents while
maintaining accuracy and precision across all quality activities.

SSC/N8164: Application of new and emrging tools
Description
This NOS about the application of new and emerging tools in AI
Scope
The scope covers the following :
Research and Identify Emerging Tools and Technologies,Evaluate and Select Appropriate
Tools,Implement and Integrate New Tools,Automate Data Quality Processes Using Advanced
Tools,Automate Data Quality Processes Using Advanced Tools,Train and Support Team
Members,Monitor the Performance and Effectiveness of Tools,Document Tool Implementation and
Usage,Facilitate Continuous Improvement and Innovation,Collaborate with Cross-Functional
Teams,Document Tool Implementation and Usage
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Stay informed of the latest trends and developments in data quality tools, software, and
technologies
PC2. Analyze emerging tools for their applicability to the organization’s data quality needs
PC3. Conduct pilot testing to determine tool effectiveness and integration capabilities
PC4. Make recommendations based on cost, efficiency, scalability, and user-friendliness
PC5. Work with IT teams to implement selected tools, ensuring smooth integration with existing
data architectures.
PC6. Develop custom scripts or configurations if needed to enhance tool performance.
PC7. Use AI and machine learning technologies to automate routine data quality tasks, such as
data cleansing and anomaly detection.
PC8. Set up automated workflows and alerts to monitor data quality in real-time.
PC9. Provide training sessions and resources to team members on using new tools effectively
PC10. Develop user guides and documentation to assist in tool usage and troubleshooting
PC11. Regularly assess the performance of implemented tools through key performance indicators
(KPIs) and metrics
PC12. Adjust configurations and processes based on feedback and ongoing evaluation results.
PC13. Encourage a culture of experimentation and innovation within the data quality team.
PC14. Collect feedback from users to identify opportunities for enhancement and tool optimization.
