#### SSC/Q8107: AI Data Architecture Analyst
Brief Job Description
The AI Data Architecture analyst qualification equips professionals with the essential skills to design,
implement, and maintain data architectures that align with organizational goals. Participants will learn to
assess business requirements, select appropriate technologies, and manage storage solutions while
ensuring compliance with data governance and security standards. The curriculum covers key areas such
as data quality assurance, performance optimization, and the implementation of security protocols. Upon
completion, individuals will be adept at analyzing existing systems, innovating data integration solutions,
and contributing to effective data management strategies, ultimately enabling organizations to leverage
their data as a strategic asset for business success.
Personal Attributes
A data architect needs to be well organized with excellent critical thinking and decision making abilities.
S/he needs to have superior team management and communication skills to work with customers and
decision makers across multiple teams.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N8109: Design and maintain data architectures as per specifications
2. SSC/N8111: Implement data storage network solutions
3. SSC/N8119: Ensure data quality and data governance processes and structures are in place
4. SSC/N8158: Follow data security best practices and risk management
5. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### SSC/N8109: Design  and maintain data architectures as per specifications
Description
This unit is about designing new data architectures for internal and external clients.
Scope
The scope covers the following :
Define requirements
Design data storage, formats and integrations
Monitor performance
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Define and document business and technical requirements for data architecture ensuring
alignment with organizational goals and stakeholder needs
- PC2. Review and analyze various data architectures capabilities limitations and evaluate potential
evolution of the data technology stack
- PC3. Formulate strategies and select the best technologies to implement data architectures
considering security standards governance and compliance requirements
- PC4. Design data architecture that integrates data from various sources stages data for
processing determines appropriate data formats and defines data segmentations
- PC5. Develop reliable and scalable data pipelines and integrations continuously monitor
performance metrics troubleshoot issues and optimize data storage and retrieval processes
- PC6. Stage data loading approaches for batch and real-time applications and adapt architecture
based on performance scalability and evolving governance standards
- PC7. Maintain comprehensive documentation of data architecture processes standards and
updates and share with relevant stakeholders for transparency and future reference
- PC8. Incorporate Agile methodologies to support iterative development and continuous
improvement in data architecture design and maintenance
- PC9. Proactively monitor governance and compliance requirements ensuring data architecture
aligns with regulatory standards and environmental changes
- PC10. Collaborate with stakeholders to understand their needs and ensure data architecture
effectively supports organizational functions and strategic objectives
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Follow organizational policies and use templates to design and document data architectures
with stakeholder input
- KU2. Understand business needs and technical requirements including data formats storage security and compliance to build strong data solutions

#### SSC/N8111: Implement  data storage network solutions
Description
This unit is about designing, implementing and maintaining a multi-vendor data storage network solution
for internal and external clients.
Scope
The scope covers the following :
Design storage network solution
Monitor performance
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Evaluate storage design considerations for the data architecture
- PC2. Describe assessment goals and methodology of storage networks
- PC3. Setup the storage network for the desired architecture
- PC4. Create documentation on storage networks for appropriate people
- PC5. Validate storage networks with appropriate people
- PC6. Monitor system storage performance and recommend suitable improvements
- PC7. Perform regular port and throughput exercises
- PC8. Resolve data storage network issues
- PC9. Analyze data access patterns to optimize storage performance and determine the most
effective configuration for data retrieval
- PC10. Implement data redundancy and backup strategies to ensure data availability and disaster
recovery
- PC11. Integrate security measures within the storage network architecture
- PC12. Perform capacity planning to estimate future storage needs based on usage trends and
projected data growth
- PC13. Research and evaluate emerging storage technologies and solutions to recommend
innovative approaches that align with organizational goals
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Follow organizational policies to design document and implement storage network solutions with stakeholder input and standard tools
- KU2. Learn about different storage systems like SAN NAS and SAS and manage storage while following security and privacy standards
- KU3. Use cloud platforms to support storage solutions and consider how they affect system performance

#### SSC/N8119: Ensure  data quality and data governance processes and
structures are in place
Description
This unit is about defining data utilization and governance processes for the team or organization.
Scope
The scope covers the following :
Define data assets
Define data utilization and governance strategies
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Work with stakeholders to identify data quality criteria like accuracy and completeness and
document benchmarks to measure quality
- PC2. Analyze data to understand its characteristics and create processes to clean duplicates and
fix formatting errors
- PC3. Standardize data formats such as dates and text and set validation rules to ensure data is
correct and consistent
- PC4. Use scripts to automatically check data during ETL processes detect errors and set up alerts
for issues
- PC5. Improve data quality by adding external data sources while ensuring accuracy and standard
practices are followed
- PC6. Investigate the causes of data issues and set up ongoing monitoring with reports and
dashboards to track quality trends
- PC7. Collect feedback from data users about quality issues and update processes and
documentation regularly
- PC8. Create regular data quality reports for stakeholders and stay current with best practices and
tools in data quality management
- PC9. Establish a data governance framework with roles and policies to manage data classification
access and responsibilities
- PC10. Implement security measures like encryption and access controls and review logs to ensure
compliance and respond to incidents
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Understand organizational policies for defining data governance processes sharing and documenting data standards and knowing involved stakeholders
- KU2. Learn how to identify and access internal and external data assets to meet business requirements

- KU1. Follow organizational policies and standards for data governance to ensure proper data management and security across all data sources and sharing processes
- KU2. Identify and classify data assets to understand potential risks and implement appropriate access controls and security measures
- KU3. Develop and enforce data utilization standards and procedures that protect data integrity and
prevent unauthorized access or sharing

### Page 33

| Sector | Sector is a conglomeration of different business operations having similar business and interests. It may also be defined as a distinct subset of the economy whose components share similar characteristics and interests. |
| --- | :---: |
| Sub-sector | Sub-sector is derived from a further breakdown based on the characteristics and interests of its components. |
| Occupation | Occupation is a set of job roles, which perform similar/ related set of functions in an industry. |
| Job role | Job role defines a unique set of functions that together form a unique employment opportunity in an organisation. |
| Occupational Standards (OS) | OS specify the standards of performance an individual must achieve when carrying out a function in the workplace, together with the Knowledge and Understanding (KU) they need to meet that standard consistently. Occupational Standards are applicable both in the Indian and global contexts. |
| Performance Criteria (PC) | Performance Criteria (PC) are statements that together specify the standard of performance required when carrying out a task. |
| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |
| Qualifications Pack (QP) | QP comprises the set of OS, together with the educational, training and other criteria required to perform a job role. A QP is assigned a unique qualifications pack code. |
| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
| Description | Description gives a short summary of the unit content. This would be helpful to anyone searching on a database to verify that this is the appropriate OS they are looking for. |
| Scope | Scope is a set of statements specifying the range of variables that an individual may have to deal with in carrying out the function which have a critical impact on quality of performance required. |
