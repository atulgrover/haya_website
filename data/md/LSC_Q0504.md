#### LSC/Q0504: Transportation Data Analyst
Brief Job Description
The individual is responsible for working on the transportation monitoring, reporting, data analysis and
bring business insights into the processes ensuring the transportation improves on a continuous basis.
Personal Attributes
The individual should have excellent communication skills, analytical skills and professional values. The
person should have the ability to think critically and analytically to resolve problems. He/she needs to
posses decision making skills to aid the management.

#### LSC/N0515: Data Collection and Analysis for Transportation
Description
This unit is about collecting, cleaning, organizing, and analysing large volumes of data from various
sources.
Scope
The scope covers the following :
Data collection for transportation network
Sanity of data and basic validations
Organizing and analysing the data
#### Elements and Performance Criteria
Data collection for transportation network
#### To be competent, the user/individual on the job must be able to:
- PC1. Collect information on traffic flow data which includes traffic volume, traffic speed and traffic
density
- PC2. Obtain information on vehicle location data, vehicle speed and acceleration using GPS data
- PC3. Obtain information on road condition data along with weather condition
- PC4. Obtain information on road surface quality
- PC5. Collect population data which can help in understanding transportation demand
- PC6. Collect data on the types of vehicles required on the network, including size and fuel type
- PC7. Obtain information on vehicle emissions for environmental impact assessments
- PC8. Obtain information on historical data to analyze trends, seasonality, and historical
performance
Sanity of data and basic validations
#### To be competent, the user/individual on the job must be able to:
- PC9. Process the data in system tools to validate the count of records against the manually
collected data
- PC10. Process the data in system tools to check for duplicate records
Organizing and analysing the data
#### To be competent, the user/individual on the job must be able to:
- PC11. Organize the data collected from different sources in separate files/folders
- PC12. Analyse the data to validate if the count of several data matches with physical data
- PC13. Prepare flow charts to represent data and analyse any missing entity

#### LSC/N0516: Performance  Monitoring in Transportation
Description
This unit is about tracking and monitoring key performance indicators (KPIs) related to transportation
operations, such as route optimization, vehicle availability, finding the cost effective carrier and levels,
order fulfilment, cycle times, and optimum load factor.
Scope
The scope covers the following :
Establishing the KPI
Transportation Carrier Performance
Transportation Vehicle Availability and Fuel Efficiency
Transportation Load Factor
Transportation Route Optimization
#### Elements and Performance Criteria
Establishing the KPI
#### To be competent, the user/individual on the job must be able to:
- PC1. Collaborate with stakeholders, including Transportation planner, operations teams, and
senior leadership, to define and establish relevant KPIs for optimum performance
- PC2. Monitor KPIs regularly, track performance against targets, and identify areas of improvement
or concern
Transportation Carrier Performance
#### To be competent, the user/individual on the job must be able to:
- PC3. Measure the on time delivery of carriers delivering the loads
- PC4. Measure the average time it takes for loads to travel from the point of origin to its
destination
- PC5. Maintain record of loading and unloading time for carrier at the dock doors
- PC6. Calculate and measure the cost of delivery by the carrier
Transportation Vehicle Availability and Fuel Efficiency
#### To be competent, the user/individual on the job must be able to:
- PC7. Calculate comparison of scheduled vehicle service times to actual departure and arrival
times
- PC8. Measure downtime of vehicle which is out of service
- PC9. Calculate the percentage of scheduled trips or routes that are completed without
cancellations or significant delays
- PC10. Record the percentage of reserve or backup vehicles available in case of unexpected vehicle
breakdowns
- PC11. Measure amount of fuel consumed per unit of distance travelled (e.g. miles per gallon or
liters per kilometer)
- PC12. Record regular maintenance practices that ensure vehicles are operating at peak efficiency

#### LSC/N0517: Transportation Tool Analysis
Description
This unit is about conducting technical tool analysis which involves evaluating and selecting appropriate
tools and technologies to manage and analyse data within the transportation network efficiently and
effectively.
Scope
The scope covers the following :
Technical Tool Selection and Uses
#### Elements and Performance Criteria
Technical Tool Selection and Uses
#### To be competent, the user/individual on the job must be able to:
- PC1. Conduct research to identify relevant data analytics, data warehousing and data
management tools available in the market.
- PC2. Evaluate tools features, capabilities, and suitability for the transportation network
requirements.
- PC3. Assess the strengths and weaknesses of different tools and technologies after considering
technical factors such as scalability, performance, ease of use, integration capabilities, and compatibility with existing systems.
- PC4. Prepare a report with SWOT analysis of each of the shortlisted tools. Present the report to
stakeholders and conduct meeting to finalize the tool after considering the organization's budget, long-term data requirements, and the skillset of the data team.
- PC5. Evaluate ETL tools that facilitate data extraction, transformation, and loading processes to
ensure that data is prepared and made available for analysis.
- PC6. Evaluate statistical analysis software that can be used to perform advanced analytics and
predictive modelling on transportation data.
- PC7. Investigate business intelligence tools that enable ad-hoc querying, reporting, and data
exploration for better decision-making.
- PC8. Ensure that the selected tools comply with data security and governance requirements,
especially when dealing with sensitive or confidential data.
- PC9. Evaluate how well the chosen tools can integrate with the organization's existing IT
infrastructure and data management systems.
- PC10. Conduct testing and proof of concept projects to validate the effectiveness and compatibility
of the selected tools in the transportation network.
- PC11. Coordinate training sessions for the data team to ensure they can effectively use the chosen
tools for their data analysis tasks.
- PC12. Ensure effective transition of tools to the vendor and responsible stakeholders.

#### LSC/N0518: Reporting and Visualization in Logistics Vertical
Description
This unit is about reports, dashboards, and visual representations of data to present insights and trends to
stakeholders, management, and cross-functional teams.
Scope
The scope covers the following :
Designing and Developing Reports, Dashboard and Visual Representations
#### Elements and Performance Criteria
Designing and Developing Reports, Dashboard and Visual Representations
#### To be competent, the user/individual on the job must be able to:
- PC1. Collect the requirement about Reports from Business users after discussing the different
processes like shipment tracking, On time performance, fuel and energy consumption.
- PC2. Perform As-Is analysis of the existing reports.
- PC3. Perform Fit-Gap analysis on how to enhance existing reports (if any) to fulfil the business
needs.
- PC4. Prepare Business Requirement Document (BRD) for new reports.
- PC5. Prepare a design document for each of new reports.
- PC6. Prepare design document which shall consist of Report Layout, Dashboard Requirement,
Visual Representations, data requirements.
- PC7. Provide guidance to developer to prepare technical design document. Finalize the data set
required to present the data in Reports.
- PC8. Perform unit test of reports, dashboards.
- PC9. Work with Business users to perform user acceptance test for reports.
- PC10. Deploy the reports for business end users.

| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |

| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
| Description | Description gives a short summary of the unit content. This would be helpful to anyone searching on a database to verify that this is the appropriate OS they are looking for. |
| Scope | Scope is a set of statements specifying the range of variables that an individual may have to deal with in carrying out the function which have a critical impact on quality of performance required. |
