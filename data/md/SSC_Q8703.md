#### SSC/Q8703: Blockchain Full Stack Developer
Brief Job Description
Individuals at this job are responsible for developing the core blockchain. They will be responsible for
developing tools, processes, and mechanisms for defining and developing the core blockchain. They will be
responsible for defining and documenting technical specifications pertaining to the blockchain solution,
including client, consensus algorithm, distributed data management, ledger maintenance, participant
incentivization, smart contract/ chain code, and tokenomics.
Personal Attributes
Individuals in this job role must possess strong coordination and communication skills to collaborate with
various stakeholders. They must also have a commitment to professional excellence and keep themselves
abreast of the latest developments related to their field of work.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N8738: Set up development environment for blockchain solution development
2. SSC/N8739: Develop backend services and frontend interfaces for the dApp, integrating all components.
3. SSC/N8740: Conduct comprehensive testing of the blockchain solution
4. SSC/N8741: Monitor the performance of blockchain applications and networks
5. SSC/N8728: Provide support in resolving issues related to blockchain apps

#### SSC/N8738: Set up development  environment  for blockchain solution
development
Description
This NOS is about setting up the development environment for blockchain solution development
Scope
The scope covers the following :
Set up development environment and implement smart contracts
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Install Node.js and npm (Node Package Manager),these are essential for most blockchain
development tools.
- PC2. Choose an Integrated Development Environment (IDE) for example Visual Studio Code with
Solidity extensions
- PC3. Install Framework (for example truffle framework for ethereum)
- PC4. Set up a local blockchain for development and testing
- PC5. Install browser extension for wallets (eg metamask) to interact with the blockchain networks
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Familiarity with the core principles of blockchain, including decentralization, immutability,
consensus mechanisms, and cryptographic security
- KU2. Knowledge of different types of blockchains (public, private, consortium, hybrid) and their use
cases.
- KU3. Knowledge of programing languages like solidity for example ethereum smart contract development
- KU4. Knowledge of development frameworks like truffle/Hardhat
- KU5. Familiarity with tools like Mocha and Chai for contract testing
- KU6. Knowledge of tools for running a local blockchain for development and testing
- KU7. Knowledge of wallets to interacts with the blockchain networks
- KU8. Familiarity with Proof of Work, Proof of Stake, etc.
- KU9. Knowledge of version control system like githib

#### SSC/N8740: Conduct  comprehensive  testing of the blockchain solution
Description
Conducting testing of a blockchain solution involves a systematic approach to ensure that the application
functions correctly, securely, and efficiently
Scope
The scope covers the following :
Define Test Objectives
Test Planning
Conduct different type of testing
Monitoring and reporting
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Establish clear objectives for testing, such as verifying functionality, ensuring security, and
assessing performance under various conditions.
- PC2. Gather requirements from stakeholders to understand what needs to be tested, including
specific functionalities and performance metrics.
- PC3. Create detailed test cases covering all aspects of the application based on functional
requirements.
- PC4. Prepare a suitable testing environment that mimics production conditions as closely as
possible
- PC5. Check if the tests can be automated to improve efficiency and coverage.
- PC6. Conduct functional testing to check transaction processing, smart contract execution, and
adherence to consensus mechanisms.
- PC7. Conduct integretion testing to ensure that different components of the blockchain application
(e.g., smart contracts, APIs) interact correctly.
- PC8. Conduct performance testing to Assess the speed and efficiency of the blockchain network
- PC9. Conduct security testing to identify vulnerabilities within the blockchain application.
- PC10. Conduct Smart contracts testing to look for logical errors, proper execution paths, and
potential security issues like reentrancy attacks or overflow errors
- PC11. Conduct API testing to ensure that the APIs used for integrating with other software function
correctly and securely
- PC12. Record outcomes of each test case, including any failures or issues encountered.
- PC13. Review results to identify patterns or recurring issues that need addressing.

The individual on the job needs to know and understand:

#### SSC/N8741: Monitor the performance  of blockchain applications and
networks
Description
Performance optimization in blockchain development is crucial for enhancing transaction speed, scalability, and overall efficiency
Scope
The scope covers the following :
Implement Layer 2 Solutions
Hardware Optimization
Network Optimization
Performance Testing and Simulation
Node level testing
Smart Contract and DApp Performance
Continuous Monitoring and Iteration
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Select appropriate consensus mechanism for optimizing transaction speed and energy
consumption
- PC2. Alleviate congestion on the main blockchain,by applying layer 2 solutions such as the
Lightning Network etc. to be processed off-chain
- PC3. Partition the blockchain into smaller segments (shards), enabling parallel processing of
transactions
- PC4. Ensure that nodes use solid-state drives (SSDs) for faster data access compared to
traditional hard disk drives (HDDs)
- PC5. Use CPUs with high clock speeds for better single-threaded performance, as blockchain
nodes often benefit from fast processing capabilities rather than a high number of core
- PC6. Optimize peer-to-peer (P2P) network topology to enhance communication between nodes
- PC7. Implement selective verification strategies in consensus protocols to reduce communication
overhead and improve transaction validation efficiency
- PC8. Conduct performance testing using tools like Hyperledger Caliper to measure key metrics
such as throughput and latency under various conditions
- PC9. Use simulations to evaluate how changes in network configuration affect performance
metrics, allowing for informed decisions regarding optimization strategies
- PC10. Assess the resource utilization (CPU, memory, disk I/O) of blockchain nodes
- PC11. Configure node exporters for collecting performance metrics & develop node performance
dashboards
- PC12. Optimize smart contracts for gas efficiency
