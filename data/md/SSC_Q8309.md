#### SSC/Q8309: Cloud Security Analyst
Brief Job Description
A Cloud Security Analyst ensures that cloud operations align with organizational policies, regulatory
requirements, and industry standards. The individual assesses cloud security risks, defines and monitors
security controls, conducts audits, coordinates incident response, and tracks compliance through defined
KPIs. The person supports secure and compliant cloud adoption across the organization.
Personal Attributes
Cloud Security Analyst must be able to communicate effectively, build relationships with others and
collaborate with various stakeholders. He/she must have a zeal to learn new things.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N8333: Define, monitor and manage cloud security safeguards and policies in the organization
2. SSC/N8326: Audit IT and cloud assets and identify KPIs to monitor implementation of governance
standards
3. SSC/N8335: Coordinate response to cloud security incidents and ensure restoration of affected
systems
4. SSC/N8336: Ensure compliance with legal, regulatory, and certification standards applicable to
cloud systems
5. SSC/N8332: Develop an organizational understanding to manage cloud security risks
6. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### SSC/N8333: Define, monitor and manage  cloud security safeguards and
policies in the organization
Description
This unit is about evaluating the organizations security posture, detecting and responding to security
anomalies, and managing cloud-related security safeguards and policies to ensure compliance with
applicable standards and minimize risk
Scope
The scope covers the following :
Conduct preliminary security analysis
Define cloud-related security policies and safeguards
Monitor security threats and anomalies
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. create and maintain reports on actual or potential cloud security threats and incidents
- PC2. analyze the shared cloud security model based on service provider type and deployment
architecture
- PC3. identify and configure automated tools to perform routine security assessments of cloud
systems
- PC4. evaluate the likelihood and potential impact of anomalies identified through security
monitoring
- PC5. apply security controls in line with established policies to detect unauthorized or unusual
activity
- PC6. define organizational responsibilities for securing cloud infrastructure and applications
- PC7. formulate and document policies for access control, encryption, and threat mitigation
- PC8. select and implement cloud-specific security standards (e.g., ISO/IEC 27017, 27018) relevant
to the organization
- PC9. establish and maintain governance processes for the enforcement of cloud security
measures
- PC10. integrate applicable data protection and privacy regulations into cloud security policies
- PC11. evaluate and revise existing security guidelines based on threat landscape changes and
audit findings
- PC12. develop and maintain security checklists, runbooks, and playbooks to guide consistent
operational response
- PC13. monitor systems using security tools to ensure continuous compliance with defined security
policies and standards
- PC14. monitor and analyze cloud environment for emerging threats, anomalies, or incidents
- PC15. develop and apply Key Performance Indicators (KPIs) to assess the effectiveness of cloud
security measure

#### SSC/N8326: Audit IT and cloud assets and identify KPIs to monitor
implementation of governance standards
Description
This unit is about auditing IT and cloud asset to ensure adherence to governance rules and defining
metrics to measure compliance with governance rules.
Scope
The scope covers the following :
Audit the organizations IT and cloud assets
Implement and monitor governance standards
Set governance targets and optimize assets
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. create, maintain, and update a checklist of IT and cloud assets targeted for audit
- PC2. liaise with relevant stakeholders to collect data and information required for audits
- PC3. conduct audits using approved tools, templates, and checklists in accordance with defined
procedures
- PC4. document audit findings, including detected security anomalies or vulnerabilities, and share
with appropriate stakeholders
- PC5. maintain updated records of IT and cloud assets, their configurations, and audit status
- PC6. identify the need for a security audit based on prior incidents, threat patterns, or risk
indicators
- PC7. collect and analyze cloud infrastructure data to verify adherence to compliance and security
best practices
- PC8. evaluate system configurations and flag deviations from regulatory requirements or
organizational standards
- PC9. apply relevant governance and security standards during the audit process to assess
compliance
- PC10. define and track Key Performance Indicators (KPIs) to monitor the effectiveness of
governance and security control implementation
- PC11. use monitoring tools and techniques to assess real-time compliance and detect deviations
- PC12. use AI-enabled audit tools to detect patterns of non-compliance or configuration drift
- PC13. identify and deploy compatible automated tools for continuous compliance monitoring
- PC14. analyze audit logs using ML algorithms to uncover recurring security gaps or compliance
issues
- PC15. provide timely feedback on detected compliance risks and misconfigurations to support
corrective action
- PC16. support internal initiatives to strengthen regulatory compliance and enforce policy
adherence

#### SSC/N8335: Coordinate response  to cloud security incidents and ensure
restoration of affected systems
Description
This unit is about responding to cloud security incidents, preventing further risk propagation, ensuring
compliance with organizational security policies, and restoring affected systems in a timely and structured
manner
Scope
The scope covers the following :
Coordinate incident response activities and ensure policy alignment
Escalate and report security incidents
Restore affected cloud systems and update response documentation
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. develop and execute response strategies for detected security incidents in line with
compliance requirements and organizational policies
- PC2. implement automated or predefined incident response workflows to contain and mitigate
active threats
- PC3. validate that incident response activities align with approved security standards, procedures,
and runbooks
- PC4. integrate AI-powered SOAR tools to automate incident triage and response workflows
- PC5. use ML models to recommend response actions based on incident classification and past
remediation patterns
- PC6. review and periodically update incident response documentation, including playbooks and
checklists, based on recent incidents and audits
- PC7. assign and escalate information security incidents to designated personnel or teams based
on severity and SLA guidelines
- PC8. track incident resolution progress, escalate delays or failures, and ensure response timelines
are met
- PC9. engage relevant internal stakeholders and external vendors to collect and verify incident-
related data
- PC10. coordinate with management to prepare reports for regulatory bodies or law enforcement, if
required
- PC11. prepare and submit comprehensive incident reports using approved tools and reporting
frameworks
- PC12. implement containment and isolation measures to prevent escalation of the security incident
- PC13. oversee recovery activities and ensure the timely restoration of affected cloud services,
configurations, and data

standards applicable to cloud systems
Description
This unit is about identifying and adopting appropriate compliance and regulatory standards to secure
deployed systems.
Scope
The scope covers the following :
Conduct business analysis
Implement and monitor regulatory/compliance requirements
Facilitate regulatory/compliance audits
Ensure regulatory/compliance certification

- PC1. analyze the organization's business model and industry-specific compliance obligations

- PC6. monitor system configurations to ensure adherence to defined security and compliance
benchmarks
- PC7. collect and review documentation to validate ongoing compliance with established standards

- PC9. recommend or initiate corrective actions, including automated remediation controls for non-
compliance
- PC10. provide security and compliance-related inputs during vendor selection, contracting, and
agreement reviews
- PC11. coordinate and support internal and third-party audits to evaluate compliance status
- PC12. identify compliance gaps and present issues to relevant stakeholders for prioritization and
mitigation
- PC13. ensure that compliance processes are audit-ready with appropriate documentation and
controls
- PC14. ensure the organization meets certification requirements set by regulatory authorities
- PC15. collaborate with certification bodies to submit compliance reports and obtain necessary
