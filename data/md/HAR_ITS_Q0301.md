#### HAR/ITS/Q0301: Software/Application Testing Assistant
Brief Job Description
The qualification provides the techniques and skills to use modern software testing tools to support
software testing projects. The course provides the candidates to learn how to planning a test project,
design test cases and data, conduct testing operations, manage software problems and defects, and
generate a testing report
Personal Attributes
The person should have strong analytical and problem-solving skills to identify and troubleshoot issues
effectively. Attention to detail and a curious mindset are also essential to ensure thorough testing and
quality assurance.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. HAR/ITS/N0301: Working with Operating System
2. HAR/ITS/N0302: Manual Testing
3. HAR/ITS/N0303: Java Programming
4. HAR/ITS/N0304: Introduction to Database and Database Testing (Manual)
5. HAR/ITS/N0305: Automation Testing with selenium
6. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### HAR/ITS/N0301: Working  with Operating System
Description
Provides a foundational understanding of operating systems, exploring their types, core functions, and
architecture.
Scope
The scope covers the following :
Equips learners with the skills necessary for roles in system administration, IT support etc.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Define operating system, its types and functions.
- PC2. Explain the concept of process management and multithreading.
- PC3. Explain memory management in operating system
- PC4. Describe basic commands in Linux / Unix operating system
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. The objective and goals of the organization and scope of work
- KU2. The principles of operating systems, including types of OS, process management, multithreading, and memory management.
- KU3. How operating systems interact with hardware and manage system resources.
- KU4. The importance of operating systems in maintaining organizational IT infrastructure, ensuring
performance, security, and resource management.
#### Generic Skills (GS)
User/individual on the job needs to know how to:
- GS1. Make informed decisions regarding operating system selection, configuration, and updates based on organizational needs and technical requirements.
- GS2. Apply problem-solving techniques to troubleshoot operating system issues, optimize performance, and configure system resources efficiently.
- GS3. To manage tasks effectively, ensuring timely installation, configuration, and troubleshooting of
operating systems.
- GS4. Deliver efficient and reliable operating system solutions that meet user needs and enhance
organizational operation

#### HAR/ITS/N0302: Manual  Testing
Description
Provides a comprehensive understanding of manual software testing principles, practices, and processes
Scope
The scope covers the following :
Prepares learners to design, execute, and document manual tests effectively, equipping them with
essential skills for roles in software testing, quality assurance, and quality control within software
development teams and organizations.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Explain software testing principles and differentiate between Quality Control and Quality
Assurance
- PC2. Explain the various phases of the Software Development Life Cycle (SDLC) and Software
Testing Life Cycle (STLC)
- PC3. Explain and differentiate between different test levels and test design techniques.
- PC4. Mention the importance of documentation in software testing and Describe various types of
testing documents.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Organization objective, its goals and Scope of the work
- KU2. To apply knowledge of software testing principles, SDLC, and STLC, along with practical skills
in test case design, execution, and documentation.
- KU3. The role of software testing within the broader software development process and its impact
on the business objectives.
- KU4. The organizational structure and how to collaborate between the development, testing, and operations teams to ensure a smooth workflow and integration of testing activities.
- KU5. How to prioritize testing efforts based on risk, project requirements, and business needs,
ensuring that critical components of the software are thoroughly tested.
#### Generic Skills (GS)
User/individual on the job needs to know how to:
- GS1. Priortise the work based on their impotance.
- GS2. Organize testing tasks, setting up testing environments, and managing time to make sure testing is done efficiently and on schedule.

#### HAR/ITS/N0305: Automation  Testing with selenium
Description
Provides the basics of automation testing, focusing on using Selenium to automate software tests
efficiently.
Scope
The scope covers the following :
Helps beginners learn automation testing using Selenium, a popular tool for testing software. It
opens up opportunities to work in software testing.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Describe automation testing, its advantages and disadvantages.
- PC2. Differentiate between Automation and Manual Testing
- PC3. Describe Automation testing tools
- PC4. Describe Selenium commands and scripts used for Automation Testing
- PC5. Define and differentiate Selenium Webdriver and selenium RC
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. The role of automation testing in increasing the speed and accuracy of the testing process.
- KU2. How to apply automation testing to meet organizational goals.
- KU3. How to prioritize test cases for automation based on business needs and project requirements.
- KU4. The importance of communication and teamwork in successfully implementing and maintaining automation strategies in an organization.
#### Generic Skills (GS)
User/individual on the job needs to know how to:
- GS1. Choose the right Selenium tool, based on the complexity of the test and the testing environment.
- GS2. Efficiently manages multiple testing projects, ensuring proper allocation of time and resources
for automation tasks.
- GS3. Communicates automation testing results clearly to stakeholders, offering detailed reports
and feedback on test performance.

| Sector | Sector is a conglomeration of different business operations having similar business and interests. It may also be defined as a distinct subset of the economy whose components share similar characteristics and interests. |

| Occupation | Occupation is a set of job roles, which perform similar/ related set of functions in an industry. |
| Job role | Job role defines a unique set of functions that together form a unique employment opportunity in an organisation. |
| Occupational Standards (OS) | OS specify the standards of performance an individual must achieve when carrying out a function in the workplace, together with the Knowledge and Understanding (KU) they need to meet that standard consistently. | Performance Criteria (PC) | Performance Criteria (PC) are statements that together specify the standard of performance required when carrying out a task. |
| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |
| Qualifications Pack (QP) | QP comprises the set of OS, together with the educational, training and other criteria required to perform a job role. A QP is assigned a unique qualifications pack code. |
| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
| Description | Description gives a short summary of the unit content. This would be helpful to anyone searching on a database to verify that this is the appropriate OS they are looking for. |
| Scope | Scope is a set of statements specifying the range of variables that an individual may have to deal with in carrying out the function which have a critical impact on quality of performance required. |
