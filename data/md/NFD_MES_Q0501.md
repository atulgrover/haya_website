NFD/MES/Q0501: Visual Communication Artist: Static and Motion Graphics
Brief Job Description
This course is a short-term skill training program for freshers and amateurs to learn the craft of Graphic
design and motion Graphic Design and earn a livelihood through employment or freelance assignments.
The objective of the program is to prepare individuals for the job of Graphic Designer/Motion Graphic Artist,
where they create visual concepts, using computer software or by hand, to communicate ideas that
inspire, inform, and captivate consumers and enable them to develop the overall layout and production
design for various applications such as logo designs, branding & advertisements, UI/UX layouts, logo
animation, explainer videos, channel packaging, etc. with high visual impact.
Personal Attributes
This job requires individuals with a keen eye for design and creativity, adept at translating concepts into
compelling visuals. They should demonstrate proficiency in computer software for graphic and motion
graphics, capable of crafting impactful and innovative designs for various purposes. Successful candidates
should possess a strong understanding of layout, typography, and colour theory and the ability to
conceptualize and execute designs that resonate with audiences across different mediums. Additionally,
they must be adaptable, detail-oriented, and equipped to thrive in a dynamic, deadline-driven
environment.

NFD/MES/N0501: Carry out visual communication through graphics design
techniques.
Description
This NOS is designed to perform visual communication through graphics design techniques.
Scope
The scope covers the following :
Vector Designing with Illustrator
Digital & Print Publishing with InDesign
Digital Design with Photoshop
Branding & Advertisement
Web Layout with Figma
Elements and Performance Criteria
Vector Designing with Illustrator
To be competent, the user/individual on the job must be able to:
PC1. install Adobe Illustrator.
PC2. detect the various features of Illustrator tools to create basic shapes –ellipse, rectangle,
polygon, star, etc.
PC3. use pen tool to create custom shapes.
PC4. use Pathfinder and Shape Builder tool to modify and create intricate patterns and shapes.
PC5. use the 3D option to create depth in 2D objects.
PC6. use transform tool to resize and rotate the shapes.
PC7. using Types to create visually appealing designs.
PC8. demonstrate how to create logos with brief.
PC9. design logos as per client expectation.
Digital & Print Publishing with InDesign
To be competent, the user/individual on the job must be able to:
PC10. install and access Adobe InDesign.
PC11. demonstrate the process of creating digital and print publishing.
PC12. use Pages panel to create paper settings for book and other forms of publishing.
PC13. create book layouts and magazine layouts with InDesign.
PC14. create book cover page, inside pages with page numbering.
Digital Design with Photoshop
To be competent, the user/individual on the job must be able to:
PC15. install and access Adobe Photoshop.
PC16. demonstrate the process of image restoration.
PC17. use of various selection tools to select images and remove backgrounds with precision.
