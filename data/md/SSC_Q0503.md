SSC/Q0503: Web Developer
Brief Job Description
Individuals at this job are responsible for designing and maintaining web-based applications that include
static and dynamic content. This includes the design, layout and coding of a website. They may work
standalone or along with application/functional developers as part of the overall solution that includes a
web based component.
Personal Attributes
This job may require the individual to work independently or in teams. The individual should be result
oriented. The individual should also be able to demonstrate skills for communication, creative and logical
thinking.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
- 1. SSC/N0501: Contribute to the design of software products and applications
- 2. SSC/N0503: Develop Media Content and Graphics for Software Products and Applications
- 3. DGT/VSQ/N0101: Employability Skills (30 Hours)

SSC/N0501: Contribute to the design of software products and
applications
Description
This unit involves contributing to software design with low complexity and impact, focusing on UI/UX
principles, responsive design, front-end and back-end development, version control, and the use of
Generative AI for enhanced efficiency and innovation.
Scope
The scope covers the following :
Understanding Business and Software Requirements
Designing Basic Programming Structures
Documentation and Compliance
UI/UX Design Principles
Responsive and Adaptive Design
Front-End Development
Back-End Development
Version Control and Deployment
Web Performance Optimization
Testing and Debugging
Generative AI
Elements and Performance Criteria
Understanding Business and Software Requirements
To be competent, the user/individual on the job must be able to:
PC1. collaborate with project stakeholders to fully comprehend Business Requirements
Specification (BRS), User Requirements Specification (URS), and Software Requirements
Specification (SRS)
PC2. ensure the understanding of High-Level Design (HLD) concept by consulting with relevant
stakeholder
Designing Basic Programming Structures
To be competent, the user/individual on the job must be able to:
PC3. design basic programming structures to implement functionality in line with BRS/URS, SRS,
and HLD
PC4. conduct design review meetings with industry experts and senior developers to validate the
design against industry standards and best practices
PC5. analyze the inputs to identify, resolve, and record design defects and inform future designs
Documentation and Compliance
To be competent, the user/individual on the job must be able to:
PC6. document the details of designs using standard templates and tools (e.g., UML diagrams,
wireframes)

SSC/N0503: Develop Media Content and Graphics for Software Products
and Applications
Description
This unit is about developing media content and producing graphic designs to enhance to usability of
software products and applications where their business impact and technical complexity is low.
Scope
The scope covers the following :
Media Content and Graphic Design Development
Responsive Web Design
Web Accessibility Standards
Dynamic Content Integration
Review and Feedback Process
Documentation and Knowledge Sharing
Compliance and Approval
Elements and Performance Criteria
Media Content and Graphic Design Development
To be competent, the user/individual on the job must be able to:
PC1. convert Business Requirements Specification (BRS) and Software Requirements Specification
(SRS) into media content and graphic designs, using available resources and tools
PC2. access reusable components, media, and graphical packages from the organization’s
knowledge base to optimize design work
PC3. utilize reusable components to create dynamic and responsive media content and graphic
designs
PC4. ensure the media content and graphic designs align with the overall design specifications
and business objectives
PC5. collaborate with stakeholders to gather feedback and refine media content and graphic
designs to meet user needs
PC6. maintain consistency in design elements, ensuring alignment with brand guidelines and user
interface standards

To be competent, the user/individual on the job must be able to:
PC7. design media content and graphics optimized for various screen sizes and devices, ensuring
responsiveness and fluid layout across platforms
PC8. apply mobile-first design principles and use frameworks like Bootstrap to create adaptable
web designs
