#### SSC/Q8120: Data Annotator
Brief Job Description
Individuals at this job are responsible for data annotation and being able to classify the data they are
provided with. They assess the information from various sources like videos, advertisements, photographs,
and other types of material and then attach tags to the content.They will need to inculcate strong work
ethic, maintain a healthy working environment, and provide data and information in standard formats.
Personal Attributes
Data Annotator is required to inculcate strong work ethic, maintain a healthy working environment, and
provide data and information in standard formats.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N8135: Identify, tag, and label distinct elements in huge datasets
2. SSC/N8136: Carry-out effective validation activities and tests on annotated data for better accuracy
3. SSC/N8137: Review, document and report annotations created on a regular interval
4. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### SSC/N8135: Identify, tag, and label distinct elements in huge datasets
Description
This unit is about analyzing and classifying different elements of the datasets using relevant annotation
tools and techniques depending on the project.
Scope
The scope covers the following :
Requirements Gathering
Data Curation
Analysis & Categorization
Data tagging and labelling
Handling ambiguties
Software utilization
Quality Control
Regulations and Compliance
#### Elements and Performance Criteria
Requirements Gathering
#### To be competent, the user/individual on the job must be able to:
- PC1. interact with data science and engineering teams to contribute to overall project
development
- PC2. evaluate business contexts and identify the true definition of the data being annotated for
specific use cases
Data Curation
#### To be competent, the user/individual on the job must be able to:
- PC3. identify the primary types of already determined data, relevant to the project (text, audio,
image, and video)
- PC4. search for data sources and data sets according to a defined keyword
- PC5. garner the pre-processed data after data cleaning and profiling from the data science team
Analysis & Categorization
#### To be competent, the user/individual on the job must be able to:
- PC6. identify data sensitivities (PHI, PII, etc.) for masked and encrypted data
- PC7. classify the different data elements as sentiments, semantics, intent, and named entities
Data tagging and labelling
#### To be competent, the user/individual on the job must be able to:
- PC8. recognize relevant annotation methods based on the data types, elements, ML algorithms
being used, the business case and its expected outcomes
- PC9. identify and analyze the domain vocabulary, language, format, and category of data
intended to be used
- PC10. label the data accordingly as per the type of annotation and output required

#### SSC/N8136: Carry-out effective validation activities and tests on
annotated data for better accuracy
Description
This unit is about performing quality checks to maintain data integrity, security and standardization in the
annotations.
Scope
The scope covers the following :
Establishing validation criterian
Review Annotation quality
Corrective Actions & Feedback
#### Elements and Performance Criteria
Corrective Actions & Feedback
#### To be competent, the user/individual on the job must be able to:
- PC1. Develop detailed documentation that outlines how to annotate various elements, including
examples and edge cases.
- PC2. Define the metrics such as precision, recall, and F1-score that help evaluate the quality of
the annotations.
Review Annotation quality
#### To be competent, the user/individual on the job must be able to:
- PC3. Randomly selecting samples of annotated data and reviewing them against the established
guidelines to check for accuracy.
- PC4. Ensure that annotations are consistent across similar instances. For example, if two
annotators label similar images differently, this inconsistency needs to be addressed.
- PC5. Employ and follow pre-defined methods to ensure accuracy of annotation models and
techniques
- PC6. Review the annotated data and conduct periodic validations adhering to all the required
standards
- PC7. Apply or execute cross-checking mechanisms to ensure wrongful labelling is not performed
- PC8. Adhere to the defined data quality standards to secure the ground data and annotated data
from corruption and leakage
Corrective Actions & Feedback
#### To be competent, the user/individual on the job must be able to:
- PC9. Provide inputs to data engineers on tooling and processes for more efficient labeling, and to
improve data quality
- PC10. Execute methods to identify misclassified content
- PC11. Suggest changes in annotation schemes if and when required
- PC12. Help create open-source datasets with the right annotation for an unbiased evaluation of
annotation models

### Page 31

| Sector | Sector is a conglomeration of different business operations having similar business and interests. It may also be defined as a distinct subset of the economy whose components share similar characteristics and interests. |
| --- | :---: |
| Sub-sector | Sub-sector is derived from a further breakdown based on the characteristics and interests of its components. |
| Occupation | Occupation is a set of job roles, which perform similar/ related set of functions in an industry. |
| Job role | Job role defines a unique set of functions that together form a unique employment opportunity in an organisation. |
| Occupational Standards (OS) | OS specify the standards of performance an individual must achieve when carrying out a function in the workplace, together with the Knowledge and Understanding (KU) they need to meet that standard consistently. Occupational Standards are applicable both in the Indian and global contexts. |
| Performance Criteria (PC) | Performance Criteria (PC) are statements that together specify the standard of performance required when carrying out a task. |
| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |
| Qualifications Pack (QP) | QP comprises the set of OS, together with the educational, training and other criteria required to perform a job role. A QP is assigned a unique qualifications pack code. |
| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
| Description | Description gives a short summary of the unit content. This would be helpful to anyone searching on a database to verify that this is the appropriate OS they are looking for. |
| Scope | Scope is a set of statements specifying the range of variables that an individual may have to deal with in carrying out the function which have a critical impact on quality of performance required. |
