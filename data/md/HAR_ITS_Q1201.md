HAR/ITS/N0907: IT Foundation and Digital Tools (1)
Description
The NOS provides basic knowledge and skills to operate computer and prepares you to perform basic
office jobs.
Scope
The scope covers the following :
The NOS builds essential skills in Word, Excel, PowerPoint, and Internet usage, preparing students
for basic office tasks and serving as a foundation for advanced computer applications.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Understand the meaning, characteristics, history, generations, and classification of
computers.
PC2. Identify and explain the main components, input/output devices, and the working of a
computer system.
PC3. Differentiate between data and information, and perform basic number conversions.
PC4. Demonstrate understanding of operating systems, including the settings and functions of
Windows..
PC5. Diagnose and resolve common peripheral malfunctions and connectivity issues.
PC6. Create and edit documents using word processing tools with proper formatting and layout.
PC7. Apply formulas and functions in spreadsheets and use spreadsheet tools effectively.
PC8. Design and present information visually using digital presentation software.
PC9. Develop correct typing posture and accuracy with improved speed.
PC10. Utilize networking and internet skills to communicate online, manage email accounts, ensure
cybersecurity, and understand cloud storage
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Demonstrates understanding of the evolution, characteristics, and classification of computers,
including their historical development and technological generations.
KU2. Identifies and explains the main hardware components, input/output devices, and the overall
functional process of a computer system.
KU3. Explains the purpose, functions, and configuration of operating systems, particularly Windows,
in managing computer resources and settings.
KU4. Understands methods for diagnosing and resolving common hardware, peripheral, and
connectivity issues within a computer system.

HAR/ITS/N1202: Introduction to Multimedia and Web Designing tools
Description
The NOS helps students to learn and develop skills in designing multimedia web sites using various
multimedia and web designing tools such as HTML, CSS, Javascript etc.
Scope
The scope covers the following :
Develop skills in designing and developing multimedia websites using modern web technologies and
tools, enabling students to create interactive and user-friendly web solutions.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Understand the concept of multimedia and its key elements.
PC2. Know the tools and technologies used in multimedia and web design
PC3. perform image editing and design tasks using Adobe Photoshop, including working with layers,
tools, effects, and exporting images as per required standards.
PC4. Develop the ability to create structured web pages using HTML
PC5. enhance their design and layout using CSS, including responsive design techniques like
viewport, grid, and media queries.
PC6. build interactive and dynamic web applications using JavaScript and jQuery,
PC7. create modern, mobile-friendly websites using frameworks like Bootstrap for faster and
efficient development.
PC8. Understand and use WordPress, to build, manage, and customize websites using themes,
plugins, widgets, and content tools.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Fundamental concepts of multimedia and web design, including design principles, user
experience, and digital content structure.
KU2. Technical aspects of web development using HTML, CSS, JavaScript, and tools like Adobe
Photoshop.
KU3. Concepts of responsive web design, frameworks like Bootstrap, and use of libraries such as
jQuery.
KU4. Working and management of Content Management Systems, especially WordPress, including
themes, plugins, and content publishing
KU5. Organizational requirements, workflow processes, data management practices, and
adherence to project guidelines and timelines.
