ASP/ITS/Q0101: AI - Machine learning Developer
Brief Job Description
Individuals in this role are responsible for designing, developing, and deploying AI and Machine Learning
applications and platforms. They evaluate the performance of algorithmic models within the deployment
environment and ensure optimal system integration. Their responsibilities include building, testing, and
implementing end-to-end AI solutions tailored to specific use cases.
Personal Attributes
A learner in the AI and Machine Learning course should possess analytical and logical thinking, a strong
problem-solving mindset, and curiosity for innovation. Attention to detail, patience, and perseverance are
essential for handling complex data and algorithms. Mathematical aptitude, adaptability, and a
commitment to continuous learning help in mastering evolving technologies.

ASP/ITS/N0107: Python Programming with Scientific and Mathematical
Applications
Description
Learners will acquire foundational to intermediate proficiency in Python, enabling them to apply
programming skills to scientific and mathematical problem-solving, data processing, and model
development using essential libraries.
Scope
The scope covers the following :
Learners will acquire foundational to intermediate proficiency in Python, enabling them to apply
programming skills to scientific and mathematical problem-solving, data processing, and model
development using essential libraries.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:

operations.
PC2. Use NumPy and SciPy libraries to perform array manipulations and scientific computations.
PC3. Create and interpret visualizations using Matplotlib for scientific data.
PC4. Connect to databases using Python and perform data insertion, retrieval, and updates.
PC5. Solve linear algebra problems using Python for scientific and engineering applications.
PC6. Simulate and analyze random processes using appropriate Python libraries and techniques.
PC7. Formulate and solve basic optimization problems using tools like SciPy and PuLP.

ASP/ITS/N0105: Core Concepts in Machine Learning
Description
Learners will gain an in-depth understanding of supervised and unsupervised machine learning algorithms,
enabling them to develop, train, evaluate, and interpret predictive models on real-world datasets.
Scope
The scope covers the following :
Building, training, and validating ML models on real-world datasets.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Explain key machine learning concepts, types of learning, and common algorithms.
PC2. Build and evaluate regression models using techniques like linear and polynomial regression
on real-world data.
PC3. Apply classification algorithms such as logistic regression, decision trees, and SVM to labeled
datasets.
PC4. Use non-parametric techniques like K-Nearest Neighbors for classification tasks with unknown
data distributions.
PC5. Perform clustering and dimensionality reduction using unsupervised learning methods like k-
means and PCA.
PC6. Evaluate model performance using metrics such as confusion matrix, cross-validation,
precision-recall, and ROC curves.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Core concepts of supervised unsupervised and non parametric learning methods
KU2. Functioning and applications of algorithms like linear polynomial regression logistic regression
decision trees SVM KNN k means and PCA
KU3. Principles of overfitting underfitting and bias variance tradeoff
KU4. Model evaluation techniques including confusion matrix precision recall ROC curves and cross
validation
KU5. Importance of feature selection dimensionality reduction and data distribution in ML workflows
Generic Skills (GS)
User/individual on the job needs to know how to:
GS1. Analyze and preprocess real world datasets for regression classification and clustering tasks

ASP/ITS/N0103: Bayesian methods And Text Mining
Description
Learners will develop the ability to implement Bayesian inference, probabilistic modeling, and text mining
methods using Python for extracting patterns and solving uncertainty-based problems.
Scope
The scope covers the following :
Learners will develop the ability to implement Bayesian inference, probabilistic modeling, and text
mining methods using Python for extracting patterns and solving uncertainty-based problems.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Apply Bayesian inference concepts including prior, likelihood, and posterior in probabilistic
models.
PC2. Implement Gaussian Mixture Models using Python to represent and analyze complex data
distributions.
PC3. Use MCMC, Gibbs sampling, or variational inference to approximate posterior distributions in
Bayesian models.
PC4. Preprocess textual data through tokenization, stop-word removal, and normalization
techniques.
PC5. Extract features from text using TF-IDF, word embeddings, or other vectorization techniques.
PC6. Perform sentiment or topic analysis on unstructured text using appropriate Python libraries.

hands-on experience with neural networks, generative models, transformers, LLMs, and prompt

Elements and Performance Criteria

architectures

regularization techniques
KU4. know the applications and working of convolutional recurrent and transformer based models
in various domains
KU5. understand prompt engineering methods and their importance in guiding large language
models for specific tasks

Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
