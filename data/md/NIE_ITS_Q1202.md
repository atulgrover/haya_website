NIE/ITS/Q1202: Junior Cloud Computing Associate
Brief Job Description
A Junior Cloud Computing Associate is an entry-level professional in the field of cloud computing. They
assist in managing and maintaining cloud infrastructure and services. Their responsibilities may include
basic cloud resource provisioning, monitoring, and support tasks.
Personal Attributes
It includes Virtualization, Basics of Cloud Computing, and Linux Operating System with the expertise to
effectively implement virtualization technologies, grasp essential cloud computing concepts, and master
the Linux operating system
Applicable National Occupational Standards (NOS)
Compulsory NOS:
- 1. NIE/ITS/N1204: Conceptualize Operating Systems - Windows and Linux
- 2. NIE/ITS/N1205: Introduction to Network Management System
- 3. NIE/ITS/N1206: Implementing Virtualization and Basics of Cloud Computing Technology
- 4. NIE/ITS/N1207: Conceptualize Advance Linux
- 5. NIE/ITS/N1209: Emphasizing Cloud Computing Services
- 6. DGT/VSQ/N0102: Employability Skills (60 Hours)
- 7. NIE/ITS/N1208: Managing Cloud Architecture with Open Stack

NIE/ITS/N1204: Conceptualize Operating Systems - Windows and Linux
Description
Operating systems are fundamental software components that manage and facilitate the interaction
between hardware and software in a computer system. Windows and Linux are two prominent operating
systems, each with its unique characteristics, architectures, and use cases
Scope
The scope covers the following :
Able to operate operating Window & Linux Operating System
Elements and Performance Criteria
Opearting System
To be competent, the user/individual on the job must be able to:
PC1. Configure Network Settings and perform user and group management
PC2. Knowledge of various management service roles and get acquainted with the concept of
remote desktop management
PC3. Installation of Windows and Linux Operating System
PC4. Creation of disk partitions and configure Active directory
PC5. • Conceptualization of s of Group policy, work Shell and run various Windows
• commands
PC6. Basic Commands in Linux and implement administrator tasks with sudo.
PC7. Acquire skills pertaining to group user management, Piping and Greping and also mounting of
disk.

The individual on the job needs to know and understand:
KU1. Window Operating System
KU2. Linux Operating System and its command

NIE/ITS/N1205: Introduction to Network Management System
Description
Network Management is the practice of administering, monitoring, and maintaining a computer network to
ensure its optimal performance, security, and reliability. It involves a set of activities, tools, and techniques
used to control, plan, deploy, and optimize network resources, services, and infrastructure. Effective
network management is crucial for organizations of all sizes to ensure their networks function efficiently
and securely.
Scope
The scope covers the following :
Able to configure and manage network system
Elements and Performance Criteria
Network Management
To be competent, the user/individual on the job must be able to:
PC1. Overview of OSI ,TCP/IP Model and Function of layers, learn about various types of networks
PC2. Knowledge about the Benefits of Network, Components of Computer Networks and also have
an insight into various topology used in networking
PC3. Explain various Transmission modes, Ethernet and the Classification Of Transmission Media.
PC4. In-depth idea about various networking devices like Repeaters, Hubs, Bridges,Switches and
router
PC5. Introduction to TCP/IP Protocol Model in Depth, Port Numbers, Common TCP& UDP Ports and
also Some important TCP/IP protocols
PC6. IP addressing, Classes, IP Addressing Scheme, Subnetting Basics along with How to Create
Subnets, Subnet Masks, Subnetting Class C Addresses, Subnetting Class B Addresses and
VLSM
PC7. Configure ip addresses in Windows and Linux and also have a proper introduction to RIR,
registries and IANA along with attaining knowledge about TCP/IP Troubleshooting utilities,
Troubleshooting IP Addressing
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Overview of TCP/IP & OSI Model
KU2. Network devices, IP Addressing & Topology configuration
Generic Skills (GS)
User/individual on the job needs to know how to:

NIE/ITS/N1205: Managing Cloud Architecture with Open Stack.
Description
OpenStack is an open-source cloud computing platform that allows you to build and manage your own
private or public cloud infrastructure. It is designed to provide a flexible and scalable solution for managing
cloud resources and services. Here's an overview of how you can manage cloud architecture with
OpenStack
Scope
The scope covers the following :
Configure and manage openstack Services
Elements and Performance Criteria
Openstack
To be competent, the user/individual on the job must be able to:
PC1. Basic components and Architectures of open Stack along with Installation of Openstack
PC2. Configure and manage Open Stack Client and Horizon dashboard.
PC3. Configure and manage OpenStack Identity Management
PC4. Configure and manage Image management
PC5. Configure and manage Compute Service
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. OpenStack is an open-source cloud platform for managing public, private, and hybrid cloud
infrastructures
KU2. Key OpenStack components include Nova (compute), Swift (object storage), Cinder (block
storage), Neutron (networking), and Horizon (dashboard).
KU3. Keystone handles identity management, providing secure authentication, authorization, and
role-based access control across OpenStack.
Generic Skills (GS)
User/individual on the job needs to know how to:
GS1. Effectively manage and configure cloud resources using OpenStack components like Nova,
Swift, and Neutron.
GS2. Troubleshoot and resolve issues related to cloud infrastructure, ensuring optimal performance
and reliability.
GS3. Implement security best practices, including identity management, role-based access control,
and secure API usage.
