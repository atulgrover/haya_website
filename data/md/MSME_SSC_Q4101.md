MSME/SSC/Q4101: Jr. Designer UI UX
Brief Job Description
A web graphic designer is responsible for curating the aesthetics of a website from logos to fonts and
images. They typically work with other designers and web developers to decide on a direction for the
website's image. To be successful as a web graphic designer you must have a good understanding of front-
end and back-end coding to create functions that work and look appealing.
Personal Attributes
A web graphic designer is responsible for curating the aesthetics of a website from logos to fonts and
images. They typically work with other designers and web developers to decide on a direction for the
website's image. To be successful as a web graphic designer you must have a good understanding of front-
end and back-end coding to create functions that work and look appealing.

MSME/SSC/N4405: Understanding the fundamentals of Art and Illustration
Description
Knowledge of basic art principles such as line, shape, color, texture, composition, and visual storytelling
used to create effective illustrations.
Scope
The scope covers the following :
Knowledge of basic art principles such as line, shape, color, texture, composition, and visual
storytelling used to create effective illustrations.
Elements and Performance Criteria
MSME/UIUX/01
To be competent, the user/individual on the job must be able to:
PC1. Demonstrate proficiency in art and illustration techniques.
PC2. • Command of line, shape, color, texture, and composition.
• Creative Expression:
PC3. Showcase creativity and artistic expression.
PC4. • Express ideas, emotions, and concepts through artwork.
• Visual Communication:
PC5. Effectively communicate messages visually
PC6. Use visual language, symbols, and design principles.Conceptual Development:
PC7. Develop and expand creative concepts and ideas.
PC8. • Translate abstract ideas into visual artwork.
• Research and Reference:
PC9. Incorporate research, reference materials, and inspiration.
PC10. • Research historical, cultural, and contemporary influences.
• Creative Problem-Solving:
PC11. Exhibit effective problem-solving skills in art challenges.
PC12. • Find creative solutions to visual problems.
• Presentation and Professionalism:
PC13. Present work professionally and effectively
PC14. • Skill in presenting artwork for exhibitions, portfolios, and client projects.
• Critique and Self-Reflection:
PC15. Actively participate in critiques and provide constructive feedback.
PC16. • Critically evaluate own work and others' work for constructive learning.
• Cultural and Ethical Awareness:
PC17. Demonstrate understanding of cultural and ethical considerations
PC18. Awareness of cultural diversity, social issues, and ethical implications.

MSME/SSC/N4406: Exploring the realm of Web Technologies
Description
Understanding the technologies used to create and maintain websites, including HTML, CSS, JavaScript,
web design, and web development tools.
Scope
The scope covers the following :
Understanding the technologies used to create and maintain websites, including HTML, CSS,
JavaScript, web design, and web development tools.
Elements and Performance Criteria
MSME/UIUX/02
To be competent, the user/individual on the job must be able to:
PC1. • Grasp concepts like the Internet, URLs, and web page delivery to
• computers
PC2. Apply HTML markup effectively, including tags, attributes, and elements
PC3. • Format text, create hyperlinks, and insert images appropriately in HTML
• pages
PC4. • Understand copyright fair use principles when incorporating external
• content.
PC5. Enhance web page appearance using HTML and CSS for styling.
PC6. Differentiate between HTML and CSS, understanding their roles.
PC7. Utilize CSS selectors to target specific elements effectively.
PC8. Comprehend the cascade and selector precedence order in CSS
PC9. Develop a personal homepage project showcasing creativity and skills.
PC10. • Apply advanced HTML/CSS techniques, such as splitting sites and
• combining CSS selectors
PC11. Evaluate and apply user interface design principles to web interfaces.
PC12. Ensure accessibility and readability in web design.
PC13. Utilize lite site and prototyping concepts for efficient web page creation.
PC14. • Conduct user testing, collaborate effectively, and iterate on design
• prototypes.
PC15. • Implement responsive design principles and enhance interactivity with
• JavaScript and jQuery.

MSME/SSC/N4407: Acquire the knowledge of Figma & Adobe XD for UI/UX
Design
Description
Learn to create user-friendly interfaces, wireframes, prototypes, and interactive designs using Figma and
Adobe XD.
Scope
The scope covers the following :
Learn to create user-friendly interfaces, wireframes, prototypes, and interactive designs using Figma
and Adobe XD.
Elements and Performance Criteria
MSME/UIUX/03
To be competent, the user/individual on the job must be able to:
PC1. • Demonstrate proficiency in using Figma and Adobe XD, understanding
• their key features and functionalities.
PC2. • Apply design principles effectively, including layout, typography, color
• theory, and visual hierarchy.
PC3. • Create aesthetically pleasing and goal-aligned UI designs for web and
• mobile applications.
PC4. • Design experiences that enhance user satisfaction, usability, and overall
• user experience
PC5. • Create interactive prototypes to mimic user interactions and showcase
• digital product functionality.
PC6. Collaborate with team members effectively, utilizing version control features for maintaining
design consistency.
PC7. • Prepare design documentation, including design system guidelines, style
• guides, and annotations.
PC8. • Develop communication and presentation skills to effectively convey
• design rationale to peers, clients, or stakeholders.
PC9. • Analyze design problems, gather feedback, and iterate on solutions
• based on user testing and feedback.
PC10. • Plan and execute usability tests, applying the results to optimize designs
• for improved usability.
PC11. • Be aware of ethical considerations in design, including accessibility,
• inclusivity, and privacy.

| Sector | Sector is a conglomeration of different business operations having similar business and interests. It may also be defined as a distinct subset of the economy whose components share similar characteristics and interests. |
| :--- | :---: |
| Sub-sector | Sub-sector is derived from a further breakdown based on the characteristics and interests of its components. |
| Occupation | Occupation is a set of job roles, which perform similar/ related set of functions in an industry. |
| Job role | Job role defines a unique set of functions that together form a unique employment opportunity in an organisation. |
| Occupational Standards (OS) | OS specify the standards of performance an individual must achieve when carrying out a function in the workplace, together with the Knowledge and Understanding (KU) they need to meet that standard consistently. Occupational Standards are applicable both in the Indian and global contexts. |
| Performance Criteria (PC) | Performance Criteria (PC) are statements that together specify the standard of performance required when carrying out a task. |
| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |
| Qualifications Pack (QP) | QP comprises the set of OS, together with the educational, training and other criteria required to perform a job role. A QP is assigned a unique qualifications pack code. |
| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
| Description | Description gives a short summary of the unit content. This would be helpful to anyone searching on a database to verify that this is the appropriate OS they are looking for. |
| Scope | Scope is a set of statements specifying the range of variables that an individual may have to deal with in carrying out the function which have a critical impact on quality of performance required. |
