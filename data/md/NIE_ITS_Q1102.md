#### NIE/ITS/Q1102: Junior Data Analyst
Brief Job Description
The Junior Data Analyst Qualification is meant to develop the front end and Implementation of use cases of
Data Analytics. The Junior Data is meant to inculcate the basic skills of data handling, processing and
visualization. The trained learner will be able to view data in summary and aggregated form, he/she would
able to formulate equation for prediction. inculcate the basic skills of Hadoop Framework and programming
experience of core Java. Training in different tools of Hadoop like Map Reduce, Hive will increase the
exposure to the analytics field.
Personal Attributes
Personal attributes include an analytical mindset for complex data interpretation, critical thinking skills for
effective problem-solving, meticulous attention to detail, a curious and adaptable approach for continuous
learning, strong communication abilities to convey technical insights to diverse audiences, efficient time
management, collaborative teamwork, ethical awareness in handling sensitive data, and the flexibility to
adapt to evolving project demands and technological advancements in the data analytics domain.

#### NIE/ITS/N1120: Perform basic calculation using spreadsheet-*
Description
Introduction to Tableau involves understanding its data visualization capabilities and functionalities.
Connecting Tableau to various data sources such as Excel, CSV, and databases allows for seamless data
integration. Analyzing data using Tableau's robust features, including formatting options, sorting
capabilities, and diverse charting tools, enables users to gain valuable insights and present data in a
visually appealing and comprehensive manner.
Scope
The scope covers the following :
The scope encompasses a comprehensive understanding of Tableau, focusing on its data visualization capabilities and the process of connecting to diverse data sources such as Excel, CSV,
and databases. It includes extensive training in data analysis through Tableau's advanced features,
encompassing formatting techniques, sorting functionalities, and various charting tools, enabling
users to effectively transform complex datasets into insightful visual representations for informed
decision-making and data presentation
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Familiarization with Tableau's interface and its capabilities for data visualization and analysis.
Learning the process of linking Tableau to Excel and CSV files for seamless data integration and analysis
- PC2. Understanding how to establish connections between Tableau and various databases to
access and analyze data directly from these sources, Exploring Tableau's data analysis tools and functionalities for dissecting and understanding complex datasets
- PC3. Mastering formatting techniques within Tableau to enhance the visual appeal of data
visualizations and dashboards. Understanding the sorting capabilities in Tableau to arrange data in a meaningful and logical order for effective analysis. Utilizing Tableau's diverse
charting tools to create various types of visual representations, including bar charts, line graphs, and pie charts, for comprehensive data presentation.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Introduction to Tableau and Connecting to Excel, CSV Text Files
- KU2. Connecting to Databases and its analysis
- KU3. Formatting, Sorting and Charts

understanding of the Linux file system, covering concepts such as file management, real and virtual files,

guidance on using command-line text editors, creating, searching, and comparing text files, as well as
managing files through copying, moving, and other relevant operations within the Linux environment.

command-line text editors, file searching, comparison, and manipulation, enabling users to effectively manage files and directories within the Linux environment.

entails the information input, while organizing it into tables and formatting involves structuring and
visually enhancing the presentation. Conditional formatting enables users to dynamically format cells

and pivot tables provide an effective means of data summarization. Data validation ensures the accuracy
and reliability of data input, while filtering allows for focused data analysis by selectively displaying
subsets of information that meet specified criteria.

#### Assessment Guidelines
• Assessment of the qualification evaluates candidates to ascertain that they can integrate knowledge,
skills and values for carrying out relevant tasks as per the defined learning outcomes and assessment criteria.

assessment criteria. competence acquired by the candidate can be obtained by conducting Theory (Online), Practical assessment, Internal

Assignment, Major Project. The emphasis is on the practical demonstration of skills & knowledge gained by
the candidate through the training.
