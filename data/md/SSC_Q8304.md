#### SSC/Q8304: Cloud Infrastructure Analyst
Brief Job Description
Individuals in this job are responsible for designing, maintaining, evaluating, and testing architectures of
cloud products and solutions. Cloud Architects also create enterprise policies and guidelines for cloud
implementation and governance. They assess cloud vendors and third-party cloud service providers. They
also assist in validating customer proposals and project plans for cloud implementation
Personal Attributes
Cloud Infrastructure Analysts must be able to communicate effectively, build relationships with others and
collaborate with various stakeholders. He/she must have a zeal to learn new things.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N8313: Provision, configure, test and deploy cloud infrastructure
2. SSC/N8314: Maintain compute, network and storage systems deployed on cloud and ensure backup and recovery
3. SSC/N8315: Automate cloud infrastructure management
4. SSC/N8316: Migrate legacy/ on-premise/cloud applications and data to new cloud platforms
5. SSC/N8317: Integrate cloud infrastructure with existing IT systems
6. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### SSC/N8313: Provision, configure, test and deploy cloud infrastructure
Description
This unit is about implementing appropriate cloud architecture and provisioning, configuring, and
deploying the infrastructure required for the cloud solutions.
Scope
The scope covers the following :
Drive architecture implementation
Provision, configure & deploy cloud infrastructure
Ensure scalability & interoperability
Ensure security
Troubleshoot issues
Implement tools & processes
#### Elements and Performance Criteria
Drive architecture implementation
#### To be competent, the user/individual on the job must be able to:
- PC1. implement appropriate multi-cloud/hybrid cloud architecture and solutions
Provision, configure & deploy cloud infrastructure
#### To be competent, the user/individual on the job must be able to:
- PC2. provision, configure, test, and deploy cloud infrastructure and related components
- PC3. build, configure and deploy containers and virtual environments on the cloud
Ensure scalability & interoperability
#### To be competent, the user/individual on the job must be able to:
- PC4. define and predict capacity requirements of the deployed virtual environment
- PC5. implement multi-routing, switching, and load balancing solutions to ensure scalability of
infrastructure

- PC7. ensure interoperability of cloud platform with other cloud service providers and on-
premise/legacy systems
Ensure security
#### To be competent, the user/individual on the job must be able to:
- PC8. implement cloud solutions by adhering to security standards
Troubleshoot issues
#### To be competent, the user/individual on the job must be able to:
- PC9. troubleshoot network infrastructure in case of failure
- PC10. troubleshoot issues related to the provisioning of compute and storage systems
Implement tools & processes

#### SSC/N8316: Migrate legacy/ on-premise/cloud applications and data to
new cloud platforms
Description
This unit is about migrating legacy/on-premise/cloud applications and data to new cloud platforms and
ensuring the migrated workload is secure and performs as intended.
Scope
The scope covers the following :
Develop migration plan
Drive resource provisioning
Drive cloud migration
Follow SOPs
Validate migration
Ensure alignment with governance policies
Ensure security
#### Elements and Performance Criteria
Develop migration plan
#### To be competent, the user/individual on the job must be able to:
- PC1. support the identification and estimation of application remediation and changes in the
source code required for the preparation of migration
- PC2. develop plans to create appropriate migration bundles and sequences and prepare data for
interfaces
- PC3. create, validate and execute fallback/ rollback plans in case the migration does not perform
as intended
Drive resource provisioning
#### To be competent, the user/individual on the job must be able to:

the cloud
- PC5. configure servers including storage & network for migration
Drive cloud migration

- PC6. migrate servers, storage, and databases to the new environment
- PC7. manage the migration of traffic
- PC8. identify and leverage appropriate migration tools to execute migration procedures
Follow SOPs
#### To be competent, the user/individual on the job must be able to:
- PC9. follow and maintain Standard Operating Procedures (SOPs) for the execution of migration
Validate migration
