SSC/Q8109: AI Database Administrator
Brief Job Description
This Qualification is designed to equip participants with essential knowledge and skills for effectively
managing databases and computing clusters within various professional environments. Spanning multiple
#### modules, this qualification covers foundational concepts in database management, including the
installation and configuration of popular open-source database management systems such as MySQL and
PostgreSQL, as well as hands-on experience with SQL commands for data manipulation. Participants will
learn advanced topics including data validation, compliance frameworks, automated maintenance, and
monitoring techniques to ensure optimal database performance. Furthermore, the qualification
emphasizes user access management, security configurations, and the importance of documentation in
operational continuity.
Personal Attributes
An AI - Database Administrator needs to be very organized with the ability to make crucial decisions. S/he
needs to have an eagerness to learn newer concepts and an ability to work under pressure.

SSC/N8115: Create new databases
Description
This unit is about creating new databases for internal and external clients.
Scope
The scope covers the following :
Define objective
Install database
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Define and prioritize objectives based on business needs and database performance
requirements
PC2. Identify and evaluate quality and reliability of suitable data sources
PC3. Specify storage requirements including scalability considerations and create new databases
PC4. import data from the identified sources into the database
PC5. create documentation on new databases for appropriate people
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. the purpose and aims of the statistical analysis being undertaken
KU2. organizational policies, procedures and guidelines which relate to creating new databases
KU3. organizational policies and procedures for sharing data
KU4. organizational policies and procedures for documenting databases
KU5. who to involve when creating new databases
KU6. the range of standard templates and tools available and how to use them
KU7. different data sources and how to access documents and information from data sources
KU8. different databases, including: relational (MySQL, Oracle Database), NoSQL (Redis,
MongoDB, Hbase, Cassandra, Amazon DynamoDB)
KU9. different functions to update or delete data from the databases such as CRUD (Create Read
Update Delete)
KU10. different functions to import data into the databases
KU11. how to query and write scripts to acquire and understand the data
KU12. how to store and retrieve information
KU13. how to work on various operating systems such as linux, ubuntu, or windows
Generic Skills (GS)

SSC/N8116: Maintain existing databases
Description
This unit is about maintaining existing databases for internal and external clients.
Scope
The scope covers the following :
Update and migrate databases
Define maintenance procedures
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Collaborate with stakeholders to validate databases for compliance and performance
PC2. Modify and remove data from existing databases and implement archiving procedures for
outdated information
PC3. Assist in the migration of existing databases to new environments, ensuring data integrity
throughout the process
PC4. Implement automated database maintenance plans, backup routines, and monitoring tools to
proactively identify issues
PC5. Perform both manual and scheduled maintenance procedures for backup, optimization, and
indexing, including specific examples of each
PC6. Diagnose and resolve issues with database completeness and veracity, ensuring data
integrity.
PC7. Conduct load or stress testing and user acceptance testing to ensure database reliability
under pressure
PC8. Monitor ongoing and forecasted workloads and data storage consumption; develop reports
for relevant stakeholders, including benchmarking against industry standards.
PC9. Oversee and regularly test the disaster recovery strategy for database environments to
ensure effectiveness
PC10. create documentation on managed databases
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. the purpose and aims of the statistical analysis being undertaken
KU2. organizational policies, procedures and guidelines which relate to maintaining existing
database
KU3. organizational policies and procedures for sharing data
KU4. organizational policies and procedures for documenting databases
KU5. who to involve when maintaining existing databases

SSC/N8117: Manage database access and configuration
Description
This unit is about managing access rules and configurations for databases for internal and external clients.
Scope
The scope covers the following :
Enable user access
Monitory capacity and performance
Elements and Performance Criteria
Enable user access
To be competent, the user/individual on the job must be able to:
PC1. define and test user access rules for databases
PC2. define encryption standards for the database
PC3. perform load/stress testing to ensure the database does not crash in a DDoS (Distributed
Denial of Service) attack
PC4. ensure access to specific data and form of the data and provide deployment support to
appropriate people using the databases
Monitory capacity and performance
To be competent, the user/individual on the job must be able to:
PC5. monitor ongoing and forecasted workloads and determine consumption of data storage and
compute resources
PC6. monitor logs, server usage, and performance metrics to ensure functionality and accessibility
PC7. develop reports on database utilization, availability and performance metrics for relevant
stakeholders
PC8. troubleshoot database utilization, availability and performance issues and remediate known
impacting vulnerabilities
PC9. oversee the availability and disaster recovery strategy for the database environment
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. organizational policies, procedures and guidelines which relate to managing database access
and configuration
KU2. organizational policies and procedures for sharing data
KU3. who to involve when managing database access and configuration
KU4. the range of standard templates and tools available and how to use them
KU5. how to define user access by setting authentication rules such as encrypted passwords

SSC/N8118: Manage computer cluster administration
Description
This unit is about managing access rules and configurations for computing clusters for internal and
external clients.
Scope
The scope covers the following :
Manage cluster deployment
Monitor capacity and performance
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Define, deploy, and manage clusters, including setup configurations and maintenance of
redundancy and failover strategies
PC2. Evaluate cluster requirements through capacity planning to ensure scalability
PC3. Monitor cluster connectivity and performance, recommending efficiencies, and utilize
advanced analytics or machine learning for predictive insights
PC4. Administer cluster access for appropriate users and manage permissions effectively
PC5. Create and validate documentation specific to computing clusters
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. your organizations policies, procedures and guidelines which relate to managing cluster
administration
KU2. your organizations policies and procedures for sharing data
KU3. your organization's policies and procedures for documenting computing clusters
KU4. who to involve when managing cluster administration
KU5. the range of standard templates and tools available and how to use them
KU6. different capacity planning considerations such as data redundancy, overhead and
compression, IOPS (Input/Output Operations per Second)
KU7. different applications that provide computing clusters such as Cloudera, Hortonworks
KU8. different cluster monitoring tools such as kubernetes, swarm, mesos
KU9. different ways to deploy and manage clusters based on business requirements
KU10. how to manually setup cluster configurations
KU11. how to define encryption standards for data stored on the cluster
KU12. different metrics to monitor cluster connectivity and performance
KU13. how to troubleshoot issues with clusters
