HAR/ITS/N0911: IT Foundation and Digital Tools (CSD)
Description
The NOS provides basic knowledge and skills to operate computer and prepares you to perform basic
office jobs.
Scope
The scope covers the following :
The NOS builds essential skills in Word, Excel, PowerPoint, and Internet usage, preparing students
for basic office tasks and serving as a foundation for advanced computer applications.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Understand the meaning, characteristics, history, generations, and classification of
computers.
PC2. Identify and explain the main components, input/output devices, and the working of a
computer system.
PC3. Differentiate between data and information, and perform basic number conversions.
PC4. Demonstrate understanding of operating systems, including the settings and functions of
Windows..
PC5. Diagnose and resolve common peripheral malfunctions and connectivity issues.
PC6. Create and edit documents using word processing tools with proper formatting and layout.
PC7. Apply formulas and functions in spreadsheets and use spreadsheet tools effectively.
PC8. Design and present information visually using digital presentation software.
PC9. Develop correct typing posture and accuracy with improved speed.
PC10. Utilize networking and internet skills to communicate online, manage email accounts, ensure
cybersecurity, and understand cloud storage
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Demonstrates understanding of the evolution, characteristics, and classification of computers,
including their historical development and technological generations.
KU2. Identifies and explains the main hardware components, input/output devices, and the overall
functional process of a computer system.
KU3. Explains the purpose, functions, and configuration of operating systems, particularly Windows,
in managing computer resources and settings.
KU4. Understands methods for diagnosing and resolving common hardware, peripheral, and
connectivity issues within a computer system.

HAR/ITS/N1605: Building Programming and Database management Skills
(Web programming, Oops & SQL)
Description
This NOS provides knowledge and practical skills in web programming, object-oriented programming, and
database management using HTML, CSS, JavaScript, XML, C++, and SQL.
Scope
The scope covers the following :
The scope includes creating web pages using HTML, CSS, JavaScript, and XML along with
implementing client-side scripting and validation techniques. It also covers C++ programming
concepts such as functions, arrays, pointers, classes, inheritance, polymorphism, file handling, and
database management using SQL commands, joins, triggers, and stored procedures.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Create and format web pages using HTML, CSS, and HTML5 elements including forms,
multimedia, tables, and responsive design features.
PC2. Apply CSS styling techniques and JavaScript programming concepts to develop interactive and
dynamic web pages.
PC3. Use XML, DTD, XML Schema, XPath, and XQuery concepts for structuring, validating, and
querying XML documents.
PC4. Develop and execute C++ programs using control statements, functions, arrays, strings,
pointers, structures, and file handling techniques.
PC5. Implement Object-Oriented Programming concepts such as classes, objects, inheritance,
polymorphism, abstraction, and constructors in C++ applications.
PC6. Explain database concepts, DBMS architecture, normalization, ER models, and relational
database concepts.
PC7. Create and manage databases using SQL commands including DDL, DML, TCL, DCL, and DQL
operations.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. the concepts, syntax, tools, and techniques of web programming, object-oriented
programming, XML, database management systems, and SQL operations.
KU2. the principles of website development, Cpp programming, OOP concepts, database design,
normalization, and data manipulation using SQL commands, joins, triggers, and stored
procedures.
KU3. the role of web technologies, programming, and database management systems in software
development and organizational operations.

HAR/ITS/N0802: OJT/ Project & Viva (1)
Description
The NOS enabling students to apply their acquired skills and knowledge in real work or job-oriented
environments.
Scope
The scope covers the following :
Provides practical exposure, enhance skills, and prepare students for real work environments by
bridging the gap between theory and practice
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Demonstrates application of theoretical knowledge in practical tasks
PC2. Adapts to workplace requirements and follows instructions
PC3. Demonstrates clear understanding of concepts during viva
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
