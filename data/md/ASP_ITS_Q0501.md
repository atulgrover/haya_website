ASP/ITS/N0501: Introduction to MERN
Description
This NOS equips students with the knowledge and practical skills needed to build structured and visually
appealing web pages using HTML and CSS. It covers web development basics, including the client-server
model, HTTP/HTTPS protocols, and database interactions. Students will gain hands-on experience with
HTML elements, forms, and semantic tags, as well as styling techniques using CSS for responsive design.
Additionally, they will explore advanced CSS techniques like positioning, pseudo-classes, and pre-
processors to enhance their web pages. This module serves as the foundational step toward full-stack
development using the MERN stack.
Scope
The scope covers the following :
This covers the foundational concepts and technologies required for MERN Stack development.
It includes an introduction to web development, HTML, and CSS, ensuring students gain a strong
understanding of front-end development.
The scope includes learning about web page structures, styling techniques, responsive design, and
fundamental client-server communication principles.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Demonstrate theoretical knowledge of web development fundamentals ,HTML functionalities,
and CSS styling techniques.
PC2. Write clean, well-structured, and commented HTML and CSS code to create basic web pages
and apply styling.
PC3. • Build responsive layouts that adapt to different screen sizes.
• Implement form functionalities and handle user input data.

ASP/ITS/N0502: Javascript and Typescript Fundamentals
Description
This NOS provides learners with a comprehensive understanding of JavaScript and TypeScript, enabling
them to build dynamic and interactive web applications. It covers core programming concepts, including
variables, functions, objects, classes, and asynchronous operations using promises and async/await.
Students will gain hands-on experience with DOM manipulation, browser APIs, and modular JavaScript. The
#### module also introduces TypeScript to enhance code maintainability, focusing on type annotations,
interfaces, function overloading, and generics. Furthermore, students will develop expertise in
implementing and optimizing data structures such as arrays, linked lists, stacks, queues, trees, and
graphs. The NOS ensures learners can analyze algorithmic complexity, select appropriate data structures,
and optimize code for efficiency, preparing them for real-world software development challenges in the
MERN stack ecosystem.
Scope
The scope covers the following :
This NOS covers the essential programming skills required for MERN Stack development, focusing on
JavaScript, TypeScript, and data structures.
It includes fundamental and advanced concepts of JavaScript, asynchronous programming, DOM
manipulation,
TypeScript type annotations, generics, and object-oriented programming. Additionally, it
encompasses the implementation of key data structures and their applications in problem-solving
and performance optimization.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Demonstrate a solid understanding of JavaScript fundamentals (syntax, variables, data types,
operators, control flow).
PC2. Write clean and efficient JavaScript code to perform basic operations, manipulate data
structures (arrays, objects), and interact with the DOM.
PC3. Handle asynchronous tasks effectively using promises, async/await, and callbacks to create
responsive web applications.
PC4. Apply type annotations in TypeScript code to improve code clarity, reduce errors, and enhance
code maintainability.
PC5. • Effectively utilize TypeScript features like interfaces, functions, classes,
• and modules to organize and structure code.

ASP/ITS/N0503: Building Web applications with React and Next.js
Description
This NOS provides learners with the expertise to develop dynamic and interactive web applications using
ReactJS and Next.js. Students will gain proficiency in creating reusable components, managing application
state with Redux/Zustand, and implementing efficient client-side routing using React Router. The training
includes hands-on experience with Next.js, covering server-side rendering (SSR), static site generation
(SSG), and API integrations for optimized web performance. Learners will also be introduced to TypeScript
with React for enhanced code maintainability. Additionally, the NOS covers unit testing fundamentals using
Jest, equipping students with the ability to write, execute, and analyze test cases for ensuring code
reliability. Through practical exercises, students will develop scalable and maintainable applications while
following industry best practices in modern JavaScript development.
Scope
The scope covers the following :
This NOS covers the development of interactive and scalable web applications using modern front-
end frameworks and best practices. It includes building user interfaces with ReactJS, leveraging
Next.js for optimized rendering strategies, and implementing unit testing methodologies to ensure
application reliability. The modules focus on component-based development, state management,
routing, data fetching, server-side capabilities, and testing strategies, providing a comprehensive
skill set for full-stack JavaScript development.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. • Demonstrate a solid understanding of React core concepts
• (components, state management, JSX, Virtual DOM).
PC2. • Build dynamic and responsive user interfaces (UIs) using React
• components with effective state management techniques (Redux,
• Zustand, or alternatives).
PC3. Effectively handle user interactions, data fetching from APIs, and navigation between views
within React applications.
PC4. Explain the advantages of Next.js over vanilla React and its overall approach to building web
applications.
PC5. • Structure Next.js projects effectively with pages, layouts, and
• implement routing for smooth user navigation.
PC6. • Implement different rendering approaches (SSG, SSR, CSR) within
• Next.js applications, understanding their use cases and performance
• implications.
PC7. • Utilize client and server components effectively within Next.js projects
• for a modular and performant architecture.
PC8. • Practice data fetching patterns, caching, revalidation techniques, and
• server actions within Next.js applications to optimize performance and maintainability

ASP/ITS/N0504: Building with Database: MongoDB for developers
Description
This NOS provides a comprehensive understanding of front-end web development using ReactJS and
Next.js, along with unit testing practices for robust software development. Learners will gain expertise in
building dynamic and reusable UI components, implementing state management solutions like
Redux/Zustand, and integrating client-side routing with React Router. The training includes setting up and
structuring Next.js applications, exploring different rendering techniques (SSG, SSR, CSR), and optimizing
performance using caching and revalidation strategies. Additionally, the NOS covers unit testing with Jest,
enabling students to write and execute effective test cases, leverage mock objects, and adopt test-driven
development (TDD) principles. Through practical implementation, students will develop scalable, high-
performance web applications that adhere to industry best practices.
Scope
The scope covers the following :
This NOS focuses on equipping learners with the skills to build, optimize, and test modern web
applications using ReactJS, Next.js, and unit testing methodologies. It covers interactive UI
development, state management, client-side and server-side rendering, data fetching strategies,
and testing best practices. The modules provide hands-on experience in developing scalable
applications, improving performance, and ensuring code reliability through structured unit testing.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. • Explain the concept of databases and their importance in web
• applications for data storage and retrieval.
PC2. Differentiate between relational and NoSQL databases, understanding the core principles of
MySQL and MongoDB.
PC3. Identify different MySQL storage engines and when to choose a specific engine for optimal
performance (basic understanding).
PC4. Demonstrate proficiency in creating and managing MySQL databases and tables using SQL
commands.
PC5. Write basic SQL queries to insert, update, delete, and retrieve data from MySQL tables.
PC6. Utilize the WHERE clause within SELECT statements to filter data based on specific conditions.
PC7. Explain the core concepts of MongoDB, including its document-oriented structure and key
differences from relational databases.
PC8. Create and manage MongoDB databases and collections using tools like the command line or
MongoDB Compass.v
PC9. Write basic queries using the find command and manipulate results using projection

ASP/ITS/N0505: NodeJS for Backend development
Description
This NOS provides a comprehensive understanding of database concepts, relational database
management using MySQL, and NoSQL database management with MongoDB. Learners will gain expertise
in designing normalized relational databases, writing complex SQL queries with JOINs and aggregate
functions, and managing database security. Additionally, they will explore NoSQL data modeling principles,
perform CRUD operations in MongoDB, and utilize advanced querying techniques, including aggregation
pipelines. The training also emphasizes best practices for database performance, user access control, and
security configurations. Through theoretical knowledge and practical implementation, learners will develop
the skills necessary for effective data storage, retrieval, and management in modern applications.
Scope
The scope covers the following :
This NOS focuses on equipping learners with essential database management skills, covering both
relational (MySQL) and NoSQL (MongoDB) databases. It includes database design, SQL query writing,
data manipulation, security implementation, and optimization techniques. The modules provide
hands-on experience in CRUD operations, schema modeling, data analysis, and database
administration for building scalable, secure, and efficient database solutions.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. • Demonstrate a solid understanding of Node.js fundamentals
• (event-driven architecture, non-blocking I/O) and its advantages for
• web development.
PC2. • Utilize modules effectively, manage packages with npm, and structure
• projects with clear organization (package.json).
PC3. • Build dynamic web applications using Express.js, implementing
• middleware, routing logic, handling user interactions (forms, queries),
• and connecting to databases.
PC4. • Integrate MongoDB with Node.js applications using Mongoose for
• Object Data Modeling (ODM) and perform CRUD operations (Create,
• Read, Update, Delete) effectively
PC5. • Demonstrate a solid understanding of Node.js fundamentals
• (event-driven architecture, non-blocking I/O) and its advantages for
• web development.
PC6. • Utilize modules effectively, manage packages with npm, and structure
• projects with clear organization (package.json).
PC7. • Describe various deployment options for Node.js applications (e.g.,
• Heroku, AWS) and strategies for scaling to handle increased workloads
• (horizontal & vertical scaling, load balancing).
PC8. • Identify and troubleshoot performance bottlenecks within Node.js
• applications using profiling tools.
