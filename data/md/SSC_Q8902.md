#### SSC/Q8902: 3D  Printing Software Developer
Brief Job Description
The job roles emphasize a comprehensive approach to software development within the 3D printing
industry, featuring requirements analysis, technical design, programming, and lifecycle management in
addition to essential employability skills. Professionals in these roles are expected to collaborate with
various stakeholders, possess strong analytical and technical skills, and adapt to the rapidly evolving
technology landscape in additive manufacturing.
Personal Attributes
This job requires the individual to have thorough knowledge of various technology trends and processes as
well as have updated knowledge about IT initiatives. He/she should be highly motivated and energetic with
the ability to self-direct daily activities.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N8907: Determine the functional, non-functional, and infrastructural requirements for the
defined scope of the software solution
2. SSC/N8908: Translate the 3dp processes into relevant application storyboards, technical wireframes, and data flows in the software architecture
3. SSC/N8909: Build high-performance software applications by developing embedded code, data structures and algorithms
4. SSC/N8910: Monitor, maintain and manage applications throughout the software development lifecycle
5. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### SSC/N8907: Determine  the functional, non-functional, and infrastructural
requirements for the defined scope of the software solution
Description
This unit is about analysing the business process outcomes and mapping all the technical requirements
which specify the behaviour and quality attributes of the software application
Scope
The scope covers the following :
Requirements Elicitation and Analysis,Functional requirements,Non- functional requirements,Data
Modelling ,Resource Identification,Infrastructure Design,System Integration,Technology
Integration,Infrastructure Management,Compliance and security,Scalability and Capacity
Planning,Service Level Agreements (SLAs)
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Collaborate effectively with cross-functional teams (designers, engineers, manufacturing,
marketing) to elicit and document comprehensive requirements. This includes understanding user needs, business goals, and technical constraints. Methods employed should include
interviews, workshops, surveys, and document analysis.
- PC2. Create a detailed requirements specification document covering both functional and non-
functional requirements, this should include use cases,user stories,functional requirements and non-functional requirements
- PC3. Create detailed description of the application's features and capabilities (e.g., slicing
algorithms, printer control, material management, error handling, post-processing support, data visualization, reporting, information sharing, etc.).
- PC4. Create specifications related to performance (speed, scalability, throughput), security
(authentication, authorization, data protection), reliability, usability, maintainability, and compliance (regulatory standards).
- PC5. Define the types and structures of data to be processed and stored by the application. This
includes designing the database schema and considering data integrity, consistency, and security.
- PC6. Identify and document all physical and virtual resources required for development,
deployment, and operation of the 3D printing application. This includes hardware (servers, printers, network equipment), software (operating systems, databases, middleware), and
personnel
- PC7. Define the application infrastructure (architecture, deployment environment, network
topology) necessary to support the 3D printing process. Address considerations such as high availability, scalability, and security
- PC8. Determine how the application will integrate with existing systems (e.g., CAD software, ERP
systems, cloud storage, other software applications). Detail the methods of integration (APIs, data exchange protocols, etc.) and address any interoperability challenges

#### SSC/N8908: Translate the 3dp processes into relevant application
storyboards, technical wireframes, and data flows in the software architecture
Description
This unit is about outlining the technical architecture and design patterns of the software applications in
form of conceptual elaboration and intuitive visualization of the production processes
Scope
The scope covers the following :
Storyboard development,Technical wireframing,Data flow diagraming,Architectural Design,Cloud
Integration,Microservices Architecture,System Integration,GUI development
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Create comprehensive storyboards depicting the user flow and key interactions within the 3D
printing application. These storyboards should illustrate different user scenarios and processes
at a high level. The storyboard should reflect the overall user experience
- PC2. Develop multiple versions of technical wireframes, focusing on key functionalities like slicing
modules, printer management, material management,post processing support,data visualization and information sharing
- PC3. Create detailed data flow diagrams illustrating the flow of information across the 3D printing
system. This should encompass data from input (3D models, parameters), through processing
(slicing, printer control), to output (printed object, status reports).
- PC4. Design the overall software architecture for a cloud-based 3D printing application that
integrates multiple systems
- PC5. Detail the integration with cloud storage services (AWS S3, Azure Blob Storage, etc.) for
storing and managing 3D models, print settings, and print results.
- PC6. Compare a microservices-based architecture to a monolithic architecture, justifying the choice
of architecture in the context of 3D printing, focusing on scalability, maintainability, and resilience. Identify specific services that would be suitable for decoupling (e.g., slicing, printer
control, post-processing).
- PC7. Document how the application integrates with external systems (e.g., CAD software, CAM
software, material databases).
- PC8. Develop a user-friendly graphical user interface (GUI) for interacting with the 3D printer’s
firmware. The GUI should allow users to control printer settings, monitor the print process, and
handle potential errors. Wireframes and mockups should be created and thoroughly tested
(usability testing is highly recommended).

#### SSC/N8909: Build high-performance software applications by developing
embedded  code, data structures and algorithms
Description
This unit is about developing an ecosystem of scalable and interoperable, service-oriented software
solutions for print-preparation and production processing
Scope
The scope covers the following :
Parameter Optimization,Simulation,Firmware Development,Code Development,Data
Integration,Software Integration,Deployment,File Import Enhancement,Security Implementation,Risk
Management,Application Optimization,Testing and Quality Assurance
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Develop algorithms for optimizing printing parameters (e.g., layer height, extrusion speed,
temperature) to improve print quality, speed, and material usage.
- PC2. Create algorithms for simulating the 3D printing process to predict outcomes and identify
potential problems before printing. This could include simulations of material flow, heat transfer, or structural integrity
- PC3. Design and develop firmware to be installed on 3D printers. The firmware should efficiently
control various aspects of the printer operation (Motion control, G-Code interpretation,Error handling)
- PC4. Design, develop, and maintain efficient, reusable, and reliable code modules. Adhere to
coding best practices (e.g., modular design, proper commenting, code reviews).
- PC5. Develop pipelines to extract and process data from multiple sources like databases,
knowledge bases
- PC6. Leverage API connections and scripts to seamlessly integrate with existing software
applications and packages (e.g., CAD software, cloud storage services).
- PC7. Develop and deploy software applications to both on-premise and cloud environments.
Address different deployment strategies and technologies (e.g., containerization, serverless functions).
- PC8. Identify methods to enhance file import capabilities, supporting a broader range of file
formats (STL, OBJ, etc.) and handling large files efficiently.
- PC9. Implement security measures to protect application data and prevent unauthorized access.
This might include data encryption, network security, authentication and Authorization
- PC10. Identify potential risks and threats (e.g., cybersecurity vulnerabilities, buffer overflow, data
corruption). Develop comprehensive mitigation plans to address these risks.
- PC11. Optimize the software application for performance, scalability, and resource utilization.
Incorporate techniques such as code optimization, database tuning, and caching. Address industry requirements for speed and efficiency
