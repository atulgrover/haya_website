#### NIE/SSC/Q0701: Full Stack Development Associate
Brief Job Description
The program enhances individuals' skills and promotes the responsible use of technology for broader
socio-economic growth. After completing the course, learners are prepared to work as Full Stack
Developers with a clear understanding of the entire website development process. They gain practical
knowledge in client-side scripting, website maintenance, front-end and back-end development, and
database integration. With additional experience, they may also handle server-side programming. A Web
Developer combines coding, design, and functionality to build user-friendly websites, requiring both
programming and basic graphic design skills.
Personal Attributes
The Full Stack Development Associate course encourages the development of key personal attributes
essential for success in the IT industry. Learners are expected to demonstrate analytical thinking and
problem-solving abilities to design effective and logical solutions. A strong attention to detail is crucial,
particularly when writing and debugging code or designing user interfaces. Creativity plays a vital role in
building visually appealing and user-friendly web applications. The course also nurtures adaptability and a
continuous learning mindset, enabling learners to keep pace with evolving technologies. Effective
communication, time management, and the ability to work collaboratively in teams are emphasized
throughout the program. Additionally, learners are encouraged to uphold professional ethics, practice
responsible use of technology, and exhibit self-motivation in completing tasks and contributing to real-
world projects.
Applicable National Occupational Standards (NOS)
Compulsory NOS:

4. DGT/VSQ/N0101: Employability Skills (30 Hours)

#### NIE/ITS/N0705: Design and Development  of Front-End Application and
managing  and maintaining web source code--
Description
This NOS focuses on developing skills to design and maintain front-end components of responsive
websites. Learners will gain proficiency in using HTML5 for structuring content, CSS and Bootstrap for
styling and layout, and JavaScript for interactivity and user input validation. It includes hands-on training
with code editors and understanding key web concepts like URLs, IP addresses, and client-server
architecture. The module also covers modern JavaScript (ES6+), DOM manipulation, and local storage. By
the end, learners can build dynamic, user-friendly web interfaces following industry standards.
Scope
The scope covers the following :
This NOS covers the skills required to design and develop static and responsive websites using HTML5, CSS, Bootstrap, and JavaScript. It includes understanding internet concepts, structuring web
pages, applying styles and layouts, and adding interactivity through client-side scripting. The scope
also includes using modern editors and ensuring basic form validations and responsiveness across
devices.
#### Elements and Performance Criteria

- PC5. Create, edit, and save HTML/CSS/JS files using editors.
- PC6. Organize project folder structures.
Design Web Pages Using HTML
#### To be competent, the user/individual on the job must be able to:

- PC8. Apply formatting tags (bold, italic, underline, etc.).
- PC9. Insert images, paragraphs, comments, hyperlinks, and named anchors.
Style Web Pages Using CSS

- PC10. Identify and apply different types of CSS (inline, internal, external).

#### NIE/ITS/N0703: Database connectivity with MySQL and Dynamic  Web
Application Development using Django and Front-end
Technologies(HTML/CSS/  JavaScripts/Bootstrap)
Description
This syllabus equips learners with the skills to develop, manage, and deploy secure, database-driven web
applications using the Django framework and MySQL. It covers foundational knowledge of RDBMS, database connectivity, Django's MVT architecture, ORM, and user authentication. Learners gain hands-on
experience in form handling, admin interface management, and integrating Bootstrap for responsive
design. The scope includes project development, deployment practices, and implementing security
features aligned with industry standards, preparing individuals for full-stack web development roles.
Scope
The scope covers the following :
This syllabus equips learners with the skills to develop, manage, and deploy secure, database-driven
web applications using the Django framework and MySQL. It covers foundational knowledge of RDBMS, database connectivity, Django's MVT architecture, ORM, and user authentication. Learners
gain hands-on experience in form handling, admin interface management, and integrating Bootstrap
for responsive design. The scope includes project development, deployment practices, and implementing security features aligned with industry standards, preparing individuals for full-stack
web development roles.
#### Elements and Performance Criteria
Set Up Django Environment and Project Structure
#### To be competent, the user/individual on the job must be able to:
- PC1. Install Django and create projects and apps using the command-line interface.
- PC2. Understand the MVT architecture and role of manage.py, settings.py, and urls.py.
- PC3. Configure URL routing and render views and templates correctly.
Design Front-End Using Templates and Static Files
#### To be competent, the user/individual on the job must be able to:
- PC4. Use Django templates to display dynamic content and extend base layouts.
- PC5. Include static assets (CSS, JS, images) using {% static %} and integrate Bootstrap.
