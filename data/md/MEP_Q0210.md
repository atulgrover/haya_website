MEP/Q0210: Hindi Typist
Brief Job Description
A Hindi typist is responsible for formatting and typing various types of documents in Hindi with speed and
accuracy. The individual is involved in typing letters, reports, forms, correspondence, policies, tabular
statements, or other documents from rough drafts, handwritten copies, dictated notes, or voice recordings
using word processing software or typewriter. The individual also checks documents for errors in spelling,
grammar, punctuation and format, and corrects identified errors.
Personal Attributes
The individual must be well-groomed, attentive, comfortable with multi-tasking and disciplined. The
individual must have good communication skills and be attentive to detail with an ability to spot grammar,
spelling and punctuation errors. The individual must also have dexterity of hands and fingers, clarity of
vision, and verbal, auditory and written capabilities. The individual must have a positive attitude and the
ability to work in a team.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
- 1. MEP/N0216: Use computers to store, retrieve and communicate information
- 2. MEP/N0236: Install and use various Hindi fonts and typing tools
- 3. MEP/N0238: Prepare various types of Hindi documents
- 4. MEP/N0239: Proofread Hindi documents
- 5. MEP/N0241: Maintain records and documentation
- 6. MEP/N9903: Apply health and safety practices at the workplace
- 7. MEP/N9912: Apply principles of professional practice at the workplace
- 8. DGT/VSQ/N0102: Employability Skills (60 Hours)
Options(Not mandatory):
Option : Hindi Shorthand / Stenography
This unit covers the skills required for taking shorthand notes and producing accurate and correct text in
an agreed format. It includes checking the content of document for accuracy and correcting text as
necessary and storing both the text and the original shorthand notes safely and securely.

MEP/N0216: Use computers to store, retrieve and communicate
information
Description
This unit deals in detail with storing, retrieval and communication of information using computers
Scope
The scope covers the following :
Retrieve and Manage Information using Digital Systems and AI Tools
Store information using word processors and spread sheets
Manage digital communication and ensure safe use of technology
Work safely and securely with technology
Elements and Performance Criteria
Retrieve and Manage Information using Digital Systems and AI Tools
To be competent, the user/individual on the job must be able to:
PC1. Recognize different operating systems, cloud storage platforms, and AI-driven applications
used for storing and retrieving data.
PC2. Use computer drives, cloud storage, and AI search features to locate files, data, and
documents quickly and accurately
PC3. Use AI tools and automated systems to quickly find, organize, label, and safely store digital
files, while following the organization’s rules for data access and security
Store information using word processors and spreadsheets
To be competent, the user/individual on the job must be able to:
PC4. Enter, edit, and save data or information (letters, reports, tables, etc.) using word processors,
spreadsheets, and AI-enabled digital tools.
PC5. Format, design, and present information professionally using features like templates, styles,
references, review tools, and AI-assisted formatting.
PC6. Apply basic and AI-supported formulas, functions, charts, and data visualization techniques
in spreadsheets to simplify data presentation.
PC7. Follow organizational data policies on file naming, backups, privacy, and cyber security while
using digital and AI tools.
Manage digital communication and ensure safe use of technology
To be competent, the user/individual on the job must be able to:
PC8. Use computers to prepare and share information through printouts, reports, or digital
formats.
PC9. Communicate using emails, AI-powered writing assistants, or workplace collaboration tools
(e.g., MS Teams, Slack, Google Workspace) while following security rules.
PC10. Ensure compliance with organizational data security and privacy policies while sharing files
or messages.
Work safely and securely with technology

MEP/N0236: Install and use various Hindi fonts and typing tools
Description
This unit is about acquiring knowledge about Unicode system and using various Hindi typing tools in
computer.
Scope
The scope covers the following :
This unit/ task covers the following:
Acquire knowledge of Unicode system and Unicode encoded Hindi fonts
Install and use Hindi typing tools in computer
Elements and Performance Criteria
Acquire knowledge of Unicode system and Unicode encoded Hindi fonts
To be competent, the user/individual on the job must be able to:
PC1. Understand how the Unicode system operates across multiple platforms, devices, and
operating systems (Windows, macOS, Android, iOS) to enable seamless exchange of Hindi
text.
PC2. Identify and compare Unicode and non-Unicode (ASCII) fonts and recognize compatibility
issues in cloud documents or PDFs.
PC3. Select correct Unicode encoded Hindi font as per organizational requirement and perform the
typing tasks in Hindi
PC4. Enable and configure Hindi language input in various versions of operating systems and
applications (e.g., Microsoft Windows, Google Docs, and cloud-based editors) in line with
organizational procedures.
Install and use Hindi typing tools in computer
To be competent, the user/individual on the job must be able to:
PC5. Download and install Unicode-encoded Hindi fonts from verified and licensed sources
following safe download practices.
PC6. Input data using Input Method Editors (IMEs) and digital input tools, including Google Input
Tools, Bhashini, and Indic Keyboard, to improve typing flexibility.
PC7. Install or activate Microsoft Indic Language Input Tool and similar AI-based predictive typing
utilities for Hindi input.
PC8. Type text in Hindi using English QWERTY keyboard layouts such as INSCRIPT, Phonetic, or
Remington, ensuring accuracy and speed.
PC9. Use cloud-based transliteration and voice typing options (e.g., Google Voice Typing, Speech-
to-Text) to enhance productivity.
PC10. Ensure secure handling and storage of digital Hindi fonts and typing tool settings as per
organizational IT and cybersecurity policy.
Knowledge and Understanding (KU)

Description
This unit covers the skills required for taking shorthand notes and producing accurate and correct text in
an agreed format. It includes checking the content of document for accuracy and correcting text as
necessary and storing both the text and the original shorthand notes safely and securely.
Scope
The scope covers the following :
Take dictation/notes and record in Hindi using shorthand technique
Transcribe Hindi shorthand documents
Elements and Performance Criteria
Take dictation/notes and record in Hindi using shorthand technique
To be competent, the user/individual on the job must be able to:
PC1. Acquire proficiency in shorthand using both traditional and digital stenography tools (Pitman-
style or Hindi Steno apps such as StenoKing, BharatShorthand, or Dictation.io
PC2. Use voice recognition and AI transcription software (Google Recorder, Otter.ai, Microsoft 365
Dictate, Whisper AI) to capture Hindi dictations.
PC3. Apply phraseography and logogram techniques while integrating digital shorthand stylus or
#### tablets for notetaking
PC4. Record, tag, and organize shorthand notes digitally in cloud folders (Google Drive/OneDrive)
for retrieval.
Transcribe Hindi shorthand documents
To be competent, the user/individual on the job must be able to:
PC5. Transcribe Hindi shorthand using speech-to-text software or manual typing in Unicode
PC6. Use AI grammar and formatting tools (Grammarly, Quillbot, ChatGPT) to refine Hindi text
before submission
PC7. Compare versions using Track Changes/Version History to ensure accurate transcription
PC8. Ensure data confidentiality by encrypting digital shorthand and recordings
PC9. Perform proofreading and correct the identified errors including using digital review tools
(Comments, Suggest mode)
PC10. Store both shorthand notes and transcribed text securely on digital platforms following
organizational naming and archiving protocols.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Organizational policies and priorities
