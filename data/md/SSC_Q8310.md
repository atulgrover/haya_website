SSC/Q8310: Cloud Computing
Brief Job Description
Individuals at this job are responsible for designing and implementing information technology
infrastructure in a public cloud environment and also the business and functionality for architecting
infrastructure design.
Personal Attributes
Individuals must be able to communicate effectively. They must have strong interpersonal skills, analytical
mindset and a zeal to learn new things.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
- 1. SSC/N8339: Work organization and management for cloud computing

SSC/N8339: Work organization and management for cloud computing
Description
Work organization and management for cloud computing
Scope
The scope covers the following :
Work organization and management for cloud computing
Elements and Performance Criteria
Work organization and management
To be competent, the user/individual on the job must be able to:
PC1. identify common deployment models with public cloud providers and how those models can
apply to organization-specific requirements.
PC2. identify opportunities and create migrations plans to phase-in public cloud deployments and
reduce risks.
PC3. create highly available, scalable, and secure IT architectural designs specific to each
application, taking into account compute, storage, networking, database management, and
deployment requirements
PC4. take advantage of public cloud provider solutions to reduce operational burden associated
with service deployments

SSC/N8341: Communication and interpersonal skills for cloud computing
Description
Communication and interpersonal skills for cloud computing
Scope
The scope covers the following :
Communication and interpersonal skills for cloud computing
Elements and Performance Criteria
Communication and interpersonal skills for cloud computing
To be competent, the user/individual on the job must be able to:
PC1. discover and document key requirements and how they relate to public cloud offerings.
PC2. discover and document technology-specific opportunities to leverage public cloud offerings

PC4. clearly map departmental and technology-specific requirements and goals to public cloud
solutions

transition to public cloud resources

SSC/N8342: Problem solving, innovation, and creativity
Description
Problem solving, innovation, and creativity
Scope
The scope covers the following :
Problem solving, innovation, and creativity
Elements and Performance Criteria
Problem solving, innovation, and creativity
To be competent, the user/individual on the job must be able to:
PC1. evaluate, select, and implement foundational cloud computing services such as compute,
network, and storage
PC2. evaluate, select, and implement advanced cloud computing services such as managed data
services, caching services, and automated scaling and availability features.
PC3. evaluate, select, and implement various network-related technologies to infrastructure design
such as network communication protocols, sub netting, NAT, DNS, VPN, broadcast networking,
and dynamic routing protocols
PC4. automate infrastructure creation and modification through the use of scripting or
programming, and the use of infrastructure templates

SSC/N8343: Cybersecurity
Description
Cybersecurity
Scope
The scope covers the following :
Cybersecurity
Elements and Performance Criteria
Cybersecurity
To be competent, the user/individual on the job must be able to:
PC1. design and implement authentication processes at departmental and organizational level,
controlling access to public cloud administrative capabilities and system access.
PC2. develop policies and procedures for systems and application access to public cloud interfaces
and services.
PC3. implement policies and procedures for auditing of public cloud activities and access.
PC4. create internal prescriptive guidance and requirements for procedures necessary to create,
update, remove and access public cloud infrastructure and resources.
PC5. implement service and technology specific security controls on resources running within a
public cloud environment as well as utilization of services provided by an IaaS vendor.
PC6. engage with business, development, and leadership staff to identify, recommend, and
implement security best practices while ensuring an efficient user experience.
NSQC Approved || IT-ITeS SSC NASSCOM 14

SSC/N8344: Reliability, scalability, and elasticity
Description
Reliability, scalability, and elasticity
Scope
The scope covers the following :
Reliability, scalability, and elasticity
Elements and Performance Criteria
Reliability, scalability, and elasticity
To be competent, the user/individual on the job must be able to:
PC1. record, analyse, and interpret application, system, and network data to facilitate the
recommendation of an appropriate architecture that sufficiently utilizes scalability and
elasticity to meet the variable demands of internal and external users and systems.
PC2. implement different availability, scalability, and durability models in accordance with
application and system design requirements
PC3. design availability models that meet the business requirements of an organization, taking into
account allowed recovery time and allowable service interruption parameters
PC4. utilize public cloud services and features to aid the design and deployment of availability,
durability, and scalability requirements.

SSC/N8345: Performance and optimization
Description
Performance and optimization
Scope
The scope covers the following :
Performance and optimization
Elements and Performance Criteria
Performance and optimization
To be competent, the user/individual on the job must be able to:
PC1. analyse and interpret performance metrics from compute, storage, network, and application
levels for use in public cloud infrastructure design objectives.
PC2. utilize performance tuning techniques and packages to ensure optimal resource utilization
PC3. implement microservice strategies to capitalize on technology advances in areas like
container development.
PC4. pursue the decoupling of services to allow the separation of application components to
facilitate a service-oriented architecture.
PC5. recommend and implement database and storage solutions that best fit the needs of an
application.
PC6. implement serverless architecture

Operational considerations

Operational considerations

Sustainability
To be competent, the user/individual on the job must be able to:

PC7. review the implications for sustainability of using managed services across a wide customer
base
