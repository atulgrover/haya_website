#### HAR/ITS/N0910: IT Foundation and Digital Tools (CWT)
Description
The NOS provides basic knowledge and skills to operate computer and prepares you to perform basic
office jobs.
Scope
The scope covers the following :
The NOS builds essential skills in Word, Excel, PowerPoint, and Internet usage, preparing students
for basic office tasks and serving as a foundation for advanced computer applications.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Understand the meaning, characteristics, history, generations, and classification of
computers.
- PC2. Identify and explain the main components, input/output devices, and the working of a
computer system.
- PC3. Differentiate between data and information, and perform basic number conversions.
- PC4. Demonstrate understanding of operating systems, including the settings and functions of
Windows..
- PC5. Diagnose and resolve common peripheral malfunctions and connectivity issues.
- PC6. Create and edit documents using word processing tools with proper formatting and layout.
- PC7. Apply formulas and functions in spreadsheets and use spreadsheet tools effectively.
- PC8. Design and present information visually using digital presentation software.
- PC9. Develop correct typing posture and accuracy with improved speed.
- PC10. Utilize networking and internet skills to communicate online, manage email accounts, ensure
cybersecurity, and understand cloud storage
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Demonstrates understanding of the evolution, characteristics, and classification of computers,
including their historical development and technological generations.
- KU2. Identifies and explains the main hardware components, input/output devices, and the overall
functional process of a computer system.
- KU3. Explains the purpose, functions, and configuration of operating systems, particularly Windows,
in managing computer resources and settings.
- KU4. Understands methods for diagnosing and resolving common hardware, peripheral, and connectivity issues within a computer system.

#### HAR/ITS/N1702: Frontend  Development: Building Responsive Websites
Description
This NOS provides knowledge and practical skills in frontend web development using HTML, CSS,
JavaScript, jQuery, and XML for creating interactive and responsive websites.
Scope
The scope covers the following :
The scope includes designing and developing responsive web pages using HTML5, CSS2/CSS3,
JavaScript, Bootstrap, and jQuery. It also covers XML concepts, document validation, DOM manipulation, form handling, media integration, responsive layouts, animations, and interactive web
functionalities for modern web applications.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Create and format web pages using HTML, CSS, and HTML5 elements including forms,
multimedia, tables, and responsive design features.
- PC2. Develop responsive web pages using viewport settings, grid systems, media queries, images,
videos, and Bootstrap framework.
- PC3. Apply CSS styling techniques and JavaScript programming concepts to develop interactive and
dynamic web pages.
- PC4. Use XML, DTD, XML Schema, XPath, and XQuery concepts for structuring, validating, and
querying XML documents.
- PC5. Implement JavaScript concepts including variables, functions, loops, events, BOM, DOM
manipulation, and form validation in web applications.
- PC6. Use jQuery syntax, selectors, events, effects, traversing, and AJAX features to create
interactive web interfaces.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. the concepts, principles, tools, and technologies used in frontend web development including
HTML, CSS, JavaScript, jQuery, XML, and responsive web design.
- KU2. webpage structuring, styling techniques, client-side scripting, DOM manipulation, XML validation, responsive layouts, and interactive web application development.
- KU3. the role of frontend web development in website creation, digital communication, and user experience enhancement across industries.
- KU4. to apply web development standards, coding practices, responsive design principles, and quality assurance procedures followed in software and web development environments.
#### Generic Skills (GS)

#### HAR/ITS/N1701: UX/UI Design with Figma and Web  Application
Frameworks
Description
This NOS provides knowledge and practical understanding of UX/UI design concepts using Figma and the
fundamentals of web application frameworks.
Scope
The scope covers the following :
The scope includes designing user interfaces and prototypes using Figma tools and understanding
UX/UI principles for enhancing user experience.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Explain the concepts, similarities, and differences between User Experience (UX) and User
Interface (UI) design.
- PC2. Use Figma tools and interface features to create wireframes, layouts, and high-fidelity mock-
ups for web and mobile applications.
- PC3. Apply UX/UI design principles to develop user-friendly, visually appealing, and interactive
interface designs.
- PC4. Explain the purpose, structure, and types of web application frameworks used in frontend and
backend development.
- PC5. Differentiate between Content Management Systems (CMS) and web application frameworks
based on functionality and usage.
- PC6. Describe MVC architecture and its workflow involving Model, View, and Controller components
in application development.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. the concepts, principles, tools, and techniques of UX/UI design, wireframing, prototyping, and
high-fidelity mock-up creation using Figma.
- KU2. web application frameworks, MVC architecture, frontend and backend frameworks, and their role in developing modern web applications.
- KU3. the importance of UX/UI design and web application frameworks in enhancing user experience, application performance, and digital business solutions.
- KU4. to apply design standards, development practices, collaboration methods, and workflow processes followed in web design and software development environments.
#### Generic Skills (GS)

#### HAR/ITS/N0802: OJT/ Project & Viva (1)
Description
The NOS enabling students to apply their acquired skills and knowledge in real work or job-oriented
environments.
Scope
The scope covers the following :
Provides practical exposure, enhance skills, and prepare students for real work environments by
bridging the gap between theory and practice
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
