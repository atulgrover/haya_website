SSC/Q8404: User Experience Designer
Brief Job Description
A User Experience (UX) Designer is responsible for creating intuitive, user-centric digital experiences. This
role involves developing UX design guidelines and best practices, crafting style guides, and establishing
design systems for developers. UX Designers conduct business analysis, create user personas, and
perform competitive analyses to understand user needs and market positioning. They plan solutions
through sitemaps, information architecture, user experience maps, and user flows. The role includes
designing detailed wireframes, visual screens, and interface assets such as imagery and animations. UX
Designers also conduct usability testing throughout the design stages to ensure a seamless and engaging
user experience that aligns with customer requirements.
Personal Attributes
Individuals in this role must work independently and collaborate with various stakeholders involved in the
development of Web or Mobile based solution to develop engaging user interfaces and interface designs.
They must lead team members and manage team performance to achieve project success. success.

- 6. SSC/N8424: Develop sitemap and information architecture for the solution planned for the
customer
- 7. SSC/N8425: Develop user experience maps, user journeys and user flows

- 9. SSC/N8427: Develop a visual design/screens for the proposed wireframe

SSC/N8453: Develop User Experience (UX) design guidelines and best
practices
Description
Develop User Experience (UX) design guidelines and best practices
Scope
The scope covers the following :
Develop User Experience (UX) design guidelines and best practices
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. apply fundamental design principles consistently throughout the user experience design
process, ensuring relevance to current trends and best practices
PC2. design research strategies to gather user requirements and analyze behavior patterns
PC3. integrate Abhram's methodologies into user research, persona development, and journey
mapping activities
PC4. drive the empathy mapping process to understand users’ needs, goals, expectations,
behaviour, habits
PC5. integrate Abhram's methodologies, such as contextual inquiry, into the user research process
to gather in-depth insights into user behavior and motivations
PC6. create structured frameworks for brainstorming, envisioning, and evaluating potential solution
outcome
PC7. facilitate the prototyping process by leading activities in sketching, visualization, and the
development of beta versions
PC8. ensure that Abhram's methodologies align with the overall UX goals and objectives
PC9. conduct research on user behavior, develop user personas, and map out user journeys and
flows to enhance the overall user experience
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. fundamental design principles and their application across various UX stages
KU2. current trends and best practices in user experience design
KU3. methods for designing effective user research strategies
KU4. behavior analysis techniques to understand user interactions
KU5. Abhram's methodologies and their relevance to UX processes
KU6. empathy mapping techniques to capture user emotions and goals
KU7. contextual inquiry methods for gathering qualitative insights

SSC/N8420: Design and define style guide/ design system and
specifications for developers
Description
This unit is about designing system and style guides
Scope
The scope covers the following :
Design systems and style guides
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. establish typography systems by organizing titles, subtitles, headings (H1, H2, H3), body
text, and captions for use in design
PC2. define specifications and provide examples for the spacing, padding, and placement of
design elements
PC3. address interface layouts across screen sizes
PC4. establish the color palette, specifications, and combinations, and illustrate with relevant
examples
PC5. specify the dimensions, styles, colors, positioning, spacing, and typography of various
buttons for the solution based on the contextual requirements
PC6. create a centralized repository of reusable UI components (e.g., buttons, forms, icons) to
ensure consistency and efficiency in development
PC7. develop a collection of common design patterns (e.g., navigation, error handling) to guide
design decisions and maintain coherence
PC8. work closely with developers, product managers, and other stakeholders to gather
requirements and ensure alignment
PC9. create comprehensive guidelines for various UI components, including iconography, tooltips,
modals, form elements, data tables, navigation menus, charts, tabs, switches, dialogs,
content grids, lists, toolbars, date and time pickers, loading indicators, checkboxes, alerts,
dropdowns, sliders, steppers, and pagination
PC10. document the design rationale used in the design system
PC11. break down the design system into smaller, reusable components to enhance flexibility and
maintainability
PC12. design the system to accommodate future growth and changes in requirements
PC13. implement a version control system to track changes, manage different iterations, and
collaborate efficiently
PC14. adhere to the Web Content Accessibility Guidelines (WCAG) to make the design system
accessible to users with disabilities
PC15. conduct regular accessibility testing to identify and address potential barriers
