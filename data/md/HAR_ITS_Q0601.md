Description
Provides the knowledge of fundamental concepts of computers.
Scope

HAR/ITS/N0605: Querying and Managing data with SQL
Description
provides knowledge of SQL (Structured Query Language) for querying and managing data in relational
database.
Scope
The scope covers the following :
Equips learners with the skills to analyze, query, and manage data in relational database.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Define and differentiate database and Relational database management system.
PC2. Describe SQL syntax, data types, operators, expression etc.
PC3. Explain and use various SQL queries to Insert and manipulate data in database.
PC4. Describe and use various keys in database (candidate key, primary key, alternate key and
foreign key) and differentiate between them
PC5. Explain and use different types of Joins to retrive data from two or more tables
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Tables, relationships, keys (primary, foreign, and unique), and normalization.
KU2. Operations like INSERT, UPDATE, DELETE, and SELECT.
KU3. The objective and goal of Organisation and scope of work.
KU4. Ensuring efficient and secure handling of organizational data.
Generic Skills (GS)
User/individual on the job needs to know how to:
GS1. Effectively present data in reports and presentations derived from SQL queries.
GS2. Collaborate and discuss with teams to define data requirements and solutions.
GS3. Structure databases and queries to meet project timelines and organizational needs.
GS4. Troubleshoot query performance issues and resolving data inconsistencies.
