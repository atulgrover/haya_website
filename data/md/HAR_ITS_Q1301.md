HAR/ITS/N0902: IT Foundation and Digital Tools
Description
The NOS provides basic knowledge and skills to operate computer and prepares you to perform basic
office jobs.
Scope
The scope covers the following :
The NOS builds essential skills in Word, Excel, PowerPoint, and Internet usage, preparing students
for basic office tasks and serving as a foundation for advanced computer applications.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Understand the meaning, characteristics, history, generations, and classification of
computers.
PC2. Identify and explain the main components, input/output devices, and the working of a
computer system.
PC3. Differentiate between data and information, and perform basic number conversions.
PC4. Demonstrate understanding of operating systems, including the settings and functions of
Windows..
PC5. Diagnose and resolve common peripheral malfunctions and connectivity issues.
PC6. Create and edit documents using word processing tools with proper formatting and layout.
PC7. Apply formulas and functions in spreadsheets and use spreadsheet tools effectively.
PC8. Design and present information visually using digital presentation software.
PC9. Develop correct typing posture and accuracy with improved speed.
PC10. Utilize networking and internet skills to communicate online, manage email accounts, ensure
cybersecurity, and understand cloud storage
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Demonstrates understanding of the evolution, characteristics, and classification of computers,
including their historical development and technological generations.
KU2. Identifies and explains the main hardware components, input/output devices, and the overall
functional process of a computer system.
KU3. Explains the purpose, functions, and configuration of operating systems, particularly Windows,
in managing computer resources and settings.
KU4. Understands methods for diagnosing and resolving common hardware, peripheral, and
connectivity issues within a computer system.

HAR/ITS/N0903: Digital Communication & Collaboration
Description
The NOS provides professional communication skills using tools like Google Meet and Google Docs for
workplace collaboration and online interaction.
Scope
The scope covers the following :
Builds skills in digital communication and collaboration using tools like Google Meet and Google
Docs.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Understand Instant Messages, types and features of Instant Messages.
PC2. Know the benefit of Video Conferencing and various devices and apps used in Video
Conferencing.
PC3. Know the various social media platforms
PC4. Know about Google workspace and various Google Collaboration Tools.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Types of instant messaging used for personal and professional communication.
KU2. Uses of video conferencing, including required devices and applications such as Google Meet
and Zoom.
KU3. Meaning, advantages, disadvantages, and responsible use of social media platforms
KU4. Features and functions of Google Workspace including Gmail, Google Calendar, and Google
Meet
KU5. Creating and managing files using Google Docs, Google Sheets, Google Slides, and Google
Forms.
Generic Skills (GS)
User/individual on the job needs to know how to:
GS1. Organize and prioritize tasks to manage time efficiently and meet deadlines
GS2. Work collaboratively in a team, contributing to shared goals and helping others when needed
GS3. Handling technical issues during online meetings or collaboration tasks.
GS4. Follow instructions accurately and work independently when required

HAR/ITS/N1201: Creating Website using HTML, CSS and JavaScript
Description
Provides knowledge and skills to create web pages using HTML, CSS and JavaScript
Scope
The scope covers the following :
The NOS covers the fundamental skills required to create, design, and validate interactive web
pages.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Create web pages using HTML and CSS.
PC2. Use HTML elements, tags & attributes.
PC3. Create lists, links, and tables using HTML tags
PC4. Make WebPages more attractive using CSS
PC5. Understand JavaScript basics- variables, functions, and control structures
PC6. Create interactive web pages using Javascript.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Basic structure of web pages (HTML elements, tags, attributes)
KU2. CSS styling techniques: inline, internal, and external stylesheets
KU3. Core JavaScript concepts: variables, data types, operators, loops, and functions
KU4. Debugging and error handling in JavaScript.
Generic Skills (GS)
User/individual on the job needs to know how to:
GS1. Analyze client requirements and design solutions that meet functional needs.
GS2. Clearly communicate ideas and requirements to team members and clients.
GS3. Manage time and priorities to meet project deadlines.

Description
Provides knowledge of AI and ChatGPT and their applications in daily tasks.

PC1. Understand the meaning of AI and Chatgpt

PC3. Use Chatgpt for various tasks

KU1. Concepts and meaning of Artificial Intelligence (AI)
KU2. to use ChatGPT for tasks like content generation, problem-solving, research, and automation

Generic Skills (GS)
User/individual on the job needs to know how to:
GS1. Analyze tasks and determine how AI and ChatGPT can provide solutions.
GS2. Apply AI solutions responsibly.
GS3. Apply ethical considerations in AI usage, including privacy, security, and fairness, to ensure
responsible and compliant implementation
GS4. Manage time efficiently to integrate AI solutions into workflows.
