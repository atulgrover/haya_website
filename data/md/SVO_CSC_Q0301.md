SVO/CSC/N0301: Fundamentals of CNC Lathe Programming
Description
This NOS unit covers identifying NC/CNC machine program elements, writing and trialling a machine
program for CNC lathe machine, and preparing an operation sheet.
Scope
The scope covers the following :
Preparatory activities for programming, write CNC Lathe program and testing and trial run of
program.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. follow standard operating procedures (SOPs)
PC2. • read, interpret and follow the information on written job instructions, specifications, SOPs, part
• information, CNC lathe machining process plan/sheet, charts, lists, drawings and other
applicable
• reference documents to obtain job requirements, tasks and relevant informatio
PC3. • determine the machining operations and processing sequence to be performed on the CNC
lathe

• speed, machining tolerances, etc. from the sketches, job sheets, process plan/sheet etc.

clamping
• and positioning method, workholding device, tool requirements from the tooling layout, cutting
• process etc. from the available documents and information and assess their suitability

Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. organisation procedures for health, safety and security, individual role and responsibilities in
this context
KU2. elements of a NC/CNC program
KU3. function of elements in controlling the operation of a NC/ CNC machine
KU4. machining operations to be performed in the manufacture of the given part or product
KU5. appropriate type(s) of NC/CNC machine to perform the required machining operations
KU6. machining operations to be controlled by the program to be written
KU7. tool path(s) to be followed when producing the part or product
KU8. sequence of machining operations to be programmed
KU9. reasons for selecting the chosen tool path(s) and sequence of operations
KU10. zero point of the NC/CNC machine
KU11. canned cycles and sub-routines accessible in the particular NC/CNC machine
KU12. application of each canned cycle and sub-routine available
KU13. canned cycles and/or sub-routines to be used in the NC/CNC program
KU14. reasons for selecting the chosen canned cycles and/or sub-routines
KU15. standard codes i.e. D, F, G, M, N, S and T used in the writing of NC/CNC programs
KU16. applications of standard codes in NC/CNC programming
KU17. procedures for writing NC/CNC programs in standard code format
KU18. procedures for completing NC/CNC operation sheets
KU19. information to be included in NC/CNC operation sheets
KU20. procedures for manual operation of the NC/CNC machine
KU21. reasons for testing and proving the NC/CNC program
KU22. procedures for editing the NC/CNC program via the machine controller

| Sub-sector | Sub-sector is derived from a further breakdown based on the characteristics and interests of its components. |
| Occupation | Occupation is a set of job roles, which perform similar/ related set of functions in an industry. |
| Job role | Job role defines a unique set of functions that together form a unique employment opportunity in an organisation. |
| Occupational Standards (OS) | OS specify the standards of performance an individual must achieve when carrying out a function in the workplace, together with the Knowledge and Understanding (KU) they need to meet that standard consistently. Occupational Standards are applicable both in the Indian and global contexts. |
| Performance Criteria (PC) | Performance Criteria (PC) are statements that together specify the standard of performance required when carrying out a task. |
| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |
| Qualifications Pack (QP) | QP comprises the set of OS, together with the educational, training and other criteria required to perform a job role. A QP is assigned a unique qualifications pack code. |
| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
