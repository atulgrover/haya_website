LSS/Q2202: Computerized Pattern Stitching Machine Junior Technician
Brief Job Description
The individual is to perform stitching operations with the required quality of the footwear or goods &
garments using computerized stitching machine and also the person can programm the machine to
execute the stitching operations.
Personal Attributes
Stitcher should perform the stitching operations with good hand, leg, and eye coordination and should
have good psychomotor skills
Applicable National Occupational Standards (NOS)
Compulsory NOS:
- 1. LSS/N2210: Preparation of materials and Computerized stitching machine for stitching operations
- 2. LSS/N2211: Perform program for the stitching operations
- 3. LSS/N2212: Inspect jigs and fix them on the machine
- 4. LSS/N2213: Operate the computerized pattern stitching machine with the required quality
- 5. LSS/N8601: Maintain health, safety & security, a clean work area & equipment, use optimized
resources at the workplace, and comply with industry & organizational Requirements
- 6. DGT/VSQ/N0101: Employability Skills (30 Hours)

LSS/N2210: Preparation of materials and Computerized stitching machine
for stitching operations
Description
This unit is about the preparation of raw materials and other tools and equipment required for
computerized pattern stitching operations
Scope
The scope covers the following :
Prepare the materials
Prepare the computerized pattern-stitching machine
Elements and Performance Criteria
Prepare the materials
To be competent, the user/individual on the job must be able to:
PC1. check the raw materials based on the specifications like color, thickness, area, etc.,
PC2. handle the raw materials carefully and avoid any damages to the raw materials
PC3. check the materials used are free from faults
PC4. follow the instructions on the work order or job card
PC5. arrange the material as per the specification
PC6. store the raw materials as per specification
PC7. report and document the fault materials
PC8. ensure the work area is free from hazards and wastes
Prepare the computerized pattern-stitching machine
To be competent, the user/individual on the job must be able to:
PC9. examine the machine for any safety-related issues and readiness for use
PC10. check the air connections from compressor is connected correctly
PC11. check the pedal and levers are connected correctly
PC12. set the machine with correct needle, thread and speed as per the requirements
PC13. test run the machine and chek the emergency stop is working perfectly
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. properties of leather and non-leather materials
KU2. specifications given by the raw material manufacturers
KU3. the difference between lock stitch and chain stitch
KU4. the different types of needles and threads

LSS/N2211: Perform program for the stitching operations
Description
This unit is about the performing program in a computerized pattern stitching machine and loading the
external program into the machine
Scope
The scope covers the following :
Make a program on the computerized pattern-stitching machine
Load the external program into the machine
Elements and Performance Criteria
Make a program on the computerized pattern-stitching machine
To be competent, the user/individual on the job must be able to:
PC1. determine the job specifications and operational objectives by referring to job cards,
approved samples, work orders, planning documentation, quality control documents, etc.,
PC2. check the basic stitching parameters in the sample like stitch length per CM/Inch, Needle
type and size, thread type and size, speed of the machine, base materials, etc.,
PC3. create the program for the required stitching in the machine and save the program
PC4. check the sequence of the program as per the process sheet
PC5. Select the required speed, needle, thread for the program
PC6. Perform test run using the program
PC7. use the appropriate storage medium such as a computer hard disk, pen drive, or cloud
services for saving the proven program
Load the external program into the machine
To be competent, the user/individual on the job must be able to:
PC8. coordinate with the relevant personnel to report and rectify incorrect and inconsistent
information in job specification documents
PC9. get the relevant program from the CAD or Product Development department
PC10. transfer the program to the machine by entering it in the console or transmitting it through a
wired link or a data transfer device
PC11. validate the stitching program is correct
PC12. perform test runs using the program and give feedback to the relevant department
PC13. follow the approved procedures to resolve problems encountered with the programming,
loading and editing activities
PC14. carry out relevant documentation as per the organizational policy
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:

LSS/N2212: Inspect jigs and fix them on the machine
Description
This unit is about the inspection of the jigs/fixtures for the pattern stitching machine and fixing them in the
machine
Scope
The scope covers the following :
Perform inspection of the Jigs and fixtures
Fixing them in the pattern stitching machine
Elements and Performance Criteria
Perform inspection of the Jigs and fixtures
To be competent, the user/individual on the job must be able to:
PC1. select and prepare the appropriate jigs and other tools for testing with proving the program
PC2. Inspect the jigs as per the correct specifications
PC3. check the jig dimensions like length and width are matching with the dimensions of
computerized stitching machine
PC4. inspect the closing of jigs are perfect without any tolerance
PC5. check the needles are mounted in positions corresponding to the program selected
Fix the machine
To be competent, the user/individual on the job must be able to:
PC6. check the jigs are correctly fixed in the pattern sewing machine
PC7. check the component is free from edge burs, correctly cut and proper thickness
PC8. ensure the component is as per dimension and correctly fixing in the jigs
PC9. ensure there is no damage to the jigs while using it
PC10. perform a test run with the test component on the jig and provide feedback to relevant
authority
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. properties of leather and non-leather materials
KU2. specifications given by the raw material manufacturers
KU3. the difference between lock stitch and chain stitch
KU4. the different types of needles and threads
KU5. the basic maintenance of stitching machine
KU6. the different parts in the stitching machines like needle, bobbin and bobbin case, needle
plate, tension plate, thread winder, needle bar, pressure foot, etc.,

LSS/N2213: Operate the computerized pattern stitching machine with the
required quality
Description
This unit describes the operation of a computerized pattern-stitching machine with the required quality
Scope
The scope covers the following :
Operate the pattern stitching machine
Contribute to achieving product quality in a computerized pattern stitching machine
Elements and Performance Criteria
Operate the pattern stitching machine
To be competent, the user/individual on the job must be able to:
PC1. check that the program is at the correct starting point
PC2. ensure the jigs is fixed correctly and machine is ready operate
PC3. load and unload component(s) using the appropriate jigs or work-holding devices
PC4. check the correctness of the program by conducting a test run
PC5. identify the abnormal conditions while operating the machine and adjust speed, thread
tension, bobbin tension and programs if required
PC6. check the messages shown on the machine’s visual display regularly and take appropriate
action
PC7. restart the program from the correct restart point when the machine is been stopped before
the completion of the program
PC8. carryout the stitching operation with required pace of production
PC9. us the relevant industry 4.0 manufacturing technology to ensure interconnectivity,
automation, real-time data collection, and analysis
Contribute to achieving product quality in a computerized pattern stitching machine
To be competent, the user/individual on the job must be able to:
PC10. perform the quality check on incoming raw materials for color, defects, textures, strength,
etc., as per the sample/specifications
PC11. check the quality of the stitching needle and thread in the following parameters needle
number and point as per the specification sheet, needle bent, thread break, excessive thread
tension, thread fraying, etc.,
PC12. check that the stitching is done properly as per the design specifications and that no damage
happens to the appearance and quality
PC13. carry out the quality checks at the specified intervals on the finished product
PC14. check any stitch quality issues like stitch open, loop stitch, stitch break, roller impression,
uneven stitching if any
PC15. report defects in the materials, tools, and equipment to the supervisor

DGT/VSQ/N0101: Employability Skills (30 Hours)
Description
This unit is about employability skills, Constitutional values, becoming a professional in the 21st Century,
digital, financial, and legal literacy, diversity and Inclusion, English and communication skills, customer
service, entrepreneurship, and apprenticeship, getting ready for jobs and career development.
Scope
The scope covers the following :
Introduction to Employability Skills
Constitutional values - Citizenship
Becoming a Professional in the 21st Century
Basic English Skills
Communication Skills
Diversity & Inclusion
Financial and Legal Literacy
Essential Digital Skills
Entrepreneurship
Customer Service
Getting ready for Apprenticeship & Jobs
Elements and Performance Criteria
Introduction to Employability Skills
To be competent, the user/individual on the job must be able to:
PC1. understand the significance of employability skills in meeting the job requirements
Constitutional values – Citizenship
To be competent, the user/individual on the job must be able to:
PC2. identify constitutional values, civic rights, duties, personal values and ethics and
environmentally sustainable practices
Becoming a Professional in the 21st Century
To be competent, the user/individual on the job must be able to:
PC3. explain 21st Century Skills such as Self-Awareness, Behavior Skills, Positive attitude, self-
motivation, problem-solving, creative thinking, time management, social and cultural
awareness, emotional awareness, continuous learning mindset etc.
Basic English Skills
To be competent, the user/individual on the job must be able to:
PC4. speak with others using some basic English phrases or sentences
Communication Skills
To be competent, the user/individual on the job must be able to:
PC5. follow good manners while communicating with others
PC6. work with others in a team

Assessment Guidelines and Assessment Weightage
Assessment Guidelines
- 1. Criteria for assessment for each Qualification Pack will be created by the Sector Skill Council. Each
Element/ Performance Criteria (PC) will be assigned marks proportional to its importance in NOS. SSC will
also lay down the proportion of marks for Theory and Skills Practical for each Element/ PC.
- 2. The assessment for the theory part will be based on the knowledge bank of questions created by the
SSC.
- 3. Assessment will be conducted for all compulsory NOS, and where applicable, on the selected
elective/option NOS/set of NOS.
- 4. Individual assessment agencies will create unique question papers for the theory part for each
candidate at each examination/training center (as per the assessment criteria below).
- 5. Individual assessment agencies will create unique evaluations for skill practicals for every student at
each examination/ training center based on these criteria.
- 6. To pass the Qualification Pack assessment, every trainee should score the Recommended Pass %
aggregate for the QP.
