#### SVO/CSC/N0401: Fundamentals  of CNC Milling Machine Programming
Description
This NOS unit covers identifying NC/CNC milling machine program elements, writing and trialling a
machine program for CNC milling machine, and preparing an operation sheet.
Scope
The scope covers the following :
Preparatory activities for programming
Write CNC milling machine program
Testing and trial run of program
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. follow standard operating procedures (SOPs)
- PC2. • read, interpret and follow the information on written job instructions, specifications, SOPs, part
• information, CNC milling process plan/sheet, charts, lists, drawings and other applicable reference
• documents to obtain job requirements, tasks and relevant information

milling

• plan/sheet etc.
- PC5. • identify the programming method, dimensions, material requirements, cutting tool type,

- PC6. check the process sheet and match it with the received drawings and other specifications

- PC8. select appropriate CNC program elements for milling machine controller
- PC9. • coordinate with the relevant personnel to report and rectify incorrect and inconsistent
information in • job specification documents
- PC10. interpret engineering drawings to define milling machine function and tool path geometry
- PC11. calculate coordinates for tool path or milling functions, as required
- PC12. write program in standard code format in accordance with SOPs

#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. organisation procedures for health, safety and security, individual role and responsibilities in
this context
- KU2. elements of a NC/CNC program
- KU3. function of elements in controlling the operation of a NC/ CNC milling machine
- KU4. machining operations to be performed in the manufacture of the given part or product
- KU5. appropriate type(s) of NC/CNC milling machine to perform the required milling operations
- KU6. milling operations to be controlled by the program to be written
- KU7. tool path(s) to be followed when producing the part or product
- KU8. sequence of milling operations to be programmed
- KU9. reasons for selecting the chosen tool path(s) and sequence of operations
- KU10. canned cycles and sub-routines accessible in the particular NC/CNC milling machine
- KU11. application of each canned cycle and sub-routine available
- KU12. canned cycles and/or sub-routines to be used in the NC/CNC milling program
- KU13. reasons for selecting the chosen canned cycles and/or sub-routines
- KU14. standard codes i.e. D, F, G, M, N, S and T used in the writing of NC/CNC programs
- KU15. applications of standard codes in NC/CNC programming
- KU16. procedures for writing NC/CNC programs in standard code format
- KU17. procedures for completing NC/CNC operation sheets
- KU18. information to be included in NC/CNC operation sheets
- KU19. procedures for manual operation of the NC/CNC milling machine
- KU20. reasons for testing and proving the NC/CNC program
- KU21. procedures for editing the NC/CNC program via the milling machine controller
