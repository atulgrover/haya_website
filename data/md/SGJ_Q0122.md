Brief Job Description
Agrivoltaics Installer Electrical is responsible for installation, operation and maintenance of solar
photovoltaic systems for producing power and suitable crops at the project site.
Personal Attributes

SGJ/N0164: Perform Site Survey for installation of Solar PV System for
Agrovoltaic system
Description
How to assess the site condition for the installation of Agri PV system. Identify load to be connected to
agrivoltaic System. Perform all pre-site testing activities.
Scope
The scope covers the following :
This unit tells about Site Survey for installation of Solar PV System for Agrovoltaic system
Elements and Performance Criteria
Site Survey for the installation of agrivoltaic system and access the customer’s requirement.
To be competent, the user/individual on the job must be able to:
PC1. understand the concept and requirements of agrivoltaic system.
PC2. discuss how to Understand the location of installations.
PC3. explain how to Select a shadow-free location for agrivoltaic system.
PC4. assess the site level pre-requisites for solar PV installation and show how to prepare a site
map of the location where installation and cultivation has to be carried out.
PC5. identify and list the load to be connected to the Solar PV system and show how to assess the
load to be run on agrivoltaic system.
PC6. explain how to Check for any shading obstacles to the solar panels.
PC7. discuss about ON Grid and Off Grid Solar PV system
PC8. explain and perform Soil test, Earth Resistance test, Pull-out test and contoured Survey.
PC9. decide on the type of mounting and spacing of panels to be developed.
PC10. discuss how to inform the customer of any civil construction to be undertaken for installing
the panels.
PC11. prepare a load profile.
PC12. Outline the importance of Agri PV system.
PC13. Perform Soil test, Earth Resistance test, Pull-out test and contoured Survey.
PC14. show how to document the site survey variables and complete the checklist/site survey form.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Company documentation policy.
KU2. Document information using appropriate corporate forms.
KU3. Obtain authorization from specified field safety officer and supervisor
KU4. Company reporting structure

SGJ/N0165: Procure Solar PV system components according to Agrovoltaic
Installation
Description
How to estimate Solar PV system sizing. Final designing and drawing approval. How to Prepare Bill of
Material. Discuss Order placing for components, procurement, and verification.
Scope
The scope covers the following :
This unit tells about how to Procure Solar PV system components according to Agrovoltaic
Installation
Elements and Performance Criteria
Procure the agrivoltaic system components and prepare bill of material
To be competent, the user/individual on the job must be able to:
PC1. determine size of solar panel, Controller/Inverter, Transformer, Cable, Breaker, SCADA
system, etc.
PC2. discuss procedure of Design finalization and drawings release
PC3. prepare Bill of Materials (BoM) from single line diagram, civil/mechanical and
electrical/agriculture drawings and show how to check materials received as per final BOM
and ensure that the correct material for the job arrives on site and is damage free
PC4. explain how to Approach stores of the company or the market to place the requirement for
components as per BOM.
PC5. ensure that the quantity of panels, controller/inverter and batteries match the voltage
requirement of the system.
PC6. document variation and submit to design team (if required) and obtain approval or revised
drawings.
PC7. ensure that only company recommended quality materials are used unless specified by
customer.
PC8. ensure that all materials are Quality control passed.
PC9. ensure that all the components are handled and stored properly as per standard operating
procedures and show how to report and document the status of material received at site and
take appropriate action for replacements, if any.
PC10. show the connection practice of on-grid/off-grid/hybrid system.
PC11. show how to identify and verify the equipment specifications.
PC12. show how to arrange for tools and consumables required for mounting the solar panels over
crops.
PC13. show how to complete all documentation w.r.t. procurement
Knowledge and Understanding (KU)

SGJ/N0167: Install Electrical components of Solar PV System for
Agrivoltaic system installation
Description
This unit tells about how to Install Electrical components of Solar PV System for Agrivoltaic system
installation
Scope
The scope covers the following :
Activities required for Agrovoltaic system installation
Show how to perform Installation of electrical components along with conduits and cables.
Elements and Performance Criteria
Install Electrical components of Solar PV System for Agrivoltaic system installation
To be competent, the user/individual on the job must be able to:
PC1. discuss how to use the site safety plan and maintain clean work place.
PC2. explain how to clarify the maximum working voltage.
PC3. explain how to measure current and voltage on equipment before proceeding with work.
PC4. inspect and demonstrate the use of electrical installation toolkit.
PC5. inspect and maintain safety equipment.
PC6. inspect and maintain testing equipment.
PC7. inspect the civil and mechanical installation for agrivoltaic system.
PC8. install solar panels on the mounting structure with appropriate configuration and show how
to install mounting structure on foundation.
PC9. maintain proper space between the rows for Solar PV installation and show how to install
multiple panels on structure.
PC10. select the location for the energy meter, DC combiner box, controller/inverter, battery bank,
and earthing point as per the drawing and show how to install panels, controller/inverter and
other components.
PC11. confirm battery bank location and Install batteries (if required) and show how to confirm and
install battery bank racks.
PC12. prepare battery terminals and Install battery interconnection cables and show how to Install
batteries and prepare battery terminals (e.g., clean).
PC13. install DC combiner box and show how to connect cables in the agrivoltaic system.
PC14. Prepare conduit and cable routing plan and show how to label and sealing of all the
components and cables.
PC15. install controller/inverter (as per requirement)
PC16. install all cables in the agrivoltaic system as per approved drawing and Show how to select
the correct cable type, color, and gauge. Show how to support and secure conduit. Show how
to terminate cables.
