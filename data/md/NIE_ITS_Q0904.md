NIE/ITS/Q0904: Cyber Security and Social Media Analyst
Brief Job Description
The Cyber Security & Social Media Analyst qualification is designed to equip learners with essential skills in
operating systems, networking, cyber security, cyber forensics, and social media analytics. The course
provides hands-on training in configuring secure networks, managing firewalls, detecting and mitigating
cyber threats, and analyzing social media data using modern tools. It also introduces learners to AI/ML
concepts, server administration, and the use of disruptive technologies like cloud computing. The
qualification prepares candidates for diverse roles in cyber security and digital communication, making
them industry-ready professionals capable of protecting digital assets and managing online reputations.
Personal Attributes
It cultivates critical thinking, attention to detail, and a strong analytical mindset essential for cybersecurity
and network administration. It encourages adaptability, technical curiosity, and problem-solving in real-
world scenarios. Learners also develop ethical responsibility, digital awareness, and effective
communication skills necessary for managing secure systems and data-driven technologies.

NIE/ITS/N0907: Operating system Basics
Description
Fundamentals of Network and Operating Systems encompass competencies in understanding networking
fundamentals, operating system basics, network configuration and management, network services and
protocols, troubleshooting, virtualization, security, documentation, and compliance within the context of
network and operating system environments.
Scope
The scope covers the following :
Networking fundamentals, configuration and management, operating system basics, virtualization,
security
Elements and Performance Criteria
Computer Networking
To be competent, the user/individual on the job must be able to:
PC1. Knowledge about the Benefits of Networks, components of Computer Networks and also
have an insight into various topologies used in networking.
PC2. Explain various Transmission modes, Ethernet, and the Classification Of Transmission Media.
PC3. In-depth idea about various networking devices like Repeaters, Hubs, Bridges, Switches, and
routers
OSI Reference Model & TCP/IP Protocol Suite
To be competent, the user/individual on the job must be able to:
PC4. Overview of OSI, TCP/IP Model, and Function of layers, learn about various types of networks.
PC5. Knowledge about TCP/IP Protocol Model in Depth, Port Numbers, Common TCP& UDP, Ports,
and also Some important TCP/IP protocols
PC6. About IP addressing, classes, IP addressing scheme, subnetting basics, how to create
subnets, subnet masks, subnetting Class C addresses, subnetting Class B addresses, and
VLSM include: efficiency, scalability, flexibility, and security.
TCP/IP command line Troubleshooting utilities
To be competent, the user/individual on the job must be able to:
PC7. • Configure ip addresses in Windows and Linux and also have a proper introduction to RIR,
registries and IANA along with attaining knowledge about TCP/IP
• Troubleshooting utilities
PC8. Troubleshooting IP Addressing
Overview and Exploring Windows OS
To be competent, the user/individual on the job must be able to:
PC9. In-depth idea about the Windows operating system and its File System
PC10. Understand Basic Windows and its Control Panel
PC11. Understand various management service roles and get acquainted with the concept of
remote desktop management.

Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Computer Networking: Understanding the fundamentals of computer networking, including
how data is transmitted, network topologies, common network protocols, and the importance
of networks in modern computing.
KU2. OSI Reference Model & TCP/IP Protocol Suite: Mastery of the OSI reference model, which
breaks down network communication into seven layers, and the TCP/IP protocol suite, which is
used in the internet and real-world networking scenarios, allowing for a deep understanding of
how data is encapsulated and transmitted across networks.
KU3. TCP/IP Command Line Troubleshooting Utilities: Proficiency in using command-line tools such
as ping, tracert, and ipconfig to diagnose and troubleshoot network-related issues, enhancing
the ability to resolve connectivity and communication problems effectively.
KU4. Overview and Exploring Windows OS: Familiarity with the Windows operating system,
including its interface, file system, user management, and basic administrative tasks, enabling
students to navigate and operate within a Windows environment.
KU5. Overview and Exploring Linux OS: Competence in the Linux operating system, understanding
its structure, file system, user and group management, and basic system administration tasks,
allowing students to effectively use and administer Linux-based systems.
Generic Skills (GS)
User/individual on the job needs to know how to:
GS1. A strong foundation in computer networking, OSI and TCP/IP models, command-line
troubleshooting, and proficiency in Windows and Linux operating systems, providing a
comprehensive understanding of core IT concepts.
GS2. A valuable set of general skills, including critical thinking, effective communication, time
management, adaptability, and attention to detail, making them well-rounded professionals in
the IT field.
GS3. Professional skills in network configuration, protocol understanding, operating system
proficiency, security awareness, problem-solving, documentation, and user and group
management, equipping them for roles in network administration, system administration, IT
support, and providing a platform for continuous learning and career growth in the technology
industry.

NIE/ITS/N0908: Computer Network*
Description
Fundamentals of Cyber Security encompass competencies in core cyber security principles, regulations
and policies, threat awareness, network and operating system security, access control, incident response,
data protection, ethical hacking, and risk management, providing a framework for individuals to
understand, implement, and adhere to essential security practices in the field of cyber security.
Scope
The scope covers the following :
Fundamentals of Cyber Security encompasses the foundational knowledge and skills required to
comprehend, implement, and maintain essential security practices, including threat awareness,
network and system security, access control, and incident response, to safeguard digital assets and
data from cyber threats and vulnerabilities.
Elements and Performance Criteria
Basics of Information Security
To be competent, the user/individual on the job must be able to:
PC1. understand Information Security, CIA Triad, Confidentiality, integrity, Availability
Authentication, Authorization, and Accounting.
PC2. Understanding computer Ethics will be able to the differentiate between ethical and
Unethical behavior
PC3. About Services & Techniques, Actives, Passive Threats and Exploit, etc, Authentication
Authorization and Accounting (AAA)
Ethical Hacking and Basic Cryptography
To be competent, the user/individual on the job must be able to:
PC4. Overview of Ethical Hacking.
PC5. About the types of malware and its prevention.
PC6. About Cryptography, Plaintext, Ciphertext, Encryption, Decryption, Cipher, Symmetric, and
asymmetric Cryptography, Hashing
Introduction to OS security
To be competent, the user/individual on the job must be able to:
PC7. About OS security and Access Control.
PC8. Share Security, Password Policies, User Account Policies.
Security Tools for Windows Operating System
To be competent, the user/individual on the job must be able to:
PC9. Overview of security tools for Windows Operating System.
PC10. About Virus & Threat Protection mechanisms.
PC11. About Firewall & Network Protection, install and configure a personal firewall, and will be able
to create Inbound & Outbound Rules

Description
develops the competencies required to design, configure, and manage secure computer networks. It
covers foundational and advanced networking concepts including IP addressing (IPv4/IPv6), subnetting,
routing protocols (RIP, OSPF, EIGRP), VLANs, ACLs, NAT, and WAN technologies. Learners gain hands-on
experience with configuring network devices, securing Layer 2 environments, enabling remote access
protocols, and implementing monitoring and VPN solutions.
Scope
The scope covers the following :
It aligns with the National Occupational Standards (NOS) by preparing learners for roles in network
administration, technical support, and cybersecurity. It covers practical skills such as configuring
routers, switches, protocols, and network security features, making students job-ready for roles in IT
infrastructure. The hands-on focus on troubleshooting, monitoring, and securing networks supports
core competencies expected in national and global ICT job markets.
Elements and Performance Criteria

tunnels, and configures monitoring/logging tools like SNMP and syslog servers to track device
activities.

topology.

and computer screens. Proctors authenticate the candidate based on registration details, pre-test image
captured and I- card in possession of the candidate. Proctors can chat with candidates or give warnings to
candidates. Proctors can also take screenshots, terminate a specific user's test session, or re-authenticate
