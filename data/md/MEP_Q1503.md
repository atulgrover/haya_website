#### MEP/Q1503: Lead Business Analyst
Brief Job Description
Lead Business Analyst qualification equips learners with in-depth skills in data analysis, big data
technologies, machine learning, and business intelligence tools such as Python, R, SQL, Tableau, and
Hadoop. This qualification is designed to prepare individuals for advanced roles in business analytics,
enabling them to lead data-driven decision-making processes and optimize business strategies through
sophisticated analytical techniques. It is ideal for those seeking to enhance their expertise in the rapidly
evolving field of business analytics.
Personal Attributes
Analytical thinking, problem-solving ability, leadership skills, strategic decision-making, technical
proficiency, attention to detail, adaptability, strong communication skills, critical thinking, data-driven
mindset.

#### MEP/N1515: Basics of R Programming
Description
This NOS focuses on the fundamental concepts of R programming, including data manipulation, statistical
computing, and visualization, to support business analytics and data-driven decision-making.
Scope
The scope covers the following :
R Programming Fundamentals
Basic Data Types, Vectors, Lists, and Matrices
Arrays, Factors, and Data Frames
Flow Control & Functions
Charts & Graphs
#### Elements and Performance Criteria
R Programming Fundamentals
#### To be competent, the user/individual on the job must be able to:
- PC1. Install and configure the R programming environment on various operating systems.
- PC2. Identify and explain the features of R, including how to execute R scripts and manage
projects within R.
- PC3. Utilize comments, reserved words, and identifiers effectively in R scripts.
- PC4. Declare and use constants and variables in R, applying appropriate operators (arithmetic,
relational, logical, assignment, and miscellaneous) in expressions.
- PC5. Understand and apply operator precedence rules in complex expressions and work with
strings effectively in R.
Basic Data Types, Vectors, Lists, and Matrices
#### To be competent, the user/individual on the job must be able to:
- PC6. Define and utilize basic data types in R, including numeric, integer, complex, logical, and
character types.
- PC7. Create, combine, and modify vectors, including accessing, deleting, and sorting vector
elements.
- PC8. Perform vector arithmetic, recycling, and element sorting, demonstrating the ability to read
and manipulate vector data.
- PC9. Create and manipulate lists in R, including accessing, updating, and merging list elements.
- PC10. Convert lists to vectors and demonstrate list operations effectively.
- PC11. Create matrices, access matrix elements, and perform matrix arithmetic and operations,
including manipulation and sorting of matrix data.
Arrays, Factors, and Data Frames
#### To be competent, the user/individual on the job must be able to:
- PC12. Create and manipulate arrays in R, including accessing, modifying, and performing
arithmetic operations on array elements.

- KU3. Explain data manipulation techniques using R packages such as dplyr and tidyr.
- KU4. Identify best practices for writing efficient R scripts and debugging errors.
#### Generic Skills (GS)
User/individual on the job needs to know how to:
- GS1. Communicate analytical findings effectively using R-generated reports and visualizations.
- GS2. Apply problem-solving skills to clean, process, and analyze data using R.
- GS3. Use critical thinking to select appropriate statistical techniques for business insights.
- GS4. Demonstrate proficiency in RStudio and relevant R libraries for data analysis.

#### MEP/N1516: Database Management   System
Description
This NOS focuses on the fundamentals of database management systems (DBMS), including data storage,
retrieval, security, and optimization to support efficient business data management.
Scope
The scope covers the following :
Database Approach
Working with MS Access
Working with Structured Query Language (SQL)
Working with PL/SQL
Query Processing and Optimization
#### Elements and Performance Criteria
Database Approach
#### To be competent, the user/individual on the job must be able to:
- PC1. Explain the features, advantages, and disadvantages of the database approach compared to
traditional data management methods.
- PC2. Identify and describe the components of a Database Management System (DBMS), including
hardware, software, data, procedures, and database access language.
- PC3. Differentiate between various data models, including hierarchical, network, relational, and
Entity-Relationship (ER) models.
- PC4. Perform ER analysis, defining attributes and domains, and apply integrity constraints such as
primary keys, foreign keys, and unique constraints.
- PC5. Explain the concepts of normalization and apply normalization techniques to design
databases in INF, 2NF, and 3NF to eliminate redundancy and ensure data integrity.
- PC6. Maintain data security, confidentiality and follow ethical conduct always while handling
different data
Working with MS Access
#### To be competent, the user/individual on the job must be able to:
- PC7. Create tables in MS Access, defining data types and field properties according to the
requirements of the database.
- PC8. Establish and manage relationships between tables in MS Access to maintain referential
integrity.
- PC9. Design and create forms in MS Access for efficient data entry and retrieval.
- PC10. Construct and execute queries in MS Access, including simple queries, cross-tab queries, and
queries designed for specific data retrieval needs.
- PC11. Generate reports in MS Access using report wizard and query design, creating simple reports
and cross-tab reports that summarize and present data effectively.
Working with Structured Query Language (SQL)

- PC20. Describe the principles of database recovery and apply appropriate techniques to restore

- KU4. Identify best practices for database security, backup, and recovery management.

- GS1. Communicate database structures and queries effectively to technical and non-technical stakeholders.

- GS3. Use problem-solving techniques to troubleshoot database performance and integrity issues.
- GS4. Demonstrate proficiency in SQL, database management tools, and cloud-based database solutions.

#### MEP/N1517: Data Visualization Tools - Tableau
Description
This NOS focuses on using Tableau for data visualization, analysis, and reporting to enhance business
intelligence and support data-driven decision-making.
Scope
The scope covers the following :
Tableau Basic Reports
Tableau Charts
HR analytics tools and techniques
Tableau Advanced Reports
Tableau Calculations & Filters
#### Elements and Performance Criteria
Tableau Basic Reports
#### To be competent, the user/individual on the job must be able to:
- PC1. Connect to Excel files within Tableau, importing data for analysis.
- PC2. Connect to text files and import data efficiently into Tableau for report generation.
- PC3. Integrate data from Microsoft Analysis Services with Tableau, ensuring correct data
interpretation.
- PC4. Create and remove hierarchies in Tableau to organize data and enable drill-down analysis.
- PC5. Define and implement parameters in Tableau to control data visualizations dynamically.
- PC6. Utilize grouping techniques to categorize data, applying examples to create meaningful data
segments.
- PC7. Design your first report in Tableau, applying data labels for clarity.
- PC8. Organize data using folders and apply sorting techniques to enhance data visualization.
- PC9. Combine data sets in Tableau, creating comprehensive reports that provide a holistic view of
the data.
Tableau Charts
#### To be competent, the user/individual on the job must be able to:
- PC10. Create various chart types in Tableau, including area, bar, box, bubble, and bump charts, to
represent data visually.
- PC11. Develop more complex visualizations such as bullet, circle, Gantt, line, and lollipop charts.
- PC12. Utilize advanced chart types like Pareto, pie, scatter, stacked, tree, world cloud, and waterfall
charts to provide in-depth data analysis.
- PC13. Create filled maps, crosstab, combined, motion, and heatmap visualizations to represent
geographical and temporal data.

| Sector | Sector is a conglomeration of different business operations having similar business and interests. It may also be defined as a distinct subset of the economy whose components share similar characteristics and interests. |

| Sub-sector | Sub-sector is derived from a further breakdown based on the characteristics and interests of its components. |
| Occupation | Occupation is a set of job roles, which perform similar/ related set of functions in an industry. |
| Job role | Job role defines a unique set of functions that together form a unique employment opportunity in an organisation. |
| Occupational Standards (OS) | OS specify the standards of performance an individual must achieve when carrying out a function in the workplace, together with the Knowledge and Understanding (KU) they need to meet that standard consistently. Occupational Standards are applicable both in the Indian and global contexts. |
| Performance Criteria (PC) | Performance Criteria (PC) are statements that together specify the standard of performance required when carrying out a task. |
| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |
| Qualifications Pack (QP) | QP comprises the set of OS, together with the educational, training and other criteria required to perform a job role. A QP is assigned a unique qualifications pack code. |
| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
| Description | Description gives a short summary of the unit content. This would be helpful to anyone searching on a database to verify that this is the appropriate OS they are looking for. |
| Scope | Scope is a set of statements specifying the range of variables that an individual may have to deal with in carrying out the function which have a critical impact on quality of performance required. |
