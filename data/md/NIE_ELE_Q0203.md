#### NIE/ELE/Q0203: Embedded  System  Junior Developer (O-Level Embedded
System Design)
Brief Job Description
This course offers practical training in integrating multiple disciplines, such as engineering and computer
science, to design and develop complex systems. It emphasizes hands-on experience and industry-
relevant skills to prepare students for Embedded System analysis, design, and implementation roles. O
Level in Embedded System Design aims to equip students with the practical skills and theoretical
knowledge necessary to tackle real-world challenges in designing and implementing complex systems.
Personal Attributes
A Junior Embedded System Developer should possess strong problem-solving skills and an analytical
mindset to address real-time system challenges. They must demonstrate attention to detail, especially
when coding and integrating hardware components. Effective communication and collaboration skills are
essential for working within development teams and documenting technical processes. Adaptability and a
willingness to continuously learn and apply new technologies are crucial in the rapidly evolving field of
embedded systems.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. NIE/ELE/N0206: Embedded System Design & C- Programming
2. NIE/ELE/N0207: Microcontroller - ARM Cortex M series - Architecture, Peripheral Programming
3. NIE/ELE/N0208: Sensor data acquisition and actuation in embedded systems
4. NIE/ELE/N0209: Linux Internals
5. NIE/ELE/N0220: Implementation of an Embedded System Project using ARM Cortex-M Series,
Sensor Data Acquisition, and Linux Internals
6. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### NIE/ELE/N0206: Embedded  System  Design & C- Programming
Description
This NOS equips the students to explore the characteristics and components of embedded systems, setting
up the development environment, and mastering C language syntax and basic programming constructs
Scope
The scope covers the following :
The scope of this course encompasses an in-depth study of embedded systems and their characteristics, focusing on the C programming language tailored for embedded applications.
Students will learn to set up the development environment and master C language syntax, variables,
data types, control flow, pointers, and memory management techniques. The course also covers input/output operations, bit-level manipulation, peripheral register control, interrupt handling, and
timer configurations. This comprehensive approach ensures students gain practical skills and theoretical knowledge essential for embedded systems programming.
#### Elements and Performance Criteria
Embedded Systems and C Programming
#### To be competent, the user/individual on the job must be able to:
- PC1. Comprehend the fundamental characteristics and applications of embedded systems
- PC2. Gain proficiency in the basics of the C programming language tailored for embedded systems
- PC3. Successfully set up and configure an embedded systems development environment, including
necessary tools and software
Programming Constructs and Memory Management
#### To be competent, the user/individual on the job must be able to:
- PC4. Demonstrate understanding of C language syntax, including variables, data types, operators,
and control flow structures
- PC5. Apply pointers in various programming scenarios, understanding their significance in
embedded systems
- PC6. Efficiently use dynamic memory allocation and deallocation techniques, and implement
memory management strategies for optimal performance in embedded systems
Peripheral Control and Interrupt Handling
#### To be competent, the user/individual on the job must be able to:
- PC7. Access and manipulate peripheral registers to control hardware components
- PC8. Implement interrupt handling mechanisms and develop interrupt service routines for
responsive embedded applications
- PC9. Configure timers and manage interrupt-based timer operations to achieve precise timing and
scheduling in embedded systems

#### NIE/ELE/N0207: Microcontroller - ARM Cortex M series - Architecture,
Peripheral Programming
Description
This NOS equips the students to have the skills necessary to develop, optimize, and manage embedded
applications, ensuring efficient and effective use of microcontroller resources.
Scope
The scope covers the following :
This NOS provides a comprehensive understanding of Embedded C programming, embedded systems concepts, and ARM Cortex microcontroller architectures. Students will learn the
fundamentals and advanced concepts of C programming, including memory management, pointers, and file operations. They will gain insights into the application areas, architecture, and development
tools for embedded systems, with a focus on recent trends. The course covers ARM Cortex architectures in depth, including the M4 and A processors, and their development environments.
#### Elements and Performance Criteria
Embedded C Programming
#### To be competent, the user/individual on the job must be able to:
- PC1. ● Demonstrate proficiency in writing and understanding complex C programs involving control
flow, data structures, and memory management.
- PC2. ● Implement algorithms using pointers and understand their role in memory manipulation and
efficient programming.
- PC3. ● Develop error-free programs with correct usage of bitwise operators and typecasting for
optimized code execution
ARM Cortex Architecture
#### To be competent, the user/individual on the job must be able to:
- PC4. ● Demonstrate the ability to configure and utilize Cortex M4 peripherals effectively in
embedded applications, including GPIO, timers, UARTs, and ADCs
- PC5. ● Develop and debug assembly language programs for ARM Cortex-M4 processors, ensuring
proper memory access and interrupt handling
- PC6. ● Design and implement interrupt service routines (ISRs) for real-time event management on
Cortex M4 microcontrollers
Power Management in Embedded Systems
#### To be competent, the user/individual on the job must be able to:
- PC7. ● Design power optimization strategies using various power modes like Active, Sleep, and
Standby to extend battery life and improve energy efficiency
- PC8. ● Implement clock management techniques, including clock gating and dynamic frequency
scaling, to minimize power consumption during idle periods
- PC9. ● Develop energy profiling techniques and utilize power management APIs to optimize energy
usage and enhance system performance

#### NIE/ELE/N0208: Sensor data acquisition and actuation in embedded
systems
Description
The objective is to understand transducers' role, sensor classifications, principles of transduction, and
sensor characteristics
Scope
The scope covers the following :
This course offers an in-depth introduction to transducers, sensors, and actuators, focusing on their
roles in measurement and control systems. Students will learn about the principles of transduction,
sensor and actuator classifications, characteristics, and applications in various fields. The course
also covers interfacing these components with microcontrollers, signal conditioning, and calibration
techniques. By the end, students will be equipped to implement sensors and actuators in real-world
applications, enhancing their skills in modern measurement and control technologies
#### Elements and Performance Criteria
Sensor Fundamentals and Types
#### To be competent, the user/individual on the job must be able to:
- PC1. ● Ability to explain the basic principles of sensors and their functions accurately
- PC2. ● Demonstrate proficiency in classifying sensors based on measured quantities and sensing
mechanisms
- PC3. ● Evaluate sensor characteristics such as sensitivity, accuracy, linearity, and range in
practical scenarios
Actuator Fundamentals and Applications
#### To be competent, the user/individual on the job must be able to:
- PC4. ● Demonstrate understanding of actuator functions and classify them based on output types
and characteristics
- PC5. ● Apply knowledge of actuators to solve real-world problems in robotics, automation, and fluid
control
- PC6. ● Evaluate and select appropriate actuators for specific applications based on performance
criteria like response time, force, torque, and displacement
Integration and Interfacing Techniques
#### To be competent, the user/individual on the job must be able to:
- PC7. ● Successfully interface sensors and actuators with microcontrollers and embedded systems
- PC8. ● Apply signal conditioning and amplification techniques effectively to improve sensor and
actuator performance
- PC9. ● Demonstrate calibration and compensation methods to ensure accurate integration and
reliable functioning in control systems
#### Knowledge and Understanding (KU)

#### NIE/ELE/N0209: Linux Internals
Description
This Course is to provide a comprehensive understanding of Embedded Linux, focusing on its architecture,
kernel basics, system calls, and file and process management. Students will learn about memory and
device management, inter-process communication, multi-threading, synchronization, and networking
concepts specific to embedded systems.
Scope
The scope covers the following :
This course encompasses the fundamental principles and practical applications of Embedded Linux.
It aims to provide students with a thorough understanding of how Linux is integrated into embedded
systems. The course covers key aspects of Linux kernel architecture, system calls, file and process
management, memory and device management, inter-process communication, multi-threading, synchronization, and networking in embedded environments. By the end of the course, students will
be proficient in the concepts and practices necessary for developing and managing embedded systems using Linux.
#### Elements and Performance Criteria
Embedded Linux Architecture and Components
#### To be competent, the user/individual on the job must be able to:
- PC1. ● Students should be able to explain the overall structure of Embedded Linux and identify its
key components
- PC2. ● Students should accurately describe the differences between Embedded Linux and standard
Linux distributions
- PC3. ● Analyze and discuss case studies where Embedded Linux is used, highlighting its
advantages and challenges
Linux Kernel Basics
#### To be competent, the user/individual on the job must be able to:
- PC4. ● Students should demonstrate how the kernel manages resources such as processes,
memory, and devices
- PC5. ● Perform practical exercises that involve configuring and optimizing kernel parameters for
resource management
- PC6. ● Write simple programs that make use of system calls to perform basic tasks like file
operations or process management
Inter-process Communication and Multi-threading
#### To be competent, the user/individual on the job must be able to:
- PC7. ● Write and test programs that utilize IPC to communicate between processes
- PC8. ● Develop and debug multi-threaded applications, ensuring proper synchronization and
resource sharing

and values for carrying out relevant tasks as per the defined learning outcomes and assessment criteria.

assessment criteria. Competence acquired by the candidate can be obtained by conducting Theory

emphasis is on the practical demonstration of skills & knowledge gained by the candidate through the
