SSC/Q8803: XR Designer
Brief Job Description
The assessment will consist of a blend of hands-on practical evaluations, viva-voce, and online proctored
scenario-based multiple-choice questions ensuring a thorough evaluation of the individual's proficiency in
learning outcomes, practical understanding, and real-world application of concepts.
Personal Attributes
AR/VR Designer must manage and collaborate with various stakeholders involved in the development of
AR/VR solution experiences. They must work independently and collaboratively to develop user interfaces
and designs. They should have an analytical mindset, and a zeal to learn new things.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
- 1. SSC/N8810: Design user experience for AR/VR solution
- 2. SSC/N8811: Develop Content and generate concept ideas for AR VR experiences, considering user
needs and project objectives.
- 3. SSC/N8823: Build prototypes to visualize and test AR/VR concepts, allowing for iterations based on
user feedback.

SSC/N8810: Design user experience for AR/VR solution
Description
This unit is about curating the AR/VR solution designing to enhance the user experience while using the
product/service
Scope
The scope covers the following :
UX design
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Understand user requirements and user behavior patterns using various ethnographic
research methods.
PC2. . Create wireframes to define the features to be included in the solution (visual, sound,
motion, etc.), the general layout of visuals, and user flows
PC3. Define the story-telling aspects to be included in the solution to enhance the user journey
PC4. Identify the no. of users (single or multiple) and define how they would interact
PC5. Set up the environment for designing the interface by identifying suitable canvas size and
software tools
PC6. Define the specifications of various visual objects to be created in the solution (dimensions,
resolution, intended viewing distance, etc.)
PC7. Define standards for various factors affecting user experience (e.g., range of motion, viewing
zones, brightness, synchronization between physical and visual motion cues, etc.)
PC8. Implement core design principles throughout the user experience design process (relevant to
current time)
PC9. Drive the prototyping process by facilitating wireframing, visualization, and beta version
development processes
PC10. Conduct user interviews to test the product/solution hypothesis for prototype design
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. organizational policies, procedures, and guidelines which relate to conducting research
methods and documenting research data
KU2. organizational policies and procedures for sharing data
KU3. who to involve while conducting market research
KU4. range of standard templates and tools available and how to use them
KU5. how to create a storyboard and conceptualize requirements
KU6. wireframing tools

SSC/N8811: Develop Content and generate concept ideas for AR VR
experiences, considering user needs and project objectives.
Description
This NOS is about developing and generating concepts for AR/VR experiences
Scope
The scope covers the following :
Three D asset creation
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Develop storyboards that illustrate the flow of the user experience, including key interactions,
transitions, and emotional beats, allowing for a visual representation of the proposed content.
PC2. Create and optimize 3D models and scenes for the development of AR/VR solutions
PC3. Evaluate resources that have pre-existing 3D models
PC4. Develop texturing, animation, and lighting features of the created/optimized 3D model
PC5. Test 3D model on appropriate platforms to gather feedback on the content and experience
PC6. Render 3D model in the AR/VR solution
PC7. Ensure that the visual is crisp using suitable editing and post-processing techniques
PC8. Add compositing, special FX, and music to the solution
PC9. Export the solution to the required formats
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. organizational policies, procedures, and guidelines which relate to 3D content development
and documenting data
KU2. organizational policies and procedures for sharing data
KU3. who to involve while developing AR/VR 3D solution
KU4. range of standard templates and tools available and how to use them
KU5. how to create a storyboard and conceptualize requirements
KU6. tools and software to build 3D models and create animations
KU7. tools and techniques to add additional features (music, lighting, post-processing, etc.) to
enhance user experience
KU8. tools and techniques to test the models for stability and scalability
KU9. how to create standard technical and supporting documents
Generic Skills (GS)

SSC/N8823: Build prototypes to visualize and test AR/VR concepts,
allowing for iterations based on user feedback.
Description
This NOS is about buidling the prototype
Scope
The scope covers the following :
Type of Prototypes,Prototyping Process,Iteration and Refinement,
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Understand the purpose of prototypes
PC2. Understand different types of prototypes (Low, Medium & High-Fidelity Prototypes)
PC3. Brainstorm and outline the core functionalities and features of the AR/VR application. Use
sketches or storyboards to map user journeys and identify key interactions
PC4. Develop the prototype using chosen tools and technologies. Ensure the prototype reflects the
conceptual design and intended user experience.
PC5. Incorporate visual assets (3D models, animations) and interaction scripts to simulate the
environment and user interactions
PC6. Conduct usability testing sessions with actual users to observe interactions with the prototype.
Focus on gathering qualitative and quantitative feedback regarding usability, navigation etc.
PC7. Use techniques like think-aloud protocols, where users express their thoughts while interacting
with the prototype, to capture their impressions and frustrations
PC8. . Analyze the data collected during user testing. Identify common pain points, feature
requests, and areas of confusion to inform the next iteration of the prototype
PC9. Based on feedback, make necessary adjustments to the prototype. This may involve refining
user flows, improving interactions, enhancing visual design, or fixing usability issues
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Prototyping techniques
KU2. AR/VR Development tools
KU3. User Centered design principles
KU4. Interaction and experience design
KU5. Programing and Scripting
KU6. Feedback and iteration processes
KU7. Perofrmance and Optimization
