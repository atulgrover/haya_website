#### SSC/Q8302: Cloud Engineer
Brief Job Description
Individuals in this job are responsible for designing, maintaining, evaluating, and testing architectures of
cloud products and solutions. They formulate enterprise policies and guidelines for cloud implementation
and governance. They assist in validating customer proposals and project plans for cloud implementation.
They also assess cloud vendors and third-party cloud service providers.
Personal Attributes
Cloud Architects must be able to communicate effectively. They must have strong interpersonal skills, an
analytical mindset, and a zeal to learn new things.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N8312: Assist in creating proposals and cost models for implementing cloud solutions
2. SSC/N8311: Validate project plans, costs, and resources required for implementing cloud solutions
3. SSC/N8310: Define parameters and tools to monitor and manage cloud services
4. SSC/N8309: Ensure cloud platforms and services are scalable, resilient, and fault-tolerant
5. SSC/N8308: Design and maintain strong security architecture
6. SSC/N8307: Analyze, design, and maintain Cloud Engineerure that meets business requirements
7. SSC/N8306: Translate business-level use cases into technical requirements and specifications
8. SSC/N8305: Define enterprise cloud guidelines and implement regulatory compliances
9. SSC/N8304: Assess and screen cloud vendors and third-party service providers
10. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### SSC/N8312: Assist in creating proposals and cost models for
implementing  cloud solutions
Description
This unit is about supporting the preparation of proposals for implementing cloud solutions, including
defining the scope, planning execution, estimating costs, and assisting in tracking project outcomes.
Scope
The scope covers the following :
Define project scope
Plan project implementation
Estimate project costs
Drive project implementation
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. support in compiling technical specifications and solution requirements for the proposal
- PC2. verify that user and business requirements are accurately documented in the proposal
- PC3. support in drafting a detailed scope of work and project boundaries for the cloud
implementation
- PC4. support in compiling technical specifications and solution requirements for the proposal
- PC5. assist in preparing an implementation plan with clear timelines and milestones
- PC6. identify key drivers influencing project execution such as time, cost, and performance
- PC7. provide inputs on billing models and consumption tracking for different cloud providers
- PC8. compile a checklist of implementation activities and dependencies
- PC9. document resource and licensing requirements necessary for project execution
- PC10. estimate project costs including labor, licenses, infrastructure, and support services
- PC11. define Key Performance Indicators (KPIs) to measure project success
- PC12. forecast business and IT consumption levels to inform capacity planning
- PC13. assess technical implications of the cloud solution and its compatibility with existing
infrastructure
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. standards and procedures related to cloud project proposals
- KU2. policies and protocols for sharing internal and customer data
- KU3. documentation formats and reporting protocols used for cloud proposals
- KU4. stakeholder roles and responsibilities in risk analysis and proposal validation

#### SSC/N8311: Validate project plans, costs, and resources required for
implementing  cloud solutions
Description
This unit is about evaluating and verifying project plans, costs, and resources associated with
implementing cloud solutions.
Scope
The scope covers the following :
Validate project plans, costs, and resources required for implementing cloud solutions
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. identify key stakeholders involved in cloud solution implementation, including internal teams,
external partners, and end users
- PC2. document and prioritize stakeholder expectations and business goals related to the cloud
initiative
- PC3. evaluate the feasibility of deliverables in the project plan with respect to scope, timeline, and
resource availability
- PC4. validate timelines and milestone schedules based on task complexity, resource capacity, and
organizational goals
- PC5. review SLAs for cloud services to ensure alignment with defined business and operational
objectives
- PC6. define and confirm human and technical resource requirements for each phase of the cloud
project
- PC7. validate detailed cost estimations including cloud infrastructure, software licenses,
operational overhead, and contingency costs
- PC8. confirm overall project schedule, dependencies, and implementation sequencing across
multi-cloud or hybrid platforms
- PC9. seek approval for the validated project plan from key stakeholders and incorporate feedback
received
- PC10. conduct a detailed risk analysis including technical, financial, and compliance risks, and
recommend mitigation strategies
- PC11. create a risk register and validate the risk management framework with appropriate
stakeholders
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. organizational policies, procedures, and guidelines related to IT project governance and planning

#### SSC/N8310: Define parameters  and tools to monitor and manage cloud
services
Description
This unit is about defining metrics and tools required for monitoring the performance and utilization of
cloud resources.
Scope
The scope covers the following :
Define parameters and tools to monitor and manage cloud services
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. review historical and real-time utilization data to identify trends in consumption of compute,
storage, and network resources
- PC2. interpret cloud resource deployment schemas such as auto-scaling groups, containers, and
serverless functions for monitoring scope definition
- PC3. classify services based on usage patterns to identify underutilized, overutilized, or idle
resources
- PC4. define Key Performance Indicators (KPIs) for monitoring performance, availability, and
reliability of cloud-hosted applications and services
- PC5. select and configure appropriate tools (e.g., CloudWatch, Azure Monitor, Datadog,
Prometheus) for monitoring based on cloud platform and service architecture
- PC6. develop a monitoring plan that includes thresholds, alerts, and automated actions for
performance degradation or resource breaches
- PC7. establish methods to track application-level and infrastructure-level metrics using logs,
traces, and telemetry data
- PC8. create dashboards and reports for usage analytics and present insights to technical and
business stakeholders
- PC9. integrate Artificial Intelligence (AI)/Machine Learning (ML) tools into the monitoring
ecosystem to enable predictive analytics and intelligent alerting
- PC10. configure automated anomaly detection using AI/ML algorithms to improve incident response
time
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. guidelines and governance policies for resource provisioning and utilization
- KU2. data-sharing and privacy policies relevant to operational monitoring
- KU3. documentation standards for logging system metrics, incidents, and monitoring parameters

#### SSC/N8309: Ensure  cloud platforms and services are scalable, resilient,
and fault-tolerant
Description
This unit is about ensuring that cloud platforms and services are resilient and fault-tolerant and respond to
scalability requirements.
Scope
The scope covers the following :
Ensure cloud platforms and services are scalable, resilient, and fault-tolerant
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. define key performance metrics for measuring the functionality, scalability, latency, and
reliability of cloud-based systems and applications
- PC2. perform systematic testing of cloud platforms and services to validate responsiveness,
scalability, fault recovery, and performance thresholds
- PC3. identify performance bottlenecks and root causes affecting scalability, reliability, and
availability
- PC4. evaluate the adaptability and modifiability of the cloud solution architecture to accommodate
changing requirements
- PC5. assess portability of the cloud solution across multiple environments (hybrid, multi-cloud) to
ensure cross-platform compatibility
- PC6. identify and assess potential internal and external security threats to cloud systems and data
- PC7. integrate essential security mechanisms such as IAM, encryption, and authentication
protocols in cloud infrastructure
- PC8. develop and implement disaster recovery and incident response plans to ensure business
continuity
- PC9. integrate cloud-native frameworks and patterns (e.g., microservices, containerization) to
design scalable cloud solutions
- PC10. identify and implement auto-scaling, load balancing, and orchestration services for dynamic
demand management
- PC11. utilize analytics and monitoring tools to analyze performance data and inform capacity
planning decisions
- PC12. apply AI-based scaling strategies by using predictive analytics for workload forecasting and
dynamic provisioning
- PC13. validate fault-tolerance using AI-simulated stress tests and scenario-based modeling
- PC14. schedule and execute periodic system and platform upgrades in line with organizational and
technological advancements
- PC15. validate that upgrades enhance or maintain required levels of security, performance, and
scalability
