SSC/Q0510: Software Programmer
Brief Job Description
The Software Programmer qualification trains individuals in fundamental programming principles, software
development methodologies, and a specific programming language (Java, Python, HTML5, Kotlin or Go). It
also includes essential skills in project management, requirements engineering, and general
employability/life skills, and offers specialization through elective modules.
Personal Attributes
They must show enthusiasm to learn new things, they must have good communication skills to
communicate with collegues and stake holders
Applicable National Occupational Standards (NOS)
Compulsory NOS:
- 1. SSC/N0509: Verify the specifications and contribute to the design of software program
- 2. DGT/VSQ/N0102: Employability Skills (60 Hours)
Electives(mandatory to select at least one):
Elective 1: Java
This elective deals with Programming in Java
- 1. SSC/N0510: Develop, test and execute software programs as per specifications using Java
Elective 2: Python
This electives deal with Programming in Python
- 1. SSC/N0511: Develop, test and execute software programs as per specifications using Python
Elective 3: HTML 5
This electives deals with Programming in HTML 5
- 1. SSC/N0512: Write, test and execute programs in HTML5 to develop web or mobile applications as
per specifications
Elective 4: Kotlin

SSC/N0509: Verify the specifications and contribute to the design of
software program
Description
This NOS is about understanding the business and technical requirements of the software program to be
developed
Scope
The scope covers the following :
Requirement Analysis, Design Analysis, Best Practices
Elements and Performance Criteria
Requirement Analysis
To be competent, the user/individual on the job must be able to:
PC1. Understand the business context and business/ end-user requirements for the program
PC2. Understand functional and non-functional requirements for the program
Design Analysis
To be competent, the user/individual on the job must be able to:
PC3. Interpret the high-level and low-level design parameters using appropriate sources
PC4. Participate in the design of software program
Best practices
To be competent, the user/individual on the job must be able to:
PC5. Understand the project management frameworks used (agile methodologies and design
thinking principles) in planning the software program
PC6. Keep a track of latest technological developments related to programming and identify their
potential applications in your business domain
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Organizational procedures and guidelines related to SDLC programming and documentation
KU2. Access and utilize data source documents and information relevant to software development
KU3. Identification of stakeholders involved at various stages of the SDLC.
KU4. Availability and effective use of standard templates and platforms for coding documentation
and project management
KU5. An overview of Industry 4.0 technologies their use cases and potential applications
KU6. Basic concepts of design thinking agile methodologies and iterative development
approaches

Becoming a Professional in the 21st Century

SSC/N0510: Develop, test and execute software programs as per
specifications using Java
Description
This NOS is about program development and execution in java aligned to the prescribed technical
specifications
Scope
The scope covers the following :
Design Verification, Programming and Testing, Documentation
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Check the design specifications and define the objectives and functionality of the Java
program and align them with design specifications
