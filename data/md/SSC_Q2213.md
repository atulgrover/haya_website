#### SSC/Q2213: Domestic  Biometric Data Operator
Brief Job Description
A Domestic biometric Data Operator is responsible for capturing, authenticating and processing biometric
data of target users. Depending on the size and structure of the organisation, the tasks may include
installing and the computer hardware and software monitoring and maintaining computer systems and
networks, troubleshooting biometric system, relevant computer hardware software issues and network
problems.
Personal Attributes
This job requires the individual to have thorough knowledge of various technology trends and processes as
well as have updated knowledge about biometric systems and IT initiatives. The individual should have
fast and accurate typing / data encoding.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N3023: Undertake Bio-Metric data entry and processing
2. SSC/N2208: Data Security and Privacy Management for Data Handling Roles
3. DGT/VSQ/N0101: Employability Skills (30 Hours)

#### SSC/N3023: Undertake  Bio-Metric data entry and processing
Description
This unit is about undertaking the authentication and entry of biometric data
Scope
The scope covers the following :
Check the authentication process
Maintain appropriate records
#### Elements and Performance Criteria
Check the authentication process
#### To be competent, the user/individual on the job must be able to:
- PC1. capture the biometric data of target users through data collection and processing, including
face recognition and iris scanning, while adhering to established guidelines.
- PC2. establish the user's identity, based on the matching process
- PC3. ensuring validation of biometric data by verifying accuracy and completeness during data
collection and processing
- PC4. grant access to the users based on the match of the captured biometric data with that stored
in the system
- PC5. ensure the users are aware of the guidelines applicable to the access and use of the relevant
facility or system
- PC6. identify and handle exceptions to ensure smooth system operation
- PC7. coordinate with the biometric equipment manufacturer to resolve complex issues with the
biometrics system
Maintain appropriate records
#### To be competent, the user/individual on the job must be able to:
- PC8. log the biometric data transactions for auditing purposes
- PC9. collect and enter data from handwritten applications of individuals in the appropriate
computer program
- PC10. review and verify the captured biometric data
- PC11. compare the transcribed data with the source document and correct any errors, with the
supervisor’s help as required
- PC12. managing errors in biometric face recognition or iris scanning by adhering to SOP guidelines
and maintaining compliance with security protocols
- PC13. ensure all biometric documentation is complete and ensure data privacy and security
- PC14. maintain data back-ups to prevent the accidental loss of data
- PC15. ensure compliance with the relevant privacy and security laws and regulations governing
biometric data collection and storage

#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. appropriate biometric data entry procedures, tools, and techniques for accurate data capture
and entry
- KU2. requirements of typical helpdesk customers and tools for incident management and customer support in biometric systems
- KU3. criteria distinguishing acceptable vs. non-acceptable biometric data per standards and policies
- KU4. basic computer configuration, networking, and maintenance requirements for biometric data
capture and processing
- KU5. principles of biometric system error rates, including false accept, false reject, equal error
rate, and detection error trade-off
- KU6. procedures for compiling reports and making data comparisons using appropriate database management software
- KU7. importance of documenting, classifying, and prioritizing service requests effectively
- KU8. initial registration and secure capture/storage of biometric data in systems
- KU9. encryption methods, like hashing and salting, to secure biometric templates and data transmission
- KU10. factors affecting the accuracy and reliability of biometric sensors
- KU11. distinction between one-to-one (verification) and one-to-many (identification) biometric matching algorithms
- KU12. biometric codes and standards, including relevant data protection laws and regulations
- KU13. use of biometric authentication in physical (building access) and logical (system access)
control systems, including on mobile devices and relevant performance metrics (FAR, FRR, accuracy rates)

- GS8. take quick decisions to deal with workplace emergencies/ accidents
- GS9. evaluate all possible solutions to a problem to select the best one

#### SSC/N2208: Data Security and Privacy Management  for Data Handling
Roles
Description
This unit defines the responsibilities of individuals in data-related roles to secure sensitive information,
ensure compliance with privacy regulations, and implement secure data handling practices. It involves
protecting data from unauthorized access, mitigating security risks, and adhering to legal, organizational,
and ethical standards to maintain data integrity, availability, and confidentiality.
Scope
The scope covers the following :
Ensure compliance with data security and privacy regulations
Secure data collection, storage, and transmission
Implement access controls and authentication mechanisms
Identify and mitigate data security risks
Ensure data integrity and availability
Ensure secure data disposal and archiving
Collaborate with relevant stakeholders to maintain security standards
#### Elements and Performance Criteria
Ensure Compliance with Data Security and Privacy Regulations
#### To be competent, the user/individual on the job must be able to:
- PC1. follow applicable data privacy laws and organizational data security policies
- PC2. verify compliance through audits, assessments, and regular reviews
- PC3. report any breaches or non-compliance to relevant authorities in a timely manner
Secure data collection, storage, and transmission
#### To be competent, the user/individual on the job must be able to:
- PC4. ensure the collection, storage, and transmission of sensitive data is encrypted and securely
handled
- PC5. apply access controls to data storage and ensure only authorized personnel have access
- PC6. verify secure transmission protocols to prevent unauthorized access during data transfer
Implement access controls and authentication mechanisms
#### To be competent, the user/individual on the job must be able to:
- PC7. set up role-based access control (RBAC) and enforce multi-factor authentication (MFA) for
system access
- PC8. regularly monitor and review access logs for suspicious activities and potential security
threats
- PC9. ensure regular updates, patches, and maintenance of systems to address vulnerabilities
Identify and mitigate data security risks
#### To be competent, the user/individual on the job must be able to:

external attacks
- PC11. implement proactive measures and technologies to mitigate identified security risks

Ensure data integrity and availability
#### To be competent, the user/individual on the job must be able to:
- PC13. implement data backup, disaster recovery, and availability strategies to ensure business

- PC20. provide necessary documentation, training, and updates to stakeholders regarding data

- PC21. communicate security policies and procedures effectively to all relevant personnel within the
organization

- KU1. legal and regulatory requirements for data security, privacy, and compliance, including GDPR, CCPA, and other regional laws.

- KU3. methods for implementing role-based access control (RBAC) and the principle of least privilege.
- KU4. authentication methods such as passwords, biometrics, multi-factor authentication (MFA), and token-based authentication.
- KU5. strategies for monitoring and logging system access, data changes, and user activities to
detect security threats.
- KU6. techniques for identifying, assessing, and mitigating risks like malware, phishing, and insider
threats.

#### Acronyms

### Page 24

| Sector | Sector is a conglomeration of different business operations having similar business and interests. It may also be defined as a distinct subset of the economy whose components share similar characteristics and interests. |
| --- | :---: |
| Sub-sector | Sub-sector is derived from a further breakdown based on the characteristics and interests of its components. |
| Occupation | Occupation is a set of job roles, which perform similar/ related set of functions in an industry. |
| Job role | Job role defines a unique set of functions that together form a unique employment opportunity in an organisation. |
| Occupational Standards (OS) | OS specify the standards of performance an individual must achieve when carrying out a function in the workplace, together with the Knowledge and Understanding (KU) they need to meet that standard consistently. Occupational Standards are applicable both in the Indian and global contexts. |
| Performance Criteria (PC) | Performance Criteria (PC) are statements that together specify the standard of performance required when carrying out a task. |
| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |
| Qualifications Pack (QP) | QP comprises the set of OS, together with the educational, training and other criteria required to perform a job role. A QP is assigned a unique qualifications pack code. |
| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
| Description | Description gives a short summary of the unit content. This would be helpful to anyone searching on a database to verify that this is the appropriate OS they are looking for. |
| Scope | Scope is a set of statements specifying the range of variables that an individual may have to deal with in carrying out the function which have a critical impact on quality of performance required. |

| Knowledge and Understanding (KU) | Knowledge and Understanding (KU) are statements which together specify the technical, generic, professional and organisational specific knowledge that an individual needs in order to perform to the required standard. |

These skills are typically needed in any work environment in today’s world. These skills are typically needed in any work environment. In the context of the OS, these include communication related skills that are applicable to most job roles. |
| Electives | Electives are NOS/set of NOS that are identified by the sector as contributive to specialization in a job role. There may be multiple electives within a QP for each specialized job role. Trainees must select at least one elective for the successful completion of a QP with Electives. |
| Options | Options are NOS/set of NOS that are identified by the sector as additional skills. There may be multiple options within a QP. It is not mandatory to select any of the options to complete a QP with Options. |
