#### HAR/ITS/N0909: Basics of Information Technology
Description
The NOS provides basic knowledge and skills to operate computer and prepares you to perform basic
office jobs.
Scope
The scope covers the following :
The NOS builds essential skills in Word, Excel, PowerPoint, and Internet usage, preparing students
for basic office tasks and serving as a foundation for advanced computer applications.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Understand the meaning, characteristics, history, generations, and classification of computers.
- PC2. Identify and explain the main components, input/output devices, and the working of a
computer system.
- PC3. Differentiate between data and information
- PC4. Create and edit documents using word processing tools with proper formatting and layout.
- PC5. Apply formulas and functions in spreadsheets and use spreadsheet tools effectively.
- PC6. Design and present information visually using digital presentation software.
- PC7. Utilize networking and internet skills to communicate online, manage email accounts, ensure
cybersecurity, and understand cloud storage
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. Demonstrates understanding of the evolution, characteristics, and classification of computers,
including their historical development and technological generations.
- KU2. Identifies and explains the main hardware components, input/output devices, and the overall
functional process of a computer system.
- KU3. Demonstrates knowledge of digital productivity tools, including word processors, spreadsheets, and presentation software, for creating and managing professional documents
and visual materials.
- KU4. networking concepts, internet services, communication protocols, and the applications of the
internet and IECT.
- KU5. using web browsers, search engines, Wi-Fi, Bluetooth, and online services for browsing, communication, uploading, downloading, and accessing e-governance platforms.
- KU6. to apply internet safety measures including strong passwords, antivirus tools, firewalls, safe
browsing practices, and awareness of cyber threats and online privacy issues.

#### HAR/ITS/N0407: Operating System  (ACCA)
Description
Provides a foundational understanding of operating systems, exploring their types, core functions, and
architecture.
Scope
The scope covers the following :
Equips learners with the skills necessary for roles in system administration, IT support etc.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Explain the concepts, history, architecture, functions, and types of operating systems
including Windows, Linux, Android, iOS, and other GUI-based systems.
- PC2. Differentiate between various operating systems such as batch, multitasking, multiprocessing,
real-time, distributed, network, and mobile operating systems.
- PC3. Describe the role of kernel, process management, CPU scheduling, deadlock handling,
memory management, storage management, file systems, and security in operating systems.
- PC4. Identify and use the elements of GUI operating systems including desktop, taskbar, start
menu, icons, windows, menus, toolbars, and dialog boxes.
- PC5. Perform file and folder management operations in Windows operating system including
creating, copying, moving, renaming, and deleting files and folders.
- PC6. Use Control Panel settings and system utilities for managing basic system configurations and
devices.
- PC7. Connect and configure peripheral devices such as keyboard, mouse, monitor, printer,
projector, and scanner with a computer system.
- PC8. Apply basic troubleshooting techniques to resolve common hardware and software issues
related to power supply, printer, scanner, and peripheral devices.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. The objective and goals of the organization and scope of work
- KU2. The principles of operating systems, including types of OS, process management, multithreading, and memory management.
- KU3. How operating systems interact with hardware and manage system resources.
- KU4. The importance of operating systems in maintaining organizational IT infrastructure, ensuring
performance, security, and resource management.
#### Generic Skills (GS)

#### HAR/ITS/N1604: Introduction to Data representation and Digital Logic
Description
This NOS provides fundamental knowledge of data representation, binary systems, Boolean algebra, and
digital logic concepts used in computer systems and digital electronics.
Scope
The scope covers the following :
The scope includes understanding number system conversions, binary arithmetic operations, coding
schemes, and error detection techniques for data representation. It also covers Boolean algebra,
logic simplification methods, truth tables, logic gates, combinational logic, and implementation of
digital circuits using different gate configurations.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Explain the concepts of data representation, number systems, binary arithmetic, and coding
schemes used in digital systems.
- PC2. Perform conversions between different number systems and apply binary arithmetic
operations accurately.
- PC3. Identify and explain the functions of basic and universal logic gates including AND, OR, NOT,
NAND, NOR, XOR, and XNOR gates.
- PC4. Implement digital circuits using different gate combinations and logic gate configurations such
as NAND, NOR, AND-OR-INVERT, and OR-AND-INVERT.
- PC5. Analyze and design simple combinational logic circuits using Boolean logic and logic gates.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. the concepts of number systems, binary arithmetic, coding techniques, Boolean algebra, logic
simplification methods, and digital logic gates used in computer and digital systems.
- KU2. the principles of data representation, error detection and correction, combinational logic, and
implementation of digital circuits using various logic gate configurations.
- KU3. the importance of digital logic and data representation concepts in computer architecture,
electronics, communication systems, and information technology applications.
- KU4. to apply logical analysis, circuit design principles, and standard digital system practices
followed in technical and computing environments.
#### Generic Skills (GS)
User/individual on the job needs to know how to:

#### HAR/ITS/N1603: Data Communications   and Networking Concepts
Description
This NOS provides knowledge of data communication systems and computer networking concepts including transmission methods, network architectures, communication protocols, reference models, and
network security.
Scope
The scope covers the following :
The scope includes understanding data communication components, transmission media, communication modes, and digital transmission methods.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Explain the concepts, components, and applications of data communication and computer
networks.
- PC2. Identify and classify guided and unguided transmission media used in communication
systems.
- PC3. Describe the architecture, components, and types of computer networks including LAN, MAN,
WAN, wireless networks, and internet networks.
- PC4. Explain the functions and working of networking devices such as NIC, hub, switch, router,
modem, bridge, repeater, and server.
- PC5. Interpret the structure and functions of OSI and TCP/IP reference models and their respective
layers.
- PC6. Explain networking concepts related to switching, routing, multiplexing, addressing, error
detection, and communication protocols.
- PC7. Identify and describe transport, application, network access, and internet layer protocols
including TCP, UDP, HTTP, FTP, DNS, SMTP, and Ethernet.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. the concepts of data communication, transmission methods, network architectures, networking devices, protocols, OSI and TCP/IP models, and communication technologies used
in computer networks.
- KU2. the principles of data transmission, routing, switching, error detection, network protocols, and
network security concepts including encryption, privacy, and digital signatures.
- KU3. the role of computer networks and communication systems in organizational connectivity, information sharing, and digital communication services.
- KU4. to apply standard networking practices, communication protocols, security measures, and network management procedures followed in IT and networking environments.

#### HAR/ITS/N1601: Object-Oriented Programming  and  Database
Management   System
Description
This NOS provides knowledge and practical skills in object-oriented programming using C++, data
structures, and database management systems with SQL.
Scope
The scope covers the following :
The scope includes developing programs using C++ concepts such as functions, arrays, pointers, classes, inheritance, polymorphism, abstraction, file handling, and data structures like linked lists,
stacks, queues, and trees. It also covers database concepts, ER modeling, normalization, relational
database management, SQL commands, joins, triggers, views, stored procedures, and data manipulation techniques for effective database management.
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. Explain the fundamentals of databases, DBMS architecture, relational models, and
normalization concepts.
- PC2. Create, manage, and manipulate databases using SQL commands such as DDL, DML, TCL,
DCL, and DQL.
- PC3. Apply SQL concepts including joins, keys, views, subqueries, triggers, and stored procedures
for database operations.
- PC4. Understand programming fundamentals, algorithms, flowcharts, and different programming
paradigms.
- PC5. Write, compile, debug, and execute programs in CPP language using control statements,
functions, arrays, strings, pointers, structures, and file handling.
- PC6. Develop applications in C++ using constructors, destructors, exception handling, dynamic
memory allocation, and file handling techniques.
- PC7. Implement data structures such as linked lists, stacks, queues, trees, and searching and
sorting techniques for efficient data management.
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. The concepts of data, database, DBMS architecture, database models, ER models, and normalization techniques.
- KU2. SQL syntax, commands, joins, views, subqueries, triggers, and stored procedures used in database management.
- KU3. programming fundamentals including algorithms, flowcharts, programming paradigms, and translators.

### Page 54

| Sector | Sector is a conglomeration of different business operations having similar business and interests. It may also be defined as a distinct subset of the economy whose components share similar characteristics and interests. |
| --- | :---: |
| Sub-sector | Sub-sector is derived from a further breakdown based on the characteristics and interests of its components. |
| Occupation | Occupation is a set of job roles, which perform similar/ related set of functions in an industry. |
| Job role | Job role defines a unique set of functions that together form a unique employment opportunity in an organisation. |
| Occupational Standards (OS) | OS specify the standards of performance an individual must achieve when carrying out a function in the workplace, together with the Knowledge and Understanding (KU) they need to meet that standard consistently. Occupational Standards are applicable both in the Indian and global contexts. |
| Performance Criteria (PC) | Performance Criteria (PC) are statements that together specify the standard of performance required when carrying out a task. |
| National Occupational Standards (NOS) | NOS are occupational standards which apply uniquely in the Indian context. |
| Qualifications Pack (QP) | QP comprises the set of OS, together with the educational, training and other criteria required to perform a job role. A QP is assigned a unique qualifications pack code. |
| Unit Code | Unit code is a unique identifier for an Occupational Standard, which is denoted by an ‘N’ |
| Unit Title | Unit title gives a clear overall statement about what the incumbent should be able to do. |
| Description | Description gives a short summary of the unit content. This would be helpful to anyone searching on a database to verify that this is the appropriate OS they are looking for. |
| Scope | Scope is a set of statements specifying the range of variables that an individual may have to deal with in carrying out the function which have a critical impact on quality of performance required. |

| Knowledge and Understanding (KU) | Knowledge and Understanding (KU) are statements which together specify the technical, generic, professional and organisational specific knowledge that an individual needs in order to perform to the required standard. |
| --- | :---: |
| Organisational Context | Organisational context includes the way the organisation is structured and how it operates, including the extent of operative knowledge managers have of their relevant areas of responsibility. |
| Technical Knowledge | Technical knowledge is the specific knowledge needed to accomplish specific designated responsibilities. |
| Core Skills/ Generic Skills (GS) | Core skills or Generic Skills (GS) are a group of skills that are the key to learning and working in today’s world. These skills are typically needed in any work environment in today’s world. These skills are typically needed in any work environment. In the context of the OS, these include communication related skills that are applicable to most job roles. |
| Electives | Electives are NOS/set of NOS that are identified by the sector as contributive to specialization in a job role. There may be multiple electives within a QP for each specialized job role. Trainees must select at least one elective for the successful completion of a QP with Electives. |
| Options | Options are NOS/set of NOS that are identified by the sector as additional skills. There may be multiple options within a QP. It is not mandatory to select any of the options to complete a QP with Options. |
