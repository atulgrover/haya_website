NIE/SSC/Q0201: Computer Application Accounting and Publishing
Assistant
Brief Job Description
The Computer Application Accounting and Publishing Assistant is an NSQF Level 3 qualification designed to
equip learners with the knowledge and practical skills required to perform office automation, computerized
accounting, and desktop publishing tasks in a professional environment. The programme enables learners
to use office productivity tools, maintain financial records using Tally Prime, design and publish digital
content using desktop publishing software, and apply computer fundamentals and operating system
concepts. It also develops employability skills, digital literacy, workplace communication, and project
execution capabilities, preparing learners for entry-level roles in offices, accounting firms, educational
institutions, publishing organizations, and other IT-enabled workplaces.
Personal Attributes
Detail-oriented, analytical, ethical, adaptable, communicative, and team-oriented professional.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
- 1. NIE/SSC/N0209: OJT/Project- Computer Application Accounting and Publishing Assistant

NIE/SSC/N0209: OJT/Project- Computer Application Accounting and
Publishing Assistant
Description
This NOS provides learners with the opportunity to apply the knowledge and skills acquired during
classroom and laboratory training in a real or simulated workplace environment. It enables learners to
execute assigned tasks, solve practical problems, prepare project deliverables, demonstrate professional
competencies, and meet industry standards through supervised on-the-job training and project work.
Scope
The scope covers the following :
The scope includes planning and executing workplace assignments, applying technical knowledge to
real-life scenarios, preparing project reports and presentations, using appropriate tools and
software, following organizational procedures, maintaining documentation, collaborating with team
members, demonstrating professional ethics, and completing assigned tasks within quality, safety,
and timeline requirements.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Plan and execute assigned workplace tasks or project activities by applying the knowledge
and skills acquired during the training programme.
PC2. Use appropriate software applications, tools, equipment, and workplace procedures to
complete assigned tasks accurately and efficiently.
PC3. Prepare and maintain project documentation, reports, presentations, and other records in
accordance with organizational and quality requirements.
PC4. Demonstrate effective communication, teamwork, problem-solving, professional ethics, and
adherence to workplace safety and organizational guidelines while carrying out project
activities.
PC5. Complete the assigned project or OJT within the stipulated timeline, present the outcomes,
and incorporate feedback to achieve the desired learning objectives and quality standards.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. The objectives, scope, and expected outcomes of the assigned workplace tasks or project
activities.
KU2. Organizational procedures, workplace practices, documentation standards, quality
requirements, and safety guidelines applicable to the assigned work.
KU3. The operation and appropriate use of software applications, tools, equipment, and digital
technologies required to complete project assignments.

NIE/SSC/N0208: Concept of Desktop Publishing Software
Description
This NOS equips learners with the knowledge and practical skills required to design, create, edit, and
publish professional digital publications using desktop publishing software. It covers page layout,
typography, image editing, vector graphics, document formatting, print and web publishing, and AI-
enabled design tools for producing high-quality visual communication materials.
Scope
The scope covers the following :
The scope includes designing page layouts, formatting text, creating and editing graphics, managing
images and layers, applying visual effects, preparing print and web-ready documents, handling
bitmap and vector graphics, using templates and master pages, and utilizing modern desktop
publishing and AI-powered design tools for professional publishing.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Create and format professional publications using desktop publishing software by applying
page layouts, master pages, templates, text formatting, and paragraph styles.
PC2. Design and edit graphics, illustrations, and images using drawing tools, layers, filters, effects,
and image enhancement features.
PC3. Import, arrange, align, crop, resize, rotate, and manage bitmap and vector graphics to
produce visually appealing documents.
PC4. Apply typography, color schemes, object formatting, text wrapping, spell checking, indexing,
and layout optimization to ensure publication quality.
PC5. Prepare, export, and publish print-ready and web-ready documents using appropriate file
formats, modern DTP applications, and AI-powered design tools while maintaining professional
publishing standards.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Fundamentals of desktop publishing, page layout principles, typography, document design,
and the applications of DTP in print and digital media.
KU2. Features and functionalities of desktop publishing software, including page setup, master
pages, templates, styles, text formatting, and object management.
KU3. Concepts of image editing, vector and bitmap graphics, layers, filters, color correction,
drawing tools, and graphic effects used in DTP applications.
KU4. echniques for importing, arranging, formatting, and exporting text, images, and graphics for
print-ready and web-ready publications.

NIE/SSC/N0207: Financial Accounting with Tally Prime
Description
This NOS equips learners with the knowledge and practical skills required to perform computerized
financial accounting using accounting principles and Tally Prime. It covers accounting fundamentals,
inventory management, voucher entry, GST compliance, payroll basics, financial reporting, data security,
backup procedures, and the generation of accurate financial records for business operations.
Scope
The scope covers the following :
The scope includes maintaining books of accounts, recording financial transactions, managing
ledgers and inventory, preparing financial statements, processing accounting vouchers,
implementing GST and payroll features, generating financial and inventory reports, securing
accounting data, performing backup and restoration, and using Tally Prime for day-to-day business
accounting.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. Record business transactions by creating and maintaining books of accounts, including
journals, cash books, ledgers, and accounting vouchers in accordance with accounting
principles.
PC2. Create and manage companies, ledgers, stock groups, inventory records, and accounting
configurations using Tally Prime.
PC3. Generate and interpret financial statements and business reports, including Trial Balance,
Profit & Loss Account, Balance Sheet, inventory reports, and MIS reports for decision-making.
PC4. Configure and process statutory compliance features, including GST, TDS, payroll, and
taxation-related transactions in Tally Prime.
PC5. Perform data security, backup, restoration, user access management, and data import/export
operations to ensure the integrity and confidentiality of accounting information.
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Fundamental accounting concepts, principles, classification of accounts, rules of debit and
credit, and preparation of books of accounts.
KU2. Concepts of inventory management, inventory valuation methods (FIFO, LIFO, Weighted
Average), and their significance in business accounting.
KU3. Features, navigation, company creation, ledger management, inventory setup, voucher types,
and reporting capabilities of Tally Prime.

NIE/SSC/N0206: Fundamentals of Computers and Operating Systems-
Description
This NOS equips learners with foundational knowledge of computer systems, operating systems, and
digital technologies. It covers computer components, hardware and software concepts, data
representation, storage devices, input/output devices, Windows and Linux operating systems, file
management, cybersecurity hygiene, and the practical use of ICT applications, mobile technologies, and
smart digital tools.
Scope
The scope covers the following :
The scope includes understanding computer architecture, memory and storage devices, operating
system functionalities, hardware and software classification, file and folder management, data
representation, cybersecurity awareness, Windows and Linux environments, ICT applications, mobile
computing, cloud-based services, and emerging smart technologies to support digital literacy and
workplace readiness.
Elements and Performance Criteria
To be competent, the user/individual on the job must be able to:
PC1. • Identify the different generations, classifications, characteristics, and applications of
• computers.
PC2. • Identify and explain the functions of major computer hardware components, including CPU,
• memory, storage, and input/output devices.
PC3. • Differentiate between system software, application software, utility software, and open-source
• software.
PC4. • Explain the concepts of data representation, number systems, and common data encoding
• techniques.
PC5. • Compare different memory and storage devices based on capacity, speed, performance, and
• applications
Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
KU1. Fundamentals, characteristics, evolution, and applications of computer systems across various
sectors.
KU2. Classification of computers and the functions of major hardware components, including CPU,
memory, storage, and input/output devices.
KU3. Concepts of hardware, system software, application software, utility software, and open-
source software.
KU4. Types of memory (RAM, ROM, Cache, Virtual Memory) and storage devices (HDD, SSD, optical
media, flash drives, and cloud storage).

NIE/SSC/N0205: Office Productivity Tools-
Description
This NOS equips learners with the knowledge and practical skills required to use modern office productivity
applications for creating, managing, analyzing, and presenting information. It covers word processing,
spreadsheets, presentations, cloud collaboration, database fundamentals, and AI-enabled productivity
tools to improve workplace efficiency, communication, and digital document management.
Scope
The scope covers the following :
The scope includes creating and formatting professional documents, developing spreadsheets with
formulas and charts, designing presentations, using cloud-based collaboration tools, applying AI
features in office applications, managing files through cloud storage, understanding basic database
concepts, and integrating office productivity tools for efficient workplace communication and
