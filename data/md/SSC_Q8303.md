#### SSC/Q8303: Cloud Application Developer
Brief Job Description
A Cloud Application Developer is responsible for designing, developing, and maintaining secure, resilient,
and scalable cloud-native applications. The person gathers and validates functional and non-functional
requirements, implements modern architectures and DevSecOps practices, and manages the full application lifecycle using continuous integration and delivery (CI/CD) pipelines. The individual also
ensures regulatory compliance, application performance, and efficient use of cloud infrastructure and
services.
Personal Attributes
Cloud Application Developers must be able to communicate effectively, build relationships with others and
collaborate with various stakeholders. They must have a zeal to learn new things.
Applicable National Occupational Standards (NOS)
Compulsory NOS:
1. SSC/N8323: Monitor and manage cloud applications and the deployed systems
2. SSC/N8322: Package software for secure and successful deployment on the cloud
3. SSC/N8321: Migrate applications to utilize the full potential of the cloud platform
4. SSC/N8320: Develop and maintain secure, resilient and highly available cloud applications
5. SSC/N8319: Design the application architecture to ensure scalable, resilient, and fault-tolerant
cloud applications
6. SSC/N8318: Develop functional and non-functional requirements for the defined scope of the application
7. DGT/VSQ/N0102: Employability Skills (60 Hours)

#### SSC/N8323: Monitor and manage   cloud applications and the deployed
systems
Description
This unit is about monitoring and managing the performance of the applications and the deployed
systems.
Scope
The scope covers the following :
Gather requirements
Monitor system performance
Report application performance
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. identify performance-impacting factors of the cloud application, such as memory leaks,
traffic loads, or latency
- PC2. evaluate application performance bottlenecks using historical performance data and logs
- PC3. define and document cost, resource utilization, and scalability requirements for optimization
- PC4. define clear metrics (e.g., latency, error rate, CPU/memory usage) to track system health
- PC5. configure dashboards and alerts using monitoring tools like CloudWatch, Datadog, or New
Relic
- PC6. use AI/ML-powered tools to detect anomalies and predict potential system failures
- PC7. perform root-cause analysis based on error logs and AI-based diagnostics
- PC8. validate cloud resource utilization against cost benchmarks and SLA parameters
- PC9. implement automation scripts to respond to predefined thresholds or anomalies
- PC10. monitor applications for security breaches and ensure compliance with cloud security policies
- PC11. create structured reports with visualizations to summarize performance data and trends
- PC12. share performance reports with stakeholders using approved templates or collaboration tools
- PC13. provide actionable recommendations for improving performance, cost-efficiency, and
scalability
- PC14. document any anomalies detected by AI/ML tools and suggest remedial steps
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. policies and standards for monitoring and managing deployed systems
- KU2. procedures for reporting performance metrics to relevant stakeholders
- KU3. templates and tools used for documenting and sharing performance insights

#### SSC/N8322: Package  software for secure and successful deployment on
the cloud
Description
This unit is about building, packaging, and deploying cloud-native applications using automated, secure,
and intelligent approaches. It includes incorporating modern technologies such as containerization, AI/ML-
based optimization, and automated pipelines for robust deployment.
Scope
The scope covers the following :
Build & package cloud applications
Plan for deployment
Automate deployment
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. create deployment units from application source code using appropriate build tools
- PC2. configure and manage environment-specific service configurations for deployment
- PC3. apply secure coding and deployment practices to protect application code and configurations
- PC4. use suitable containerization technologies (e.g., Docker) to ensure environment-agnostic
deployment
- PC5. incorporate AI/ML-based code analysis tools to detect vulnerabilities or inefficiencies during
the packaging phase
- PC6. define deployment strategies based on application architecture, performance, and downtime
requirements
- PC7. develop and maintain an operational checklist covering procedures, risks, and rollback
strategies
- PC8. evaluate the use of AI/ML models to forecast deployment risks and recommend optimal
deployment windows
- PC9. automate the deployment process using CI/CD pipelines, infrastructure-as-code (IaC), and
scripting tools
- PC10. plan and configure container orchestration platforms (e.g., Kubernetes) to provision, deploy,
and manage services
- PC11. integrate AI/ML tools for real-time deployment monitoring and anomaly detection
- PC12. coordinate with infrastructure, QA, and support teams to resolve pre- and post-deployment
issues
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:

#### SSC/N8321: Migrate applications to utilize the full potential of the cloud
platform
Description
This unit is about migrating applications to the cloud by incorporating changes in the application code,
applying AI/ML-enabled tools and methods, and ensuring the cloud platform is utilized to its full potential in
terms of scalability, automation, performance, and cost-efficiency.
Scope
The scope covers the following :
Gather business objectives
Analyze the source code
Map cloud and on-premise data
Re-host applications
Re-platform OS/middleware
Re-factor/ reengineer/re-architect applications
Test the applications
Ensure smooth operations
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. identify business goals and performance requirements using AI-driven assessment tools and
analytics dashboards
- PC2. identify AI/ML-based optimization opportunities to reduce cost and enhance performance in
cloud migration
- PC3. analyze source code and architecture using automated static/dynamic analysis tools,
including AI-powered code scanners for migration compatibility
- PC4. perform intelligent data mapping using AI-enabled tools for schema mapping, transformation
logic, and minimizing data loss
- PC5. identify application components suitable for lift-and-shift using automated cloud migration
platforms
- PC6. migrate compatible applications with minimal changes, supported by orchestration tools and
AI-based dependency resolution
- PC7. analyze OS/middleware compatibility and recommend re-platforming options using AI/ML-
based migration assistance tools
- PC8. reengineer non-compatible components using AI-assisted code conversion and optimization
tools
- PC9. refactor application code using ML-powered performance profiling and automated
remediation tools
- PC10. incorporate cloud-native and AI-first architecture principles for scalability, security, and
resilience

#### SSC/N8320: Develop  and maintain secure, resilient and highly available
cloud applications
Description
This unit is about building cloud applications that are secure, resilient to failure and are highly available to
customers.
Scope
The scope covers the following :
Develop cloud applications
Ensure application availability
Ensure application security
#### Elements and Performance Criteria
#### To be competent, the user/individual on the job must be able to:
- PC1. identify and map service dependencies (e.g., databases, message brokers) for deployment in
distributed environments like Kubernetes
- PC2. design and build resilient applications using fault-tolerant patterns such as retries, circuit
breakers, and fallback mechanisms for automated failover and recovery
- PC3. ensure horizontal scalability through container orchestration, auto-scaling policies, and
effective load balancing
- PC4. implement microservices architectures and use API gateways and service meshes (e.g., Istio)
for secure, modular, and scalable services
- PC5. ensure applications are operational, functional, and usable for fulfilling business or users'
requirements by incorporating AI-driven monitoring and alerting tools (e.g., AIOps platforms) to detect anomalies and preemptively resolve downtime risks
- PC6. integrate DevSecOps practices to implement and maintain security controls in compliance
with standards (e.g., ISO 27001, GDPR)
- PC7. secure data in transit using HTTPS, TLS, or VPNs, and define network security policies
- PC8. implement identity and access management using protocols such as OAuth 2.0, OpenID
Connect, or SAML, and enforce role-based access control
- PC9. secure data at rest using encryption techniques (e.g., AES, RSA) and cloud-native key
management solutions (e.g., AWS KMS, Azure Key Vault)
#### Knowledge and Understanding (KU)
The individual on the job needs to know and understand:
- KU1. industry standards for secure cloud application development and deployment
- KU2. legal and regulatory frameworks applicable to cloud security and data protection
- KU3. best practices for data integration across distributed systems
